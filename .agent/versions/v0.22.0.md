# v0.22.0 — Module 生命周期架构对齐

## 概述

Module 树形生命周期代码全面对齐技术文档标准。核心时序 bug 修复 + 类型体系重命名 + 服务注册前置 + OnWire 合约澄清。

## 改动

### 内核重构
- **IInitializable → IModuleChild**：接口重命名，Hub 自身不再实现
- **ModuleBehaviour → ModuleHub**：Awake 中主动扫描子节点替代子节点自注册，OnAssembleAll 从 Start 移至 Awake
- **ModuleComponent → ModuleChildMono**：移除自注册逻辑，Awake 基类为空
- **Module → ModuleChild**：纯 C# 子节点，构造函数自注册不变
- **ModuleRegistry**：泛型对齐 IModuleChild

### Hub 子类生命周期迁移（override 模式 → pre/post base 模式）
- **GameService**：GameContext 创建 + EventDispatcher 解析前置到 Awake/Start
- **CharacterActor**：C# 子模块创建移到 base.Awake 之前
- **AnimationBrain**：图层初始化为 pre-wire、footstep 桥接为 post-wire

### 服务生命周期整顿
- **RegisterService** 从 OnWire 移至 OnAssemble（10 个 Service），保证跨模块解析顺序无关
- **NotifyServiceWired** 彻底移除，GameService 简化
- **InputService**：EnableEvent 从 OnAssemble 移回 OnEnable
- **PathfindingService**：Scan 从 OnWire 移至 OnAssemble
- **GameStateService**：初始 ApplyState 从 OnWire 移至 Start + 加 UpdateSnapshot
- **UIService**：移除失效的 snapshot 补读

### 文档
- **module-system.md**：更新至目标架构
- 删除已废弃的独立类型文档（module-behaviour / module-component / module 等）
