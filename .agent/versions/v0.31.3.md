# v0.31.3 — Pipeline State 扩展 + ref TContext 重构

## Ability Pipeline: SearchState + ExecutionState 拆分

- 新增 `SearchState`（③ 搜索命中）— 物理查询 + Debug 可视化（0.5s 停留）
- `ExecutionState` 改为仅 ⑤ 效果载荷 + 逐 hit `AbilityReactor.Resolve`
- 枚举 `EActiveAbilityState` 插入 `Search = 3`，Execution → 4
- 管线顺序调整为 Gating → Search → Cost → Execution（动作游戏范式：先确认目标再决定消耗）

## ref TContext 零拷贝架构

- `IState<TContext>` 全部方法签名改为 `ref TContext`
- `StateMachine<TContext>` Start/Tick/Interrupt/Transition 全部 `ref`
- `AbilityPipelineState` 基类（原名 `AbilityState`）— 统一 `ref SActiveAbilityContext`
- `SActiveAbilityContext` 保持 struct — 零 GC，零拷贝，链上 State 间写入直接可见

## Debug 可视化

- `SearchState` 每帧 `Debug.DrawRay/Line`（duration 0.5s）
- Cone: 黄色中心线 + 左右边缘 + 远端弧线
- Ray: 红色单线
- Circle: 青色 XZ 平面圆环
- 白色原点球体标记（确认 State 运行中）

## Bug 修复

- **SearchImportExport**: 新建资产时漏调 `ApplyFields`，导致 range/angle 全为默认值 0
- **SearchSO 资产**: `Search_Cone_Melee_Blade_Light` range 0→2, `Search_Ray_Melee_Blade_Heavy` range 0→2.5
- **CostState**: 移除抢占式的 abilityTag 挂载（冷却互斥应由 CooldownState 统一管理）

## 废弃标注

- `AbilitySearch` 标记 ⛔ DEPRECATED（逻辑已内联至 `SearchState`）
- `AbilityExecutor` OLD_IMPLEMENTATION region 标记 ⛔ 即将废弃
