# v0.11.3 — Cost 标签体系 + Effect 标签接入

2026-06-11

## 改动

- 新增 Cost 标签体系：Cost（根）+ 6 子标签（Stamina/HP/Ammo/Durability/Fuel/Charge）
- 14 个 Cost Effect .asset 的 effectTag 从空引用接入对应 Cost 子标签
- effects_all.json 所有 Cost 条目添加 effectTag 字段
- Ability_Slash / Passive_SpikeTrap 字段迁移：categoryTag→abilityTag，移除 activeTag，添加 extraExclusionTags

## 设计决策

- Cost 标签平铺在根级（与 Damage/Impact/Execute 同层），用于 Effect 路由和防御系统的消耗排除
- 标签名与 PropertyDef Id 一致（Stamina/HP/Ammo/Durability/Fuel/Charge），便于跨系统对应
