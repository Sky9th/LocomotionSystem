# v0.40.2 — GameRegistry 集中化 + 技能树获取重构

## Registry 集中化
- 新建 `GameRegistry.cs`，一个实例类持有全部 8 个 Registry（Character/Item/AbilityTree/PropertyDef/PropertyTree/AnimationProfile/GroundSystem/AudioConfig），替代 8 个 static 类
- `GameService.AssetRegistry`（DontDestroyOnLoad）持有实例，`BootAssetCatalog` 引用同步保留作为强引用根
- 7 个 BootTask 全部改为 `GameService.Instance.AssetRegistry.Init*()`
- 所有消费者（PlayerService、CharacterActor、PropertyTable、PropertyTreeSO 等）改为 `GameService.Instance.AssetRegistry.Find*()`
- 删除 8 个 standalone static Registry 文件

## 数据丢失修复
- `AddressablesService` 新增 `PinnedLabels` 集合，`"boot"` label 永不释放——场景切换时 `Release("boot")` 为 no-op
- 根因：`TransitionGate` 切换场景时释放上一个场景的 asset labels，若包含 `Boot` label 则 Addressables 卸载所有 boot 资产的 native backing

## 技能树获取重构
- `AbilityForest` 构造函数直接收 `string[] innateTreeIds`，通过 `GameRegistry.ResolveAbilityTrees()` 批量解析
- `CharacterActor` 序列化 `innateTreeIds`，Awake 直传；Start 无技能树代码
- `CharacterDefSO` 回归空壳（仅继承 PropertyPresetSO）

## 代码清理
- `BootAssetCatalog` 删除死索引 `_byType` + `BuildTypeIndex()`
- 删除孤儿类 `PrototypeArtTask`（无接口、无调用者）
- `GameRegistry.InvalidatePropertyDefs()` 删除——Editor 永远不在 Play Mode
- `PropertyTreeSO.ResolveDef`、`CharacterActor` 属性 getter 加 `?.` 空守卫
- 更新 `PropertyBootTask` / `PropertyTreeBootTask` 注释（Registry → GameRegistry）
