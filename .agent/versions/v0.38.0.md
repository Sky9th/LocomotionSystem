# v0.38.0 — DamageEffectSO 类型拆分 + SDamageInfo per-Channel 重构

## 改动摘要

伤害管线架构重构：将 DamageEffectSO 的"伤害通道"和"伤害修正"职责拆分到不同类型，SDamageInfo 从单 Amount 改为 per-channel DamageEntry[]。

## 代码

- **新建** `DamageModifierEffectSO` — 技能侧伤害修正器（targetTag + modAdd + modPercent + priority）
- **新建** `DamageEntry` — 单通道伤害数据 struct（Tag + Amount + Duration + Interval）
- `DamageEffectSO` — 移除 modAdd/modMult/priority，只保留 baseValue（实体伤害通道）
- `SDamageInfo` — Amount/EffectTags → DamageEntry[] + TotalAmount
- `ExecutionState.ComputeDamage` — 笛卡尔积 → tag 层级匹配；公式改 base × (1+Σ%) + Σadd
- `AbilityReactor.Resolve` — 遍历 Damage[]，instant/DOT 分流
- `CharacterCombat.OnResolveDamage` — hit.Amount → hit.TotalAmount
- `MatchTag` — 层级匹配，modifier 是 channel 的祖先（同级或上级）即匹配
- 删除 `AbilityEffects.cs`（deprecated，零引用）

## 资产

- 新建 19 个 DamageModifierEffectSO 资产（DamageMod_*）
- 删除 19 个旧 modifier DamageEffectSO 资产
- 实体通道资产移除 modAdd/modMult/priority 字段
- Blade.asset → MeleeWeaponSO，Pistol.asset → RangedWeaponSO
- abilities_all.json / effects_all.json 同步更新
