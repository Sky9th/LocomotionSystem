## 设计决策

| 决策 | 原因 |
|------|------|
| 物理搜索 + 数值投骰两阶段 | 近战远程走同一 Pipeline；物理检测确认前置条件，投骰决定结果 |
| ECombatSearchType (Cone/RayLine/Circle) | 不同技能不同搜索形状，同一方法签名 |
| 4.3 合并入 4.2 | 噪音消费端不是独立子系统，是敌人 AI 的感知输入通道 |
| 4.1 包含远程手枪验证 | 架构必须支持两种搜索类型，否则 Pipeline 可能退化成一堆 if-else |
