# v0.30.0 — PropertyDefSO 类型化重构

**日期**: 2026-06-30

## 改动摘要

PropertyDefSO 从 17 字段平铺 God-object 重构为 9 个类型化子类体系。

## 具体改动

### PropertyDefSO 基类瘦身
- 删除 12 个平铺字段（Min, Max, DefaultFloat, MinInt, MaxInt, DefaultInt, DefaultBool, DefaultString, DefaultAssetGUID, AssetTypeConstraint, StructTypeName, DefaultStructJson）
- 新增 `ComputeWriteValue()` virtual — 子类各自覆写类型专属解析
- 新增 `TypeMatches<T>()` virtual — Struct 类型校验
- 新增 `Create(PropertyType)` 静态工厂
- `Type` 字段加 `[HideInInspector]`

### 9 个新子类 SO
- `FloatPropertyDefSO` { Min, Max, DefaultValue } + Parse + SafeFloat
- `IntPropertyDefSO` { Min, Max, DefaultValue } + Parse + SafeInt
- `BoolPropertyDefSO` { DefaultValue } + SafeBool
- `StringPropertyDefSO` { DefaultValue }
- `RTagPropertyDefSO` { DefaultValue }
- `RTagListPropertyDefSO` { } + ParseTagArray
- `AssetRefPropertyDefSO` { DefaultAssetGUID, AssetTypeConstraint } + ResolveAssetRef + LoadAssetByGuid
- `AssetRefListPropertyDefSO` { AssetTypeConstraint } + ResolveAssetRefList
- `StructPropertyDefSO` { StructTypeName, DefaultJson } + TypeMatches + JSON wraparr

### PropertyTable 瘦身
- DoWrite: 9-case switch → Float 特殊分支 + WriteSimpleTyped 通用方法
- 6 个 helper (SafeFloat/ParseFloat/ResolveAssetRef/LoadAssetByGuid/ResolveAssetRefList/ParseTagArray) 搬到对应子类
- 删除 `OnFloatChanged` 事件（与 OnPropertyChanged 冗余）
- 新增 Min/Max 约束覆写系统（_minOverrides/_maxOverrides + EffectiveMin/EffectiveMax）
- StructTypeMismatch 简化 → 委托 `TypeMatches<T>()`

### Editor 适配
- PropertyDefSOEditor: 每个 case 加 `is` 守卫 + 字段名更新
- PropertyImportExport: PopulateDef/ReadDef helper + Create 工厂
- PropertyTreeEditorPopups: CreateDef 对话框改用子类创建

## 删除
- Data/Properties/Definitions/ (~200 旧 Def .asset)
- Data/Properties/Trees/ (~30 旧 Tree .asset)
- Type/ 文件夹（11 个临时 TypeDescriptor 文件）
