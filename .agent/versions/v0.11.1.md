# v0.11.1 — DamageEffectSO 重构 + Effect/Tag 全量重建

## 变更

- **DamageEffectSO** — `baseDamage`/`armorPenetration`/`shieldPenetration`/`minDamage`/`maxDamage` → `baseValue`/`modAdd`/`modMult`/`priority`
- **EffectSO** — 新增 `description` 字段
- **GameplayTagDefinitionSO** — 新增 `description` 字段
- **EffectImportExport** — DTO/ApplyFields 适配新 DamageEffectSO 字段 + description
- **TagImportExport** — 修复 GetDepth（按 dot 计数替代 FullTag 匹配），支持 description 读写，导出按深度排序
- **AbilityExecutor** — 旧 baseDamage 代码注释
- **旧 Stats 系统** — 全部删除
- **Tags** — JSON→资产全量重建（228 个），新增 Damage/Impact/Execute 树
- **Effects** — JSON→资产全量重建（51 个：29 Damage + 5 Impact + 3 Execute + 14 Cost）
- **Properties** — 新增 Ammo/Fuel/Charge 定义，挂入 AmmoBase/ToolBase 树

## 设计决策

- DamageEffectSO 作为装备和 Ability 的共享契约：装备填 baseValue，Ability 填 modAdd/modMult
- 同 effectTag 多个 Effect 按 priority 有序叠加
- 复杂修正走 IEffectModifier 钩子
