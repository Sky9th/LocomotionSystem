# v0.8.0 — Ability 管道小闭环

## 核心特性

- **AbilityExecutor**: 通用能力执行器，持有被动列表、门控检查（targetRequiredTag / cooldown）、目标过滤回调、效果修改回调
- **AbilityReactor**: 目标侧反应器，接收 SDamageInfo，执行 ⑥⑦⑧ 结算管道（Resolution → ApplyDamage → Reaction → OnDamaged → 广播）
- **CharacterCombat**: 战斗中枢，桥接 Ability 管道与 Character 属性系统，注入五个修改器回调
- **Trap**: 陷阱实体，通过 TargetFilterCallback 做层过滤
- **IdentityComponent (L3_Identity)**: 实体身份组件，持有身份标签
- **AbilitySO**: 主动/被动技能抽象基类

## 数据流

```
Trap.OnTriggerEnter → 门控 → 过滤 → ⑤SDamageInfo → EffectCallback
  → Player.AbilityReactor.Resolve → Endurance 减伤 → HP 扣血
  → ⑦Reaction(占位) → ⑧HitEventSO 广播 → 冷却生效
```

## Stats 重构

- 删除旧 Rule 体系（DamageRule / SprintStaminaRule / HungerDepleteRule 等）
- StatInstance.Tick → ApplyRates
- LastStats 构造时立即填充初始快照
- GameplayTag leafName 自动推导

## 事件规则

- EventHub 为事件唯一来源，Component 不得直接持有事件资产
- HitEventSO 改为 GameEvent<SDamageInfo>，删除 SHitEvent
