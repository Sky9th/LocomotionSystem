# v0.16.0 — Service Module 标准化

## 概述

L1-L2 Service 层统一 Module 树形生命周期，删除 BaseService 中间层，Service 直接继承 ModuleComponent。GameService 主动实例化 GameContext，EventDispatcher 标记废弃。

## 改动

### 架构

- **删除** `BaseService.cs`（223 行），10 个 L2 Service 直接继承 `ModuleComponent`
- **重写** `GameService.cs`：继承 `ModuleBehaviour`，主动创建 GameContext，移除 Bootstrap 手动序列
- **新增** `ModuleRegistry.Count`：供 GameService 验证全部 Service 加载完成

### Service 标准化

| Service | 改动 |
|---------|------|
| EventDispatcherService | 自注册 + `[Obsolete]` 标记 |
| SceneService | OnWire 自注册 + PublishSnapshot 私有 helper |
| TimeService | OnWire 自注册 + 解析 Dispatcher |
| GameStateService | OnWire 自注册 + 初始状态发布 |
| PlayerService | OnWire 自注册 + 解析 Dispatcher |
| CameraService | OnWire 自注册 + PublishSnapshot 私有 helper |
| InputService | OnWire 自注册 + `_assembled` 替代 `IsRegistered` |
| UIService | OnWire 自注册 + 解析 Dispatcher |
| PathfindingService | OnWire 自注册 + Log 自管理 |
| AudioManager | OnWire 自注册 |

### 时序修复

- Editor 自动加载移到全部 Service OnWire 之后，保证订阅就位
- `AnimationBrain.OnAnimatorMove`：加 `buildCtx == null` 空安全检查

## 数据流

```
GameService.OnAssemble → GameContext 创建
  └── Registry.OnAssembleAll → Service 自组装（无外部依赖）

GameService.OnWire → EventDispatcher 注册 + SGameState 订阅
  └── Registry.OnWireAll → Service.OnWire（自注册 + 解析依赖 + 事件订阅）
  ├── 验证全部 N 个 Service 加载完成
  └── Editor 自动加载场景
```
