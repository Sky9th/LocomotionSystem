# v0.9.2 — Tag Editor Phase 2 (Logic)

## 新增
- **TagTreeModel** — AssetDatabase 扫描真实标签资产，parent 引用建树，Search/MissingAncestors
- **TagCreator** — 事务式链创建（目录+残留清理+StartAssetEditing），失败逆序回滚
- **TagNode** — 独立节点类，TagTreeView 和 TagTreeModel 共用
- **TagEditorWindow** — Create/Delete 按钮接线，引用检查，搜索过滤
  - 工具栏 `＋ Create Tag` → 创建根标签
  - 每行 `＋` 按钮 → 创建子标签
  - 删除前检查外部引用 + 子标签级联确认
- **TagPicker** — 搜索无匹配时弹出 Create 卡片，一键创建新标签
- **TagTreeView** — 搜索时隐藏不匹配节点+卡片，叶子显示 `–` 占位保持对齐
