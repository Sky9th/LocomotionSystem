# v0.9.1 — Tag Editor Phase 1 (UI)

## 新增
- **TagEditorWindow** — 独立标签管理窗口 (`Tools/RedDust/Tag Editor`)
  - StatsTree 卡片风格布局：Header + Toolbar + Search + 左 Tree/右 Inspector + StatusBar
  - 硬编码 Damage 标签假数据验证 UI 交互
  - Inspector：已有标签显示详情，未创建标签显示创建表单
  - 状态栏：现有/缺失标签计数
- **TagTreeView** — 共享树渲染器
  - StatsTree 嵌套 BeginHorizontal/Vertical 布局，折叠/展开固定宽度不跳变
  - 已有标签正常字重，未创建加粗灰显，选中加粗
- **TagPicker** — 可嵌入 PopupWindowContent
  - `Show(rect, rootFilter, allowCreate, onSelected)` 静态入口
  - 搜索匹配 + 树浏览双模式
  - `Tools/RedDust/Tag Picker (Test)` 测试入口

## 清理
- 删除 `Assets/Data/Core/Tags/` 旧标签目录（标签已迁移至 `Assets/Data/Tags/`）

## 技术决策
- 标签编辑器放 `L1_Core/GameplayTag/Editor/`，跟随代码位置
- UI 严格参照 StatsTreeEditorWindow 的 pad=6f + helpBox 卡片 + 嵌套布局模式
- 字体统一 label 级别，废弃 miniLabel
- 后续 Phase 2 将接入 TagTreeModel（AssetDatabase 扫描）+ TagCreator（事务式链创建）
