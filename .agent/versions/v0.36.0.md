# v0.36.0 — Entity.Command/Query 全量落地

## 核心改动

- **删除 CharacterContainer** — 身体槽位统一走 `entity.NestedContainer`（EntityService.Register 时创建）
- **Entity.Query 惰性自解析** — Equipment / Inventory / Ability 全部从 Entity 自身数据解析，零外部接线
- **Entity.Command 收敛** — +Place/Remove，CycleEquip/UseActiveAbility 改用 Query.Equipment
- **全局去 Actor 穿透** — PlayerService/UIService/AbilityBar/WeaponBar/DebugOverlay 全部改用 Entity.Query/Command
- **RdContainer 重命名** — `Container.Container` → `Container.RdContainer`
- **SPlayerSpawnedEvent** — L1 Entity → entityId 解耦
- **Identity +Entity 引用** — L3 模块可直接访问实体数据
- **Entity.CommonTagsPath** — 消除 `"Common/Tags"` 魔术字符串
