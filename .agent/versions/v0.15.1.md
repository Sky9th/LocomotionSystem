# v0.15.1 — Character ctx 贯彻 + ModuleComponent Awake 自注册

## 改动

- **CharacterBuildContext**: 从 10 字段扩展到 22 字段，补充 animation/audio config、5×AvatarMask、3×root motion flags
- **CharacterActor.OnAssemble**: 传全部 config 到 BuildCtx，NpcDirector 补 ctx
- **AnimationBrain**: `_actor` 引用替换为从 BuildCtx 读取；图层初始化移入 OnWire；Awake 装配 Drivers
- **LocomotionDriver/TraversalDriver/CharacterAudio**: 从 `brain.BuildContext` 取 config，消除 `GetComponent<CharacterActor>()` 上行引用
- **BaseAnimationDriver**: OnWire 补注册到 DriverArbiter，解决 Awake 阶段 arbiter 未就位的时序问题
- **ModuleComponent**: 新增 Awake 自注册到父 Registry，动态 AddComponent 的子模块自动走生命周期
- **NpcDirector**: 构造签补 ctx

## 数据流

```
CharacterActor.OnAssemble → BuildCtx (22字段)
AnimationBrain.OnWire → self-fetch BuildCtx → 图层 + Drivers
  LocomotionDriver.OnWire → brain.BuildContext → BaseLayer
  TraversalDriver.Evaluate → brain.BuildContext.AnimationAlias
  CharacterAudio.Config → brain.BuildContext.AudioConfig
```
