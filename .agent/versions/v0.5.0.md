# v0.5.0 — L4_Locomotion 目录重组 & MotionSpeedScale 架构重构

## 目录结构

- `L4_Locomotion/` 新增 `Config/`、`Ground/` 子文件夹
- `LocomotionProfile.cs` → `Config/`
- `GroundLocomotion.cs`、`Motor.cs`、`Stance.cs` → `Ground/`
- 按实现分组：接口在根，实现在 Ground/

## MotionSpeedScale 概念

- 新增 `SCharacterDiscrete.MotionSpeedScale` — 有效速度/步态速度比值
- 新增 `SCharacterDiscrete.EffectiveMaxSpeed` — gaitSpeed × scale 最终值
- 由 Stance 内部计算并缓存（gait/posture 变化时重算）
- 数据流：Locomotion → Pathfinding（而非反向）
- 基础比值 = `gaitSpeed / animNativeSpeed`，取自 `LocomotionProfile` + `LocomotionAnimationProfile`

## 数据流简化

- `CharacterFrameContext` 承载 `LocomotionProfile` + `LocomotionAnimationProfile`
- `CharacterActor` 两个 Profile 均设为 Inspector 序列化字段
- `PathfindingAgent` 精简为单一入口 `SyncLocomotion(in SCharacterDiscrete)`
- 删除 `PathfindingAgent` 中的 `locomotionProfile`、`currentGait`、`UpdateGaitSpeed`、`DesiredSpeedMultiplier`、`ApplyMotionScale`
- `AnimationBrain.ApplySpeedMultiplier` 简化为直接读取 `ctx.Discrete.MotionSpeedScale`
- 删除 `AnimationBrain.GetMotionSpeedScale`
- 删除 `SCharacterIntent.MovementSpeedMultiplier`
- 删除 `PlayerDirector.ComputeSpeedMultiplier`
- 删除 `CharacterActor.PlanarSpeed` 死代码
