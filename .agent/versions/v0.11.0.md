# v0.11.0 — Properties 消费层

## 新增

- **EntityDefSO** — 实体定义抽象基类，绑定 PropertyTreeSO + OverridesJson
- **EntityProperties** — 单实例属性表，静态工厂 Create()，统一类型分发 DoWrite，Set/Modify/Load/Guard/Tick/Snapshot/事件
- **PropertyComponent** — MonoBehaviour 门面，挂 GameObject，其他子系统通过 GetComponent 获取
- **FloatState** — Float 运行时引擎（Tick/Modify/钳制/事件），按频率分桶管理 Modifier
- **FloatModifier** + **RateContext** — 持久帧级修改器，A/B/C 三类，预设 PerFrame/PerSecond/PerMinute/Custom 频率

## 删除

- **ResolvedPropertyBag** — 解析逻辑融入 EntityProperties 构造

## 设计决策

- Schema 值永远不直接读——构造时一次性全解析
- PropertyComponent 是唯一门面——外部不接触 EntityProperties/EntityDefSO/PropertyTreeSO
- 伴生属性推断暂不做——行为模型入口留白，待后续设计
- FloatState 按频率分桶 + 共享计时器——PerFrame 零计时开销，PerSecond/Minute 无 modifier 时不计时
