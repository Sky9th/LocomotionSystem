# v0.35.0 — Command/Query 架构 + Director 消除

## 概述

引入 Entity.Command / Entity.Query 双门面架构，消除 Director 模块，SCharacterIntent 拆解分布到各子模块，PlayerService 重构为输入→命令翻译层。

## 改动

### 架构
- **新建** EntityCommandModule — 命令门面，外部系统通过 Entity 下达命令
- **新建** EntityQueryModule + VitalsQuery + InventoryQuery + EquipmentQuery — 查询门面，数据查询无需 GO
- **新建** SCharacterInputState — 外部系统每帧写入的连续输入面板
- **新建** AIService — AI 服务存根，替代已删除的 NpcDirector

### 消除
- 删除 Director/ 目录及全部内容（ICharacterDirector, PlayerDirector, PlayerInput, NpcDirector, SCharacterIntent）
- 删除 CameraSnapshotEvent — 连续帧数据改走 GameContext
- SCharacterIntent 拆解分布到 CharacterKinematic（heading/aim）、GroundLocomotion（gait）、Motor（velocity override）、Stance（posture）

### 重构
- CharacterActor — 字段重组，暴露子模块（Pathfinding/Ability/Container），InputState
- PlayerService — BindInput<T> 泛型绑定，输入事件直接调 Command
- Namespace 重组：CharacterRig → Kinematic，Structs 统一到 L3_Character/Structs/
- Animation 驱动类 public → internal
- CharacterFrameContext → SCharacterFrameContext
- PathfindingAgent 新增 HasActivePath 属性

### 简化
- hasActivePath 重复消除（PathfindingAgent.HasActivePath）
- UnsubscribeInputEvents 死代码删除
- null-conditional 优化（animSet?.GetNativeSpeed ?? 0f）
- GroundLocomotion/Stance 移除冗余缓存字段
