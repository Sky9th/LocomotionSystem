# v0.36.4

## 改动

- `AnimationRequest` 新增 `EDriverType` 枚举、`DriverType` 字段、`CustomData`、`OnMarker`/`OnCompleted`/`OnInterrupt` 回调
- `AbilityDriver` 回归纯 `ICharacterAnimationDriver` 实现，移除 `SubmitAbility`，`OnStarted` 注入 Animancer 事件并调回调
- `AnimationBrain` 新增 `SubmitRequest(request)` 重载（按 DriverType 路由），`Release()` 无需传 Driver 参数
- `DriverArbiter` 删除 `Release(driver)`，新增 `ReleaseActive()`

## 设计

动画侧改动：回调注入 AnimationRequest，Brain 零感知。外部通过 Brain 门面提交请求、释放动画，不持有 Driver 引用。
