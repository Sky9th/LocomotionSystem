# v0.38.5 — Ability 旧代码全量清理

## 背景
Ability Pipeline 8 State 已在 v0.38.0-v0.38.4 全量接管技能执行。`AbilityExecutor.cs` 中的 `#region OLD_IMPLEMENTATION`（328 行）混有死代码和活跃基础设施，旧 `TryActivate`、`ExecutePassive`、`AbilitySearch`、`SearchState` 等已无调用者。

## 改动

### AbilityExecutor.cs
- 删除 `#region OLD_IMPLEMENTATION`（~328 行）
- 14 个死成员删除：`initialPassives`、`runtimePassives`、`_search`、`Awake()`、`TargetFilterCallback`、`PassTargetRequiredTag()`、`PassCooldown()`、`ApplyCooldown()`、`ExecutePassive()`、`ApplyEffects()`（被动重载）、`AddPassive()`/`RemovePassive()`、`TryActivate()`、`ApplyBuff()`
- 15 个活跃成员提升至类主体：`OwnedTags`、5 个回调委托、冷却系统字段/方法、`OnTriggerEnter`/`OnTriggerExit`

### 删除文件
- `Executor/AbilitySearch.cs` + `.meta` — 物理查询已内联至 ExecutionState
- `Executor/State/SearchState.cs` + `.meta` — 不在当前管道链中

### 枚举清理
- `EActiveAbilityState.Search = 3` 移除

### 附带清理
- `Trap.cs` — 移除 `TargetFilterCallback` 赋值 + `ShouldTrigger()` + 死字段 `targetLayers`
- `PassiveAbilitySO.cs` — 更新过时 tooltip
- `ExecutionState.cs` — 清理过期注释和 region 标记
