# v0.36.10 — 受击反应管线 (Hit Reaction Pipeline)

## 概述

完成受击动画消费链路：Ability (L3) → Character (L3) → Animation (L4) → Drivers (L5)。
伤害携带冲击数据 → Combat 判定受击等级 → Animation 仲裁播放 → Impact Knockdown 起身链。

## 设计决策

- 受击等级由 `ImpactEffectSO.reactionLevel` 资产决定（Flinch/Stagger/Knockdown）
- 无霸体判定：有 ImpactEffect 即受击（TODO: PropertyTable 霸体值）
- 抢占规则硬编码：HitReaction > 一切，Traversal↔Ability 互斥
- Impact Knockdown → `OnCompleted` 链式提交起身；HP≤0 死亡播放倒地位移但不起身
- FadeIn 由 AnimationRequest 控制：Play 前临时覆写 MixerTransition2D.FadeDuration
- 死亡系统（Ragdoll + EventHub）预留，后续 task 单独实现
