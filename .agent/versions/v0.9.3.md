# v0.9.3 — Ability Editor Phase 1

## New
- **AbilityEditorWindow**: 左中右三栏布局，左侧 Ability 树（categoryTag 分组），中间属性编辑，右侧子资产 Picker
- **EditorUIUtility**: 统一卡片函数 `DrawCard` / `CardGap`，`LabelWithTooltip` 工具提示
- **AbilityTreeView**: Tag 树组织的技能列表 + Effect 树组织的效果浏览器

## Changed
- `categoryTag` 从 AbilityDefSO 提升至 AbilitySO 基类，PassiveAbilitySO 也拥有分类标签
- `Definitions/` 目录重命名为 `Actives/`
- `editor-ui-patterns.md` 全面更新为 DrawCard 统一规范
