# v0.7.1 — Combat → Ability 全量重命名

> 2026-06-05 · 模块独立化 · 三 Agent 交叉审查

## 变更

### 模块提取
- `L3_Character/Combat/` → `L3_Ability/` — 独立模块，角色和陷阱通用
- 命名空间 `RedDust.Character.Combat` → `RedDust.Ability`
- AbilityComponent 改为 MonoBehaviour（挂 Prefab 上）

### 类重命名
- SkillDefSO → AbilityDefSO
- SkillActivationSO → AbilityActivationSO
- SkillSearchSO → AbilitySearchSO
- PassiveSkillSO → PassiveAbilitySO
- GameplayEffectSO → EffectSO
- CooldownEffectSO → CooldownRuleSO
- CombatComponent → AbilityComponent

### 枚举重命名 + 移入 Enum/
- ECombatSearchType → ESearchType
- ESkillPhase → EAbilityPhase
- ESkillAnimationLayer → EAbilityAnimationLayer
- ESkillEventType → EAbilityEventType
- EKnockbackDir → EKnockbackDirection
- ETriggerEvent 新增 None=0，OnKill=1

### Struct 重命名
- ComboLink → SComboLink (+ S-前缀, 字段 PascalCase)
- SSkillEvent → SAbilityEvent

### 字段重命名
- skillName → internalName
- selfTag → activeTag
- triggerParam → triggerValue
- CooldownRuleSO.duration → cooldownDuration
- SNoiseEvent.Source → SourceObject

### 删除空目录
- Drivers/, Runtime/ — 实现时再建
