# v0.14.2 — EUI FormItem 架构重构 + 样式修正

## 改动

### EditorFormItem — 单一渲染入口
- 新增 `Draw(label, drawSlot)` 作为唯一渲染入口：左列固定宽 + Label + 右边距 + Slot 右
- 删除 `DrawReflected`、`DrawInput`、`FieldType` enum
- Float/Int/Toggle/ObjectField/Enum/TextField/Slider 全部走 `Draw`
- `RawField` 走 `Draw`，getValue/drawFunc 在 slot 内执行
- `ObjectFieldWithTag` 走 `Draw`（ref → local 桥接）
- `ArrayField` 走 `Draw`：label "[N]" 在左列，数组行在右列
- `BeginRow()` 统一 spacing + _itemIndex++ 管理

### 布局特性
- 左列 `BeginVertical(GUILayout.Width(w))` 固定宽，Label 占整行
- 水平组内 `MaxWidth(w * 2.5)` + 右边距，避免大空位
- 垂直布局每 FormItem 后自动 `EditorDivider.Draw()`
- 水平组内跳过 Divider

### EditorLabel — 默认样式
- 新增 `DefaultStyle`：基于 `EditorStyles.label`，左右 padding/margin 清零
- 去掉 `GUILayout.Height` 高度约束

### Button — 外边距清零
- `GetStyle` 新增 `margin = RectOffset(0, 0, ...)`，左右外边距清零

### EffectEditorWindow
- `DrawBlockedTags` 删除，替换为 `EditorFormItem.ArrayField<GameplayTagDefinitionSO>`
- label 改为中文可读：Blocked Tags / Granted Tags / Float Adjuncts
- 新增 tooltip（中文）
- 移除所有 `form.DefaultLabelWidth = xxx` 手动设置，统一默认值
