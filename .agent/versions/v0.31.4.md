# v0.31.4 — Pipeline 全 8 State 就位 + 动画链序修正

## 新增 State

- `ActivationState` — ③ 动画激活（Windup 前摇），TODO: windupDuration / animationSpeed 计时
- `CooldownState` — ⑦ 冷却施加，从 Activation 入口开始与 Fire+Recovery 重叠
- `RecoveryState` — ⑧ 后摇等待，TODO: recoveryDuration / animationSpeed 除法

## 链序修正

```
Gating → Search → Cost → Activation → Cooldown → Execution → Recovery → Completed
  ②       ④       ⑤        ③          ⑦          ⑥          ⑧
```

- Cooldown 移至 Activation 后（commit 点冷即开始时，与动画重叠）
- Recovery 移至 Execution 后（动画收尾段的自然位置）
- Activation → Cooldown（不再直连 Execution）

## 功能变更

- `AbilityExecutor.StartCooldown(ability, overrideDuration)` — 覆写冷却时长参数
- `AbilityExecutor.Enqueue` — Pipeline 运行中替换排队位，防止技能积压
- `ExecutionState` — `AbilityEffects` 内联为 private static 方法；`AbilityEffects.cs` 标记 DEPRECATED
- `SearchState` — fireWindow 每帧累加 TODO 标注
- `AbilityActivationSO` — 新增 `recoveryDuration` 字段（设计师手动设置）
