# v0.20.0

## 概览

Grip 切换运行时链路打通 + 动画资产重组 + 攀爬动画修复。

## 变更

### Grip 切换链路
- `LocomotionAnimationSetSO` + `HasFullLocomotion` — 区分 full/partial grip
- `CharacterActor.Update()` — director 之后 resolve grip，传入 Simulate
- `LocomotionDriver.Evaluate()` — 检测 grip 变化，full 换 BaseLayer.AnimSet，partial 走 Arm 层覆盖
- `AnimationBrain` + `ArmLayer` (index 2) — 武器 idle 仅覆盖手臂
- `PlayerDirector` debug 1/2/3 键切换 grip
- `GroundLocomotion` / `ILocomotionSimulator` — animSet 参数替代 DefaultLocomotionSet
- `BaseLayer.AnimSet` — `private set` → `set`

### 动画资产重组
- 新目录结构: `1H_Sidearm/` + `1H_Blade/` → Locomotion → Relax/Combat → SO 字段名
- 4 套 locomotion set: Sidearm Relax/Combat, Blade Relax/Combat
- `Human.json` 更新: 5 个 locomotionSets + 新 gripTable 映射
- `tags_all.json`: `Equip.Grip.Pistol` → `1H_Sidearm`, `Knife` → `1H_Blade`
- `CharacterAnimationProfileSO` 移到 `Human/` 根目录

### 修复
- `TraversalAnimationSetSO`: `StringAsset` → `ClipTransition`
- `AnimationImportExport`: TraversalSet 导入/导出适配 ClipTransition
- `animancerTransitions` 字段从 CharacterActor 删除
- 攀爬动画导入并挂载

### 文档
- `animation-mapping.md` 更新
- 施工历史记录到长期计划
