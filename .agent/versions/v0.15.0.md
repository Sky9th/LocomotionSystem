# v0.15.0 — Module 系统 + Character 树形生命周期

## 新功能

- **L1 Module 系统**: ModuleRegistry, Module, ModuleBehaviour, ModuleComponent — 树形生命周期统一链路
- **CharacterBuildContext**: 所有 Character 子模块统一依赖入口
- **IInitializable 协议**: 递归树初始化 (OnAssemble + OnWire)
- **AnimationBrain 升格为 ModuleBehaviour**: 拥有子模块 (LocomotionDriver, TraversalDriver)，Footstep 事件对外暴露

## 重构

- CharacterActor 继承 ModuleBehaviour，零手动样板
- 所有 C# 子模块继承 Module（构造自注册）
- 所有 MB 子模块继承 ModuleComponent（自动发现父注册）
- PlayerDirector ctx 替代 owner/this 反查
- CharacterAudio 通过 AnimationBrain.OnFootstep 事件订阅，消除跨级引用

## 修复

- AnimationBrain 图层初始化移到 OnAssemble（解决 NamedAnimancerComponent 延迟添加时序）
- LocomotionDriver BaseLayer 创建移到 OnWire（等 AnimationBrain.OnAssemble 完成）
- CharacterCombat 加 UnsubscribeEvents（OnDestroy 清理）
- TraversalDriver 沿用 BaseAnimationDriver
