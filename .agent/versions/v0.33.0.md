# v0.33.0 — EventDispatcher → EventHub 架构迁移

## 背景

`EventDispatcherService`（泛型事件总线 + MetaStruct）自项目早期遗留下来，存在死信事件（如 `SIActionWorldSpeed`）、发布方/订阅方难以追踪、事件散落各处等问题。

本次将全量 L1/L2 服务迁移至 `EventHub` + `GameEvent<T>` SO 通道体系，彻底删除 `EventDispatcherService`。

## 改动

### EventSO 收归
- 32 个 `GameEvent<T>` SO 类统一收至 `L1_Core/Events/`，按域分子目录（GameState/Scene/Player/Input/Ability）
- 类名统一 `{Category}+{Name}+Event`（如 `InputJumpEvent`、`GameStateChangedEvent`）
- `CreateAssetMenu` menuName/fileName 统一规范
- 32 个 `.asset` 同步创建在 `Data/Events/`

### EventHub 重构
- 单 `GameEvent[] channels` → 5 个分组数组（`gameStateEvents`/`sceneEvents`/`playerEvents`/`inputEvents`/`abilityEvents`）
- 重复 channel 类型自动报 `LogError`
- 注册权收回 `GameService.Start()`，不再依赖执行顺序

### 服务迁移（10 个 .cs + 1 Prefab）
- SceneService、GameStateService、PlayerService、CameraService、UIService、GameService、TimeService、PlayerInput、PathfindingService 全部从 `EventDispatcherService` 迁移至 `EventHub`
- MetaStruct 参数从所有 handler 签名中移除
- `EventDispatcherService.cs` 删除
- `GameContext.HasService()` 删除

### 命名修正
- GameState: `GameStateChangedEvent` / `GameStateChangeRequestEvent`
- Scene: `SceneLoadRequestEvent` 等（统一 Scene 前缀）
- Input: `InputJumpEvent` 等（统一 Input 前缀）
- `ThridInteract` → `ThirdInteract`（修正 typo）

## 新增
- `CameraSnapshotEvent` — 替代 `SCameraSnapshot` 的 Dispatcher 路径
- `SceneReloadRequestEvent` — 死信，无发布方，保留

## 删除
- `EventDispatcherService`（含 `EventDispatcher` GameObject on GameManager.prefab）
- `SIActionWorldSpeed`（死信）
