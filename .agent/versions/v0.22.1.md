# v0.22.1 — Character 模块生命周期修复 + 职责边界文档化

## 概述

修复 Character 模块中 8 处生命周期合约违规，并在代码和文档中明确各阶段的职责边界。

## 改动

### Character 模块修复
- **BaseAnimationDriver**: OnEnable/OnDisable 清空，OnDestroy 新增 `brain?.UnregisterDriver`
- **LocomotionDriver**: 删除空 OnEnable/OnAssemble + OnWire 中重复的 GetComponent
- **CharacterAudio**: brain 引用移到 OnAssemble，OnDestroy 新增取消 OnFootstep 订阅
- **CharacterCombat**: 7 个 Ability/Reactor 回调从 OnAssemble 移到 OnWire
- **PathfindingAgent**: Teleport 从 OnWire 移到 OnAssemble
- **AnimationBrain**: 显式 `: ModuleHub, IModuleChild`，自注册到父 Hub，图层初始化从 Start 移到 OnWire

### 职责边界文档化
- **IModuleChild**: 接口注释添加 OnAssemble/OnWire/OnEnable/OnDisable/OnDestroy 职责边界
- **ModuleHub**: 添加 Awake/Start 的 pre/post 模式注释
- **ModuleChildMono**: 添加各阶段职责速查注释
- **module-lifecycle.md**: 新增完整阶段职责边界表（含 Awake）
- **lifecycle-audit.md**: Character 模块逐阶段审计表
