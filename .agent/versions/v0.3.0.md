# v0.3.0 — Director Layer & HeadLook Fix

## Director Layer (L4_Director)

- add `ICharacterDirector` interface with single `Evaluate()` method returning `SCharacterIntent`
- add `SCharacterIntent` struct carrying resolved intent: `LocomotionHeading`, `AimDirection`, `DesiredGait`, `DesiredPosture`, `JumpRequested`
- add `PlayerDirector` implementing `ICharacterDirector`, translating raw player input into intent
- add `PlayerInputReceiver` handling event subscription and caching for player input
- add `AI/` directory placeholder for future behavior-tree director
- delete `CharacterEventReceiver.cs`, `SCharacterInputActions.cs`, `Input/` directory

## HeadLook Fix

- separate `locomotionHeading` and `aimDirection` in `CharacterKinematic.Evaluate()`
- feed `aimDirection` into `CharacterHeadLook.Evaluate()` instead of `actorTransform.forward`

## Locomotion Refactor

- switch `Motor.Evaluate()` from `SCharacterInputActions` to `SCharacterIntent`
- switch `Stance.Evaluate()` from `SCharacterInputActions` to `SCharacterIntent`
- remove gait/posture toggle state machine from Stance (migrated to PlayerDirector)
- add `SCharacterIntent` parameter to `ILocomotionSimulator.Simulate()`
- replace `CharacterFrameContext.Input` with `CharacterFrameContext.Intent`

## Scene Loading Fix

- add `SReloadSceneRequest` event for forced scene reload
- add idempotent guard in `SceneService.LoadContentScene()` to skip already-loaded scenes
