# v0.14.0 — EUI 架构重构

## 设计标准

- **组件 = Slot + 回调，组件间零耦合** — 每个组件只提供布局容器，内容全由调用方通过回调注入
- **Slot vs 变体** — 内容不可预知用 `Action drawSlot`，可预知用命名变体（`TextFieldWithClear` 等）
- **组合组件只编排子组件** — 上层组件不裸调 `GUILayout`，全委托子组件
- **风格令牌与 Helper 分离** — `EditorTokens`（纯数据）vs `EditorUIUtility`（GreyPlaceholder）

## 组件重构

- **EditorButton** — 类型入口 API（`Primary()`/`Danger()`/...）+ `Delete()`，移除 `EditorButtonStyle` 枚举
- **EditorForm** — 回调模式（`EditorForm.Draw(target, form => { ... })`），移除 `NeedsRebuild`/`Draw`
- **EditorFormItem** — 静态拼装 `EditorLabel` + `EditorInput`，变更走 `f.NotifyFieldChanged`
- **EditorInput** — 纯 Input + 变体（`TextFieldWithClear`、`ObjectFieldWithTagPicker`）
- **EditorLabel** — 纯 Label，`trailingGap` 从 `Pad` 推导
- **EditorTokens** — 设计令牌：`Pad`/`PadTight`/`Font`/`Padding`/`Color`
- **FormItemGroup** — 布局包装 `Draw(Horizontal, () => {...})`
- **EditorDivider** — 分隔线组件

## 组件清理

- **EditorSearchBar** — 重构为组合组件（`EditorLabel` + `EditorInput.TextFieldWithClear`）
- **EditorUIUtility** — 剥离全部薄委托和令牌，仅留 `GreyPlaceholder`
- **Card.cs** — `DrawWithHeader`、折叠按钮改用 `EditorButton`

## EffectEditor

- BuffEffectSO 编辑支持（grantedTags + adjuncts ArrayField）
- Filter/Create/StatusBar 补齐 Buff 类型
- 控件迁移至 `EditorFormItem.ObjectFieldWithTag`

## 迁移

所有 EditorWindow（Effect/Ability/Search/Activation/Noise/PropertyTree）从旧 EditorForm API 迁至回调模式
