# v0.6.6 — Stats Tree Editor (JSON) 基础框架

## 新增
- **StatsTreeData**: 新 JSON 驱动 Stat 树 ScriptableObject，替代 StatsTreeSO/StatsNodeSO
- **JsonStatNode / TreeDataContainer**: JSON 序列化数据结构
- **StatsTreeEditorWindow**: 新 EditorWindow，partial class 架构，支持 Header/Toolbar/Body + ScrollView
- **Editor UI Patterns 文档**: 项目级 IMGUI 编辑器规范（卡片系统、间距规则、布局模式、按钮规范）

## 功能
- Header: Tree 选择 + InheritsFrom 编辑 + Save 按钮
- Toolbar: + Folder 按钮 + 全部展开/收起
- Body: 树形卡片渲染（文件夹 + 叶节点），折叠/展开，深度标记
- 增删节点（延迟删除队列避免 layout 错乱）
- Save/Load: JSON 序列化/反序列化，Def 索引同步
- 继承链: CollectInheritedNodes 递归收集父类 JSON，myDepth 计算

## 变更
- 旧版 L4 文档 (definition/instance/interfaces/modifier/tree) 迁移至 stats 子文档
- StatsTreeSO 文档归档为旧版
- Editor UI Patterns 置于 shared/editor/
