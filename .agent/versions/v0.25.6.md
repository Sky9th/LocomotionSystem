# v0.25.6 — Event 系统统一

> 2026-06-27

## 重构

- 删除 `EventChannelBase`（OnRaised 拉模式根）
- 删除 `InputEventBase`（InputAction 生命周期混入 SO）
- 删除 `ButtonInputEventSO` / `Vector2InputEventSO` / `FloatInputEventSO`（中间空壳）
- `GameEvent<T>` 成为唯一事件通道，非泛型 `GameEvent` 做类型标记
- 21 叶子 SO 直继 `GameEvent<T>`
- `InputService` 重写：`InputActionAsset` + `GameEvent[]` 名字匹配自动绑定
- `PlayerInput` / `GameStateService` 订阅改造：`OnRaised +=` → `Register(Action<T>)`
- 新增 `SButtonInputPayload` / `SVector2InputPayload` / `SFloatInputPayload`
- `EventHub` / `PassiveAbilitySO` / Editor 引用类型收窄为 `GameEvent`
