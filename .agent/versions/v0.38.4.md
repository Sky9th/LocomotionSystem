# v0.38.4 — 管道动画修复 + 激活资产补全

## 改动摘要

修复狂按技能键导致管道卡死的两个根因：
- DriverArbiter 拒绝同类型请求时清空队列 → 改为不清、下帧重试
- AbilityDriver 复用同一 AnimationClip 时旧事件残留 → OnStarted 先 Clear 再 Add
- Animancer state.Time=0 后同帧 CheckCompletion 读到旧 NormalizedTime → 加 skip 标记

补全 10 个 Activation 资产的 recoveryDuration（从 clip 帧数推算）及 Editor Import/Export 支持。

WindupState/RecoveryState 非正常流程加 Warning 诊断日志。
