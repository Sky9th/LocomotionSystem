# v0.33.1 — WeaponAttachPoint Soft Wave + CharacterConst 全局常量收敛

## 新增

### WeaponAttachPoint — 武器附着点 Soft Wave
- `L3_Character/Equipment/WeaponAttachPoint.cs` — 纯 C# 静态类
- 按 `(slotKey, gripTag)` 查表获取 local-space offset
- 在骨骼下创建 `_EquipSocket_{slotKey}` GO 承载偏移
- 武器作为 Socket 子对象挂载，同槽换武器时 Socket 复用

### CharacterConst — Character 模块全局常量
- `L3_Character/Actor/CharacterConst.cs`
- `PropertyPath` — PropertyTree 路径（CommonTags, Slots, Vitals, Attributes, Movement, Body）
- `Slot` — 槽位 ID（RightHand, LeftHand, Head, Chest, Back 等 9 个 + ContainerSlot）
- `GripTag` — 握持标签（OneHanded, Pistol2H），对齐 rTagDefSO 的 FullTag
