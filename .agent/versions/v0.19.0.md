# v0.19.0

## 概览

角色物理配置重构：消除 Profile SO 冗余层，统一接入 Properties 属性系统。

## 变更

### 删除
- `CharacterPhysicsProfileSO` — 纯容器包装层，不再需要
- `LocomotionProfileSO` — 12 姿势速度矩阵冗余（基础速度由 `LocomotionAnimationSetSO.animNativeSpeed` 定义），acceleration 进 Properties
- `KinematicProfileSO` — 8 个系统字段 → `GroundSystemConfigSO`，7 个角色属性 → Properties / `CharacterPhysique`

### 新建
- `GroundSystemConfigSO` — 地面探测/锁地/LayerMask 等 8 个世界级参数
- `CharacterPhysique` — 9 字段 struct，Init 时从 `PropertyAgent` 读一次，hot path 零开销
- `properties_all.json` +9 PropertyDef（`Movement/`: Acceleration, MaxSlopeAngle; `Body/`: Height, ObstacleProbe*, MaxHeadYaw/Pitch）
- Human 树新增 `Body/` 文件夹

### 修改
- `Motor` — `LocomotionProfileSO` → `float desiredSpeed, float acceleration`
- `Stance` — 转向阈值硬编码（65°/5°），速度从 `LocomotionAnimationSetSO.GetNativeSpeed(gait)` 读取
- `CharacterKinematic` — `ctx.KinematicProfile` → `ctx.Physique` + `ctx.GroundSystemConfig`
- `CharacterHeadLook` — `KinematicProfileSO` → `float maxHeadYaw, float maxHeadPitch`
- `BaseLayer` / `LocomotionDriver` — 删除 `LocoProfile` 依赖
- `BuildContext` — `LocomotionProfile + KinematicProfile` → `Physique` struct

## 架构影响

```
之前:  CharacterActor → CharacterPhysicsProfileSO
                            ├─ LocomotionProfileSO (13 字段)
                            └─ KinematicProfileSO   (17 字段)

之后:  CharacterActor → PropertyAgent (Properties)
                            ├─ CharacterPhysique (9 字段, init 缓存)
                            └─ GroundSystemConfigSO (8 字段, 世界级)
```
