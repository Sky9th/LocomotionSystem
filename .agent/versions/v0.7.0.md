> 2026-06-05 · 16 类属性 → 15 类已覆盖

## 架构

SkillDefSO 从平铺 25+ 字段拆分为资产组合：

```
SkillDefSO
  Identity:       skillName, displayName, icon, description, categoryTag
  Activation:     → SkillActivationSO (12字段: 激活方式+动画+阶段标记+取消规则)
  Search:         → SkillSearchSO + 3子类 (Cone/Ray/Circle)
  Effects:        targetEffects[], selfEffects[] → GameplayEffectSO 体系
  Cooldown:       → CooldownEffectSO (独立类型)
  Noise:          → NoiseEventSO (独立类型)
  Gating:         selfTag + TagMutualExclusionSO + overrideExclusion
  Combo:          ComboLink[]
```

## 删除

- WeaponSkillSetSO — 角色层职责
- NoiseEffectSO (旧) — 噪音不是效果
- SkillDefSO 旧字段: staminaCost, damageMultiplier, noiseLevel, noiseType, damageType, canKill, comboNextSlots 等

## 设计原则

- 动画=阶段机时间轴, animationSpeed=唯一调参旋钮
- 所有效果统一 GE 管道 (Damage/Impact/Execute/Cost)
- 伤害类型=世界常数 (Tag_Damage_Fire=共享资产)
- effectTag=效果身份, grantedTag=施加标签
- 标签互斥集中管理 (父标签下子标签自动互斥)
- 被动技能=事件→条件→效果 (枚举+可选 Channel)
- 连招=ComboLink 串联, 无槽位
