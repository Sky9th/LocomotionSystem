# v0.10.1 — Property 卡片拖拽排序

## 改动

### PropertyTreeEditorWindow
- feat: 属性卡片拖拽排序 — 同文件夹内 + 跨文件夹
- feat: 拖拽时浮动卡片跟随鼠标
- feat: 蓝色指示线显示插入位置
- feat: 全局最优匹配算法 — 所有文件夹评估距离，最近的胜出
- fix: SortTreeNodes 按 _ownNodes 顺序排，不再字母覆盖拖拽结果

### 技术细节
- 拖起: MouseDrag → PrepareStartDrag + StartDrag
- 拖中: DragUpdated → 计算距离 → 记录最近文件夹
- 放下: DragPerform → AcceptDrag + ReorderLeaf（treeJson 持久化）
- 取消: DragExited → CleanupDrag 恢复原位
- 浮动卡片: GUI.Box 半透明覆盖 + 跳过被拖卡片
