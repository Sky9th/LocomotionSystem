# v0.41.0 — Entity 分类四层架构对齐

## 概述

Entity 分类体系的 Tag 树、PropertyTree、SO 类层级、Data 目录四层统一对齐。

## 核心变更

### Tag 树重构
- `Entity.Weapon/*` + `Entity.Item/*` → `Entity.Equipment/*` / `Entity.Ammo` / `Entity.Consumable` / `Entity.Actor` / `Entity.Building` / `Entity.SceneItem`
- 新增 Shield tag (`Entity.Equipment.Armor.Shield`)
- 删除 `Entity.Item.Weapon` 双挂标签、`Entity.Item.Component`

### SO 类层级
- 删除 `PropDefSO`，新建 `EquipmentDefSO` / `AmmoDefSO` / `ConsumableDefSO`
- `ArmorSO` / `ToolSO` / `ContainerSO` → 与 `WeaponDefSO` 共享 `EquipmentDefSO` 父类
- `WeaponDefSO` 改继承 `EquipmentDefSO`

### L3 模块
- `L3_Weapon` + `L3_Prop` + `L3_Item` → `L3_Equipment` + `L3_Ammo` + `L3_Consumable`
- 新建 6 个 EditorWindow + 6 个 ImportWindow

### Data/Entities 目录
- 6 个顶级目录统一单数：Character / Equipment / Ammo / Consumable / Building / SceneItem
- Weapons/ → Equipment/Weapon/，Props/ 拆分

### Namespace
- `RedDust.Weapon` → `RedDust.Equipment`
- `RedDust.Prop` → `RedDust.Equipment` / `RedDust.Ammo` / `RedDust.Consumable`

### 其他
- 9 SlotDef AcceptTags 对齐新 Tag 路径
- 6 个 Entity ImportExport + Animation ImportExport 添加默认文件路径
- AssetService / PlayerService 引用更新
- abilityTrees / animation / properties JSON 中的 Tag 引用全部更新
