# v0.20.2 — BodyForm 管道 + AnimSet 收敛 + 枚举重组

## 改动

- **枚举拆分**：`LocomotionEnums.cs` 拆为 `Enums/` 目录下四个独立文件 (`ELocomotionPhase`, `EPosture`, `EMovementGait`, `EBodyForm`)
- **EBodyForm**：新枚举 `Relax / Combat`，接入 Director → Intent → BuildContext 管道
- **AnimSet 收敛**：`GripTable.Resolve()` 改为接收 `EBodyForm` 参数，调用收敛至 `CharacterActor` 一处
- **GripAnimationEntry**：增加可选 `combatSet` 字段，BodyForm=Combat 时优先使用
- **BuildContext**：新增 `ResolvedLocoAnimSet` + `BodyForm` 属性
- **PlayerDirector**：debug 按键 4/5 切换 BodyForm
- **Body Tag 树**：设计 13 个标签 (`Body.Form.*`, `Body.Posture.*`, `Body.Locomotion.*`)，写入 `tags_all.json`
- **Tag 文档**：`gameplay-tag.md` 新增 Body 章节
