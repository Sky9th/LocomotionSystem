# v0.4.0 — Character Locomotion & Speed Architecture

## Locomotion Profile Restructure
- Split single `moveSpeed` into per-gait speeds: `walkSpeed`(2), `runSpeed`(5), `sprintSpeed`(8), `crawlSpeed`(1)
- Add `GetSpeedForGait()` method for unified speed lookup
- Add XML comments clarifying gait speed = character desired speed, separate from animation native speed

## Animation Speed Multiplier
- Add `LocomotionModeProfile.animNativeSpeed` — animation clip native speed at Speed=1.0
- Add `AnimationBrain.ApplySpeedMultiplier()` — computes `gaitSpeed / animNativeSpeed` on gait change
- Expose `AnimationBrain.SpeedMultiplier` property for global access
- Multiplier only changes on gait/state transition, not per-frame
- Support future buff/debuff system by adjusting gait speed independently of animation speed

## A* Pathfinding Integration
- Add `DesiredSpeedMultiplier` to PathfindingAgent — normalized 0-1 from A* desiredVelocity
- Sync `ai.maxSpeed` per gait via `UpdateGaitSpeed()`
- Disable `ai.slowWhenNotFacingTarget` (turn slowdown handled separately)
- Wire `MovementSpeedMultiplier` through SCharacterIntent → Motor for A* deceleration near target

## Root Motion & Turning
- Disable root motion rotation (`applyRootMotionRotation = false` by default)
- Increase default turn speeds: moving 360→720 deg/s, in-place 100→360 deg/s
- Add 0.5° dead zone to `ApplyTurnStepRotation` to filter A* heading jitter

## FSM Simplification
- Deprecate `TurnInMoving` state — moving turns use instant code rotation
- Deprecate `IdleToMoving` state — startup turns use instant code rotation
- Rename `BaseMovingState` local `gaitSpeed` → `desiredGaitSpeed` for clarity
- Add `TrySetState(Moving)` exit from `BaseTurnInPlaceState`

## Folder Structure
- Rename `L5_Drivers/L5_Locomotion/` → `L5_Drivers/Locomotion/`

## Camera
- Add camera pivot teleport to player position on spawn
- Force Cinemachine snap via `PreviousStateIsValid = false`

## Stats
- Move `LastStats` dictionary generation into `CharacterStats.Update()`

## Fixes
- Fix `Motor.ConvertToWorld()` to correctly rotate local velocity by heading
- Fix `DesiredSpeedMultiplier` returning 0 before A* path ready (no-path guard)
