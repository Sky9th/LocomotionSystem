# v0.6.0 — SO Event Channel 架构

## 新增

- `L1_Core/Events/EventChannelBase.cs` — 事件通道抽象基类，Editor OnAnyRaised 钩子
- `L1_Core/Events/GameEvent.cs` — `GameEvent<T>` 泛型通道（系统事件用）
- `L1_Core/Events/EventChannels.cs` — MB 组件，集中持有事件资产引用，驱动 IEventListener
- `L1_Core/Events/IEventListener.cs` — 订阅约定接口（BindEvents/UnbindEvents）
- `L2_Input/Events/IInputEvent.cs` — 输入事件生命周期接口
- `L2_Input/Events/InputEvent.cs` — `InputEvent<T>` 泛型基类，Unity Input System 集成
- `L2_Input/Events/SprintInputEvent.cs` — 冲刺事件通道
- `L2_Input/Events/SecondaryInteractEvent.cs` — 右键事件通道
- `L2_Input/Events/PrimaryInteractEvent.cs` — 左键事件通道
- `L2_Input/Events/CrouchInputEvent.cs` — 蹲下事件通道
- `L2_Input/Events/ProneInputEvent.cs` — 趴下事件通道
- `L2_Input/Events/StandInputEvent.cs` — 站立事件通道
- `L4_Director/Player/PlayerInput.cs` — 纯类，IEventListener，输入事件订阅+帧缓存
- `Data/Events/` — SO Event Channel 资产存放目录

## 移除

- `Actions/InputActionHandler.cs` + 全部 14 个 IAPlayer* 处理类
- `PlayerInputReceiver.cs` — PutAction boxing + EventDispatcherService 订阅

## 改动

- `InputService` — 只管理 InputEvent 生命周期，删除旧 actionHandlers
- `PlayerDirector` — 回归纯类，只做 SCharacterIntent 计算，不碰事件
- `CharacterActor` — 装配最简化，不持有事件引用
