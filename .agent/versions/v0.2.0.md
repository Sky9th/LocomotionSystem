# v0.2.0 (2026-05-29)

Namespace 整理版本 — 统一迁移到 RedDust.* 命名体系，同步强化提交工作流。

## 系统

- Namespace 根从 `Game` 改为 `RedDust`
- 20 个 namespace 按 L1-L5 层级严格映射
- Namespace 段仅由 `L#_` 前缀目录产生，非 L 目录归入父级
- L2 服务 namespace 去重：GameStateService→GameState, PlayerService→Player 等
- L2 服务 Unity 冲突修复：Input→GameInput, Time→GameTime, Camera→GameCamera, Scene→GameScene
- EventDispatcherService 从 L2 移至 L1_Core
- EventDriven struct 和契约 enum 豁免 L1-L5 层级约束
- rd-commit 技能强化：版号先升级再提交、提交信息严格格式校验
- rd-doc 技能简化：版本控制职责移交 rd-commit
- 新建 `tech/conventions/namespace-rules.md` 技术约定文档
