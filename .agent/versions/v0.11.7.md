# v0.12.0 — Ability 编辑器完整化

## 概述
补全 Ability 系统所有附属资产的编辑器功能，标准化共享 UI 组件。

## 新增
- **NoiseEditorWindow**: 独立 NoiseEventSO 编辑窗口（对标 ActivationEditorWindow）
- **NoiseImportExport**: Noise JSON 导入/导出（对标 Effect 模式）
- **AbilityImportExport**: AbilityDefSO/PassiveAbilitySO JSON 导入/导出
- **EditorImportExport 增强**: 从简易面板升级为 Effect 风格完整面板（Header + 文件选择 + 预览 + 按钮 + 结果）
- **AbilityTreeNode**: 新增 NoiseEventSO 节点类型

## 修复
- **DamageEffectSO 编辑器**: 补全 modAdd/modMult/priority 字段
- **伤害预览**: 更新为 Base/+Add/×Mult/Pri/Tag/Effective 七列
- **Create New 存根**: AbilityEditorWindow 和 SubAssetPickerView 的创建按钮改为实际功能
- **TagPicker**: 搜索栏改为 EditorUIUtility.DrawSearchRow，按钮标准化

## 标准化
- **EditorForm**: RowSpacing 4f→6f，行高统一 EditorGUIUtility.singleLineHeight
- **ImportExport 窗口**: 统一使用 EditorCard/EditorButton 组件
- **GreyPlaceholder**: 替换手动 new GUIStyle 为空状态

## 未完成
- Popup 定位问题
- 卡片点击范围
