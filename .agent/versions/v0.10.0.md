# v0.10.0 — L3_Properties 系统落地

## 新增模块

### L3_Properties
- **PropertyDefSO**: 属性定义 (Id, Type, Min/Max, DefaultValue)
- **PropertyDefinitionRegistry**: 属性定义注册表 (DefId → DefSO)
- **PropertyTreeSO**: 属性结构模板，支持继承链合并
- **PropertyNode / PropertyTreeContainer**: 数据模型
- **ResolvedPropertyBag**: 属性实例解析

### Editor
- **PropertyTreeEditorWindow**: 三栏编辑器 (左侧 Tree 列表 / 中间树编辑 / 右侧预留)
- **PropertyTreeListView**: 左侧 Tree 列表渲染
- **PropertyImportExport**: JSON ↔ .asset 导入导出
- **PropertyDefSOEditor**: 属性定义 Inspector
