# v0.10.2 — 拖拽完善 + 搜索优化 + 删除修复

## 改动

### 属性拖入
- feat: 右侧属性池拖入文件夹，支持指定插入位置

- feat: 全局最近文件夹匹配（HandleDefDrop + _defDropTargetY）

- feat: 搜索匹配属性加粗高亮，不再隐藏未匹配属性

### UI 细节
- feat: 搜索框 + 属性卡片 + 右侧属性行垂直居中

- fix: 左侧搜索框 + 属性池搜索框高度统一 22px
