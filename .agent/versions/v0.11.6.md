- 新建 Shared/Editor/Components/ 目录，抽取通用 Editor UI 组件：
  - Card.cs — 卡片系统（标准/选中/折叠/列表项/轻量/标题/间距）

  - Form.cs / FormItem.cs — 表单组件（反射 + Tooltip + 变更检测）
  - ImportExport.cs / UIUtility.cs — 导入导出视图 / 搜索筛选工具
- 新建 ActivationEditorWindow + ActivationImportExport
- 新建 SearchImportExport
- EffectEditor 接入 ImportExportView 统一组件
- EffectEditor DrawBlockedTags TagPicker 修复数组越界
- AbilityEditorWindow 修复 _activeSlot 不重置 / Select 静默失败

- 菜单重组：Editor(0-5) / Import-Export(20-24) / Tools(60+) 三组分隔

## 设计决策

- 组件文件无 Editor 前缀（Button/Card/Form），类名保留前缀
- 按钮大小由 GUIStyle padding+fontSize 决定，不设固定 Height
- 色彩对齐 Unity Design Tokens (#2C5D87 highlight, #D32222 error, #4C7EFF link)
