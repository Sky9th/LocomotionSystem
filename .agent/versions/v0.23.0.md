# v0.23.0 — AbilityTreeSO 系统落地 + 技能树架构定稿

## 改动

### AbilityTreeSO
- 新增 `AbilityTreeSO.cs` — 一切皆 AbilityTree（天赋/套路/种族/变异）
- 新增 `SAbilityTreeNode` struct — 节点系统，prerequisites 前置依赖
- 新增 `AbilityTreeImportExport.cs` — JSON 导入/导出，复用 EditorImportExport 组件
- 新增 `AbilityTreeEditorWindow.cs` — 编辑器窗口，菜单入口 RedDust/Ability Tree Import-Export
- 类别通过 treeTags (GameplayTag) 区分：`AbilityTree.Innate` / `.Talent` / `.Routine`
- 互斥：`exclusiveGroup` 分组替代 pairwise `mutuallyExclusiveWith`
- OnValidate 校验：nodeId 唯一性、前置有效性、自环检测、循环依赖检测（DFS）

### 技能树架构
- SkillTree → AbilityTree 全量重命名
- L3-skill-tree/ → L3-ability/ability-tree.md
- AbilityTreeSO 定位：L3_Ability Config 层，纯数据 SO，非 L2 非 L3 运行时
- 三层技能体系：Innate（天生） + Talent（天赋） + Routine（套路）
- 天赋/套路/种族统一抽象，不拆多个系统

### 物品/容器设计
- 新增 `L2-item-service/README.md` — ItemService 协调层

- ContainerSlotRef 归属 L3_Container，ownerId+slotKey 字符串寻址
- L3-equipment 文档标记 DEPRECATED
