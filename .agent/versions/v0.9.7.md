## 设计决策

- DTO 独立于 ScriptableObject — StatDefEntry/StatsTreeEntry/StatExportFile 纯 POCO
- defRefs 使用 Id 字符串而非 GUID，JSON 可读可编辑
- 导入为非破坏性 — 已存在资产跳过，幂等
- 树 name 不可重复（同批次内拒绝）避免 InheritsFrom 链接混乱
