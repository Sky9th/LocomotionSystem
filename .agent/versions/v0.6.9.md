# v0.6.9 — 目录重构：去掉所有 L4/L5 前缀

## 背景

L4/L5 子目录名带有架构层级标记，但嵌套本身已表达父子关系，L 数字冗余。Namespace 已经是干净名（如 `RedDust.Character.Combat`），目录名却多出 `L4_`/`L5_` 前缀，不一致且影响可读性。

## 改动

### 目录改名
- `L3_Character/L4_Animation/` → `L3_Character/Animation/`
- `L3_Character/L4_Audio/` → `L3_Character/Audio/`
- `L3_Character/L4_Combat/` → `L3_Character/Combat/`
- `L3_Character/L4_Director/` → `L3_Character/Director/`
- `L3_Character/L4_Kinematic/` → `L3_Character/Kinematic/`
- `L3_Character/L4_Locomotion/` → `L3_Character/Locomotion/`
- `L3_Character/L4_Pathfinding/` → `L3_Character/Pathfinding/`
- `L3_Character/L4_Stats/` → `L3_Character/Stats/`
- `L4_Animation/L5_Drivers/` → `Animation/Drivers/`
- `L4_Combat/L5_Drivers/` → `Combat/Drivers/`

### 文档
- `.agent/tech/README.md` 命名规则 + 目录树同步更新

### 影响
- 149 文件全部以 git rename 追踪
- 零 .cs 代码改动（namespace 已是干净名）

## 设计决策

| 决策 | 原因 |
|------|------|
| L4/L5 去前缀，L1/L2/L3 保留 | L1-L3 是顶层模块入口，保留前缀便于识别；L4/L5 的层级由嵌套表达 |
| namespace 跟随目录名 | 目录改名后 namespace 不变（本已是干净名），保持一致性 |
