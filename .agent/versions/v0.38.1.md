# v0.38.1 — 施展方属性修正 + OnHit 通知通路 + 回调改名

## S4.1 施展方属性修正
- `GroundSystemConfigSO` 新增 `strengthDamageBonus=0.05`（每点力量 +5% 伤害）
- `CharacterConst` 新增 `Attributes/Strength` 路径常量
- `CharacterCombat.OnModifyOutgoingDamage` 读取 Strength，应用 `× (1 + strength × bonus)`
- `ExecutionState.BuildDamageInfo` 补回 `OutgoingDamageCallback` 调用

## S4.3 Reactor→Caster OnHit 通知通路
- `AbilityReactor.Resolve` void → float（返回 finalAmount）
- `AbilityExecutor` 新增 `OnHitResolved` 回调
- `ExecutionState.OnTick` 捕获返回值 + 通知 caster
- `CharacterCombat.OnHitResolved` → `NotifyPassiveEvent(OnHit)` → 被动管线

## 回调改名
- `EffectCallback` → `OutgoingDamageCallback`
- `ConditionCallback` → `GatingConditionCallback`
- `PeekStatCallback` → `PreviewCostCallback`
- `ModifyStatCallback` → `ApplyCostCallback`
- `OnEffectModify` → `OnModifyOutgoingDamage`
