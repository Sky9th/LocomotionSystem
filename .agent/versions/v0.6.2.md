# v0.6.2 — A* Pathfinding Motor 集成

## 改动

- AIPath `desiredVelocity` → `SCharacterIntent.ExternalMovementVelocity` → Motor override 分支
- Motor 新增 `ConvertToLocal()`，override 路径跳过自身 Smooth（AIPath 已内置平滑）
- `PlayerDirector.ComputeHeading()` 改为 `desiredVelocity.normalized`（替代 `PathDirection`）
- Click-to-Move 闭环：右键 → SetDestination → AIPath velocity → 动画 blend tree → root motion
