# v0.11.5 — EditorForm 表单组件系统 + SearchEditor + Editor 目录重组

2026-06-12

## 改动

- 新建 EditorForm 声明式表单组件（Shared/Editor/EditorForm.cs）：fluent API + FieldInfo 反射 + [Tooltip] 自动读取 + 变更检测 + SetDirty
- 新建 SearchEditorWindow：对标 EffectEditor 的独立搜索形状编辑器
- Editor 目录重组：AbilityEditor/ EffectEditor/ SearchEditor/ _Shared/ 四子目录
- 新建 AbilityEditorUtility：树排序、数组操作、摘要函数、Search 工具
- EditorUIUtility 扩展：颜色常量、GreyPlaceholder、DrawSearchRow、DrawFilterTabBar、LabelWithTooltip 重载
- AbilityTreeNode / AbilityTreeView 扩展 Search 叶子支持
- EffectEditor / SearchEditor / MiddlePanel 表单行全部迁移至 EditorForm
- 修复 SubAssetPickerView 滚动位置重置、ComboLink 迭代删除、magic number 违规

## 设计决策

- EditorForm 归属 Shared/Editor（全局 Editor UI 组件，不绑定业务）
- 表单行统一使用 FormItem 封装 BeginHorizontal/EndHorizontal，特殊内容通过 PostInput/CustomDraw/CustomOnChange 注入
- SetDirty 方法重命名为 MarkDirty 避免 shadow ScriptableObject.SetDirty
