# v0.32.0 — Animation 仲裁重构 + AbilityDriver + ArmPoseLayer

## 改什么

动画系统 Driver 仲裁架构重大重构：播放权从 Arbiter 还给 Driver，OnStarted 签名改为传参，Arm 层独立封装。

### DriverArbiter 重构
- AcceptRequest 移除 `layer.Play()` — 播放权还给 Driver (OnStarted 中自行处理)
- `OnStarted()` → `OnStarted(AnimationRequest request)` — 数据由上至下传递
- OnInterrupted 去重 — 统一由 ProcessQueue 调用，AcceptRequest 不再重复
- 同 Driver 替换也调 OnInterrupted（修复 IgnoreCollision 泄漏）
- 默认驱动被抢占时调 OnInterrupted（修复 Arm 武器姿态残留）
- Release 前调 OnInterrupted（修复 driver 无清理机会）
- CheckCompletion 对 Stay 也调 OnCompleted
- 稳定排序（按类型名二级排）
- Queue snapshot 防并发修改
- Queue 被跳过的请求输出 Warning
- UnregisterDriver 清 activeDriver 僵尸引用

### 新 Driver
- **AbilityDriver** — 一次性动画驱动，被动响应 Arbiter 调度，T 键测试
- **ArmPoseLayer** — Arm 层武器姿态独立管理，LocomotionDriver 不再触碰 Arm 层

### Locomotion 层重构
- BaseLayer 内化 AnimSet/IdleOverride 决策（EvaluateAnimSet 自决）
- LocomotionDriver 退化为纯持有者，Evaluate 清空
- IdleOverride 机制：partial grip 静止时覆盖 defaultSet idle

### 测试
- CharacterActor T 键临时测试 AbilityDriver（Inspector 拖 AnimationClip）

## 架构

```
AnimationBrain.Apply()
  ├── FullBodyArbiter.Resolve → EvaluateDrivers → ProcessQueue → Drive
  └── HeadLook / SpeedMultiplier

LocomotionDriver (default)
  ├── BaseLayer      ← 自决 AnimSet/IdleOverride
  └── ArmPoseLayer   ← 自决 Arm Play/Fade

AbilityDriver         ← 一次性动画，OnStarted 自播
TraversalDriver      ← 占位（Rig 物理操作）
```
