# v0.12.0 — FloatAdjunct + BuffEffectSO

## 新增

### Properties: FloatAdjunct（只读修正层）
- `FloatAdjunct` 类 — Owner/TargetPath/ValueAdd/ValueMultiply/ExpiryTime
- `FloatState` 新增 `_adjuncts` 桶 + `Effective` 属性 + Tick 过期自动清理
- `PropertyTable` 新增 `AddAdjunct`/`RemoveAdjuncts`/`GetEffectiveFloat`
- `PropertyAgent` + `IPropertyReader` 暴露 Adjunct API 和 `GetEffectiveFloat`
- `Effective = clamp((Current + ΣValueAdd) × ΠValueMultiply, Min, Max)`
- `GetFloat` 不变（raw Current），`Modify/Set` 不受 adjunct 偏移影响

### Ability: BuffEffectSO（Buff/Debuff 统一底座）
- `BuffEffectSO` — EffectSO 子类，`grantedTags[]` + `adjuncts[]`（`SBuffAdjunct` 模板）
- 统一覆盖：临时 Buff（技能）、天赋（被动 OnEquip）、条件 Buff（被动触发）、装备 Buff
- `AbilityExecutor` — `_buffTags` 过期管理 + `ApplyBuff` 翻译方法
- ⑤ 效果阶段：selfEffects 和 targetEffects 均识别并处理 BuffEffectSO
- 堆叠：`valueAdd × stackCount` 线性叠加，`valueMultiply` 不随层数变化

### EffectImportExport: Buff 类型支持
- `BuffAdjunctEntry` DTO — propertyId/valueAdd/valueMultiply
- EffectEntry 新增 `grantedTags` 和 `adjuncts` 字段
- Export/Import/ApplyFields/BuildPreview 全链路支持 "Buff" 类型

### 4 个 Demo 技能 JSON
- `tags_all.json` — 新增 `Tag_SuppressiveFire`
- `effects_all.json` — 新增 `Cost_Ammo_Pistol_Burst` + `Buff_Debuff_Slow_30`
- `abilities_all.json` — 刀轻击/刀重劈/手枪普通/手枪压制
- `searches_all.json` / `activations_all.json` / `noises_all.json` — 对应子资产
