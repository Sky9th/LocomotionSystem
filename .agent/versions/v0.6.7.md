# v0.6.7 — 继承合并核心 + ParentId 重构

## 重构
- **Children[] → ParentId**: JsonStatNode 用 ParentId 替代 Children，子端声明父子关系
- **数据架构**: ownNodes(唯一可写) → workingNodes(合并派生) → parentMerged(祖先缓存)
- **编辑模型**: 所有操作只改 ownNodes，needsRebuild 标记驱动 workingNodes 重建

## 新增
- MergeLayer: 按 Id 匹配合并，ParentId/OverrideValue 继承，循环/深度保护
- RefreshPaths: ParentId 扫描重建路径
- BuildParentMerged: 一次性祖先合并缓存
- GetOrCreateOwn: 继承节点首次编辑时创建 ownNodes 覆盖
- GetDuplicateIds: 合并树重复 Id 检测
- DuplicateId: 临时存储被拒绝的 Def.Id
- WouldCreateCycle: 循环继承检测

## 修复
- 覆盖值清除: ↺ 直接删除 ownNodes 节点
- 叶子 Def 字段: 重复 Id/缺 Def/DuplicateId 红色标记
- 继承节点只读: Folder/Leaf 的 ✕/Def 按钮 disabled
- 叶子 Own 判断: 修正为 leafIsOwn 而非文件夹的 isOwn
