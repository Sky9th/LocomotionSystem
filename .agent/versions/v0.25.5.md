# v0.25.5 — EntityService + Entity 数据模型

> 2026-06-27

## 新增

### L2 EntityService
- `EntityService.cs` — 实体管理服务，数据层（Dictionary 注册表）+ GO 层（Spawn/Despawn）
- `Entity.cs` — 实体数据模型，Id + Preset（= EntityType）+ Properties + Tick
- 事件载荷：`SEntitySpawnRequest`, `SEntitySpawned`, `SEntityDespawnRequest`, `SEntityDespawned`
- 事件通道：`GameEvent<T>` SO 类型（`EntitySpawnRequestEvent` 等）

### Identity 增强
- `Identity.cs` — 新增 `EntityId` 字段 + `BindEntity()` 方法，GO 侧数据锚点

### PropertyPresetSO 增强
- 新增 `Prefab` 字段，EntityService.Spawn 时 Instantiate

## 架构决策
- EntityService 是 Entity 唯一拥有者，其他系统只持有 Id 或缓存引用
- Preset 即 EntityType（CharacterDefSO → 角色，ItemDefSO → 物品）
- Spawn/Despawn 与 Register/Unregister 分离——Entity 可脱离 GO 存在
- Entity 位于 L2（非 L3_Properties），与 EntityService 同目录

## 依赖
- 依赖：L3_Properties（PropertyPresetSO, PropertyTable）, L3_Identity, L1_Core（ModuleChildMono, EventHub）
- 被依赖：待迁移（CharacterActor, ItemEntity, PlayerService, Container）
