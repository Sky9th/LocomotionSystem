# v0.36.6 — ImportExport 统一 + 数据/修复批量落地

## 变更概要

### ImportExport 体系统一 (shared + 9 modules)
- 所有 `ImportFromJson` 返回值从 `(created, skipped, errors)` 扩展为 `(created, updated, skipped, errors)`
- 已有资产覆盖时计数为 `updated` 而非 `skipped`，语义更精确
- 涉及：Tag, Ability, AbilityTree, Activation, Effect, Noise, Search, Animation, Property
- Shared `ImportExport.cs` 组件同步更新签名和结果显示

### 编辑器改进
- **EffectEditorWindow**: 详情表单新增 `description` TextArea 字段
- **EditorLabel**: `EditorGUILayout.LabelField` → `GUILayout.Label` + `EditorStyles.label` 基类样式，修复 tooltip hover 不响应
- **TagPicker**: `rootFilter` 支持多段路径匹配（如 `Ability.Effect`），通过 `_model.Find()` 精确查找

### 运行时修复
- **WindupState**: windup 为 0 的技能不再检查 animation fire marker，直接进入 Cooldown
- **CharacterEquipment**: 武器视图 spawn 时禁用 Collider + Rigidbody 设 kinematic，避免和敌人碰撞体物理推挤
- **PathfindingAgent**: `SetDestination()` 时恢复 `ai.isStopped = false`，防止 Agent 卡住
- **AssetRefListPropertyDefSO**: GUID 列表解析重构，使用 `JsonUtility` + `GuidListWrap` 包装模式

### 数据更新
- **effects_all.json**: 全量重新导出（Unity Editor 格式），覆盖全部 Effect 资产的完整字段
- **Ability 数据**: 近战连招链补全（HeavyChop→SlashB, LightCut→2HitComboA, SlashB→3HitComboA, Kick→Grab, Punch→Kick）
- **Effect 参数微调**: Bleed baseValue 0→5 / maxStacks 1→5, Slow duration 2s→3s, 描述文本修正
