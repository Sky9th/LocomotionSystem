# v0.36.3 — 武器栏固定三槽 + 冷却 UI 修复 + 体力回复

## 核心改动

- **WeaponBarOverlay** — 固定三槽 [空手, 剑, 手枪]，选中态同步右手装备，fallback 标签
- **UIIconSlot.SetCooldown** — 冷却首帧 snap 到 1.0 + DOTween.Kill 防止旧 tween 拉扯
- **InventoryQuery** — 新增深层递归缓存 `AllItemsDeep` + `CollectRecursive` + `FindItemDeep`
- **CostState + PropertyTable** — `TryGetPath` 解决 `def.Id`("Stamina") vs 完整路径("Vitals/Stamina") 不匹配
- **CharacterActor** — 临时体力回复 modifier（每秒 +25）
- **CharacterConst** — 新增 `Vitals.Stamina` 路径常量
