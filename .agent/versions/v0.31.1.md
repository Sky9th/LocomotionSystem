# v0.31.1 — Ability Pipeline 状态机框架

## 变更

- **Ability Pipeline 状态机框架**：`IState<TContext>` + `StateMachine<TContext>` 泛型基础设施，`CanEnter`/`CanExit`/`CanBeInterrupted` 三层钩子
- **主动技能管道**：`ActiveAbilityPipeline` 持有 `StateMachine<SActiveAbilityContext>`，入口 `Enqueue` → `Start` → `Tick`
- **GatingState**：② 门控落地——冷却/互斥/外部条件三闸门，通过后流向 Completed 占位
- **AbilityExecutor 重构**：旧代码归档 `#region OLD`，新增 `Queue<SQueuedSkill>` 队列 + 每帧驱动
- **PlayerDirector 对接**：`TryActivate` → `Enqueue`，武器 Entity 传入管道
- **路径修正**：`MeleeWeaponSO` / `ItemDefSO` 注释 `Combat/ATK` → `Weapon/ATK`
- **Container AcceptTags 层级匹配**：`StartsWith` 替代精确匹配，9 个 StructDef + `properties_all.json` 同步加 `Entity.` 前缀
- **Backpack 实体**：新建 `Assets/Data/Entities/Equipment/Backpack.asset`
- **删除**：`AbilitySearchUtility.cs` / `AbilityGating.cs`，逻辑迁入 State 类
- **Bugfix**：`CleanupExpiredCooldowns` 遗漏修复
