# v0.37.0 — Ability Instance 统一模型

## 概述

引入 AbilityInstance + InstanceManager 统一主动/被动/装备/天赋技能的生命周期管理。副作用从 Push 模型翻转为 Pull 模型（目标侧 Tick 检查 Owner.IsActive 自动清理）。Reactor 收敛为目标侧效果唯一入口。GetDamageEffect API 修正为返回 Effects[]。

## 架构变更

- **AbilityInstance** — AbilitySO 运行时实例，承载生命週期 + RefreshPolicy + 副作用 Owner 溯源
- **InstanceManager** — 替代 runtimePassives，四索引管理实例的 Activate/Deactivate/GetByTrigger
- **Pull 副作用清理** — FloatState.Tick + CleanupExpiredCooldowns 检查 Owner.IsActive，InstanceManager 不追踪"影响了谁"
- **Reactor 4 阶段** — Damage Resolution → Effect Application → Reaction → Broadcast
- **AbilityPipeline** — 主动被动共用，IsIdle 含 RejectedState
- **GetDamageEffects** — 返回 EffectSO[] 替代单 DamageEffectSO
