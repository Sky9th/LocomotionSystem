# v0.40.13 — Entity 资产目录重组

## 背景
Entity 资产目录 `Assets/Data/Entities/` 与 L3 模块架构不对齐。`Equipment/` 目录混合了 Weapon（L3_Weapon）和 Prop（L3_Prop）两个模块的资产，`SceneItems/` 缺失，`ItemDefSO` 已废弃但 Backpack.asset 仍在使用。

## 改动

### 资产目录重组
- 新增 `Weapons/Melee/`、`Weapons/Ranged/`（承接 Blade、Pistol）
- 新增 `Props/Armor/`、`Props/Consumable/`、`Props/Ammo/`、`Props/Tool/`、`Props/Container/`、`Props/Material/`（6 子目录对齐 6 种 PropDefSO 子类）
- 新增 `SceneItems/`（就绪，暂无资产）
- 删除 `Equipment/` 目录

### 资产迁移
- Blade.asset → `Weapons/Melee/`
- Pistol.asset → `Weapons/Ranged/`
- Backpack.asset → `Props/Container/`，同时从废弃 `ItemDefSO` 转为 `ContainerSO`

### 代码
- `EntityEditorWindow` 新增 `GetAssetDirForType(Type)` 虚方法，`CreateAsset` 按类型路由到子目录
- `WeaponEditorWindow` / `PropEditorWindow` 覆写路由逻辑

### 清理
- 删除 `Scripts/Shared/Editor/Entity/` 空目录
