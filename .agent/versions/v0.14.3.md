# v0.14.3

Card API 简化 + EditorTreeView 组件

## Card

- 仅保留 `Draw(Action)` 和 `Draw(string title, Action)` 两个入口
- 移除 `DrawLight`/`DrawFoldout`/`DrawItem`/`DrawCardHeader`
- 移除 `selected`/`borderless`/`pad` 参数，样式全内置
- 所有 16+ 调用方适配

## EditorTreeView

- 新增 `EditorTreeView` — 基于 `UnityEditor.IMGUI.Controls.TreeView`
- `SetData(roots, onSelect, onDelete)` 绑定 `EditorTreeNode`
- EffectEditorWindow 左栏已迁移
- Tag 系统迁移失败（已回滚）

## 其他

- `EditorTokens` 新增 `ColorCardBg`/`ColorCardBorder`
- `EditorLabel` 新增自适应宽度 `Draw(string, tooltip, style)` 重载
