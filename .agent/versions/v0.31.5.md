# v0.31.5 — Ability Pipeline 审计修复

## 改什么

Ability Pipeline 7 State 全量审计，修复 P1/P2 缺口，CostState 架构改写。

### State 改动

| State | 改动 |
|-------|------|
| **GatingState** | 无改动（审计通过） |
| **CostState** | 架构改写：PropertyTable 内建路径 + 回调相位级排他。PeekStatCallback 签名改为 `Func<CostEffectSO[], string>`，ModifyStatCallback 改为 `Action<CostEffectSO[]>` |
| **WindupState** (原 ActivationState) | 改名；windupDuration / animationSpeed 计时；canCancelWindup 打断控制 |
| **CooldownState** | 移除 cooldownAbilityTags 冗余映射，简化 CleanupExpiredCooldowns |
| **ExecutionState** | EffectCallback 接入 BuildDamageInfo |
| **RecoveryState** | recoveryDuration / animationSpeed 除法 |
| **SearchState** | ⛔ DEPRECATED 标注 |

### AbilityExecutor 改动

- 新增 `PropertyTable` 属性（惰性从 Identity 取）
- 新增 `IsBlockedBySharedCooldown()` 方法
- 回调签名升级：PeekStatCallback / ModifyStatCallback 改为数组级

### CharacterCombat

- 移除 PeekStatCallback / ModifyStatCallback 死接线（PropertyTable 已覆盖）

### CostEffectSO

- TODO: 绝对值扣除不足，标记需 ECostMode 枚举

### 文档

- `ability-pipeline-states.md` 全面更新：补充 WindupState/CooldownState/RecoveryState 章节，更新 Future Plans
