# v0.6.8 — Combat 配置层 + 数据结构（Phase 4.1 Item 2-4）

## 背景

Phase 4.1 施工推进 Item 2-4：战斗枚举、ScriptableObject 配置层、运行时数据结构。贯彻架构设计原则——冷却走 GameplayEffectSO 统一管道（冷却 = Duration Effect，与 Buff/Debuff 同类型），tag 字段使用 GameplayTagDefinitionSO 引用。

- README 目录结构同步更新

## 设计决策

| 决策 | 原因 |
|------|------|
| 冷却走 GameplayEffectSO 引用 | 冷却就是 Duration Effect，与 Buff/Debuff 统一管道，贯彻架构核心原则 |
| 配置层用 SO 引用，运行时用 struct | 编辑器安全 + 运行时性能 |
| noiseType 使用 GameplayTag 体系 | 噪音"类型"本质是标签，应用 GameplayTag 基础设施 |
| `HasTagExact` O(1) | HashSet 的 Contains 是 O(1)，foreach 是 O(n)，不需要线性遍历 |
| 枚举统一 E 前缀 | 项目约定，与 ELocomotionPhase/EPosture/EMovementGait 一致 |
