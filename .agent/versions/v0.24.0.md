# v0.24.0 — AbilityForest 运行时落地 + Actor 联动

## 改动

### AbilityForest
- 新增 `AbilityForest.cs` — 角色技能森林运行时（`L3_Character/Ability/`）
- 纯 C# 类，无 MonoBehaviour。多来源活跃树集合（innate/talent/routine/learned）
- 所有状态变化自动 Resolve：AddTree/RemoveBySource/UnlockNode/SetWeaponTags
- 两层过滤：树级武器兼容 + 节点级解锁状态
- 构造函数注入 innate 树，远期 Talent 重载预留

### Actor 联动
- `CharacterBuildContext`：`SkillSlot1/SkillSlot2` → `AbilityForest` 引用
- `CharacterActor`：创建 AbilityForest + 注入 ctx，移除临时技能槽字段
- `PlayerDirector`：`ctx.AbilityForest.ResolvedActives` 直接消费
- Resolve 不在 Update 中——状态变化时自动触发，ctx 引用即最新结果

- 新增 `ability-forest.md` — 完整设计文档
- 两轮辩论定 namespace：`RedDust.Character.Ability`
