# v0.6.10 — SkillDefSO 配置层重构

> 2026-06-04 · 从平铺属性拆分为资产组合

## 设计决策

- **SkillActivationSO** — 封装「怎么放」：激活方式、动画、阶段标记。动画=时间轴本体，animationSpeed=唯一调参旋钮
- **SkillSearchSO** — 封装「往哪打」：抽象基类 + ConeSearchSO / RaySearchSO / CircleSearchSO 三种子类
- **WeaponSkillSetSO 删除** — 武器→技能映射是角色层职责，不属于 Combat 配置层
- **canMoveWhileCasting 删除** — ESkillAnimationLayer 已区分定身/可移动
- **transitionTime 删除** — 总时长由动画决定，后摇结束即可打断
- **recoveryCancelWindow 删除** — 格斗游戏精度需求，本项目用不上
