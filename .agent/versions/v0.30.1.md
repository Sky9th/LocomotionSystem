# v0.30.1 — JSON 格式重构 + 手动序列化代码清理

**日期**: 2026-06-30

## 改动摘要

Properties JSON 格式从 escaped-string 改为 typed nested objects；删除 SO 层手动 JSON 构建代码；Import/Export 全面重写。

## 具体改动

### JSON 格式升级
- 旧：`"_float": ["{\"id\":\"HP\",...}"]` — escaped string
- 新：`"_float": [{"id":"HP","min":0,"max":100,"defaultValue":100}]` — proper nested objects

### SO 子类：新增 JsonData struct + 删除手动 JSON
- 9 个子类各加 `[Serializable] public struct JsonData` — 字段与 SO 对齐
- 删除 `WriteJsonFields()` / `ToJson()` / `FromJson()` / `Escape()` — 所有手动 StringBuilder JSON 构建代码
- 删除不再需要的 `System.Text` using

### PropertyImportExport 重写
- `ImportDefs`：`List<string>` → `List<XxxPropertyDefSO.JsonData>` 类型化列表
- Export：用 JsonData struct + `JsonUtility.ToJson` 直接序列化（替代 StringBuilder 手动构建）
- Import：从 JsonData struct 直接读字段创建 SO（替代 `FromJsonOverwrite`）
- Preview：用泛型 Count 方法读 typed list 统计

### 资产目录按类型分
- `Definitions/Float/`, `Definitions/Int/`, `Definitions/Bool/` 等 9 个分子目录
