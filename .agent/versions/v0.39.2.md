# v0.39.2 — 修复场景重复 GameManager + Addressables build 初始化

## 改动

### 场景重复 GameManager 修复
- **MainMenu.unity / SampleScene.unity**: 移除重复的 GameManager prefab 实例
  - Root cause: Core 是常驻场景，GameManager 通过 DontDestroyOnLoad 全局唯一，additive 加载的场景不应携带 GameManager
  - Bug: 第二个 GameManager 的 InputService.OnDisable 调用 `map.Disable()` 污染了共享的 InputActionAsset，导致有效实例的输入回调静默失效
- **Core.unity**: 删除 SceneService 的 `_firstSceneConfig` + `_configs.Array.size` 覆写（指向不存在的 GUID `36224b16...`），回退到 prefab 默认值

### AddressablesService build 修复
- **AddressablesService.cs**: `InitializeAsync()` 增加 `IsValid()` 检查
  - Build 中 Addressables catalog 未就绪时，`UnityAddressables.InitializeAsync()` 可能返回已完成但内部 handle 无效的操作，直接访问 `.Status` 抛出 `Attempting to use an invalid operation handle`
  - 加入 `while (initOp.IsValid() && !initOp.IsDone)` + handle 失效时优雅降级

### 其他
- **Player.prefab**: 清理空 initialTags / initialPassives 数组；innateTrees 顺序调整
- **PathFinding.unity**: light color, 移除空 initialPassives / targetLayers
- **Default Local Group.asset**: 移除 boot 标签组中多余 scene config 条目
- **ProjectSettings.asset**: 添加 preloadedAssets（InputActionAsset）
