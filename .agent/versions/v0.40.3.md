# v0.40.3

## 改动摘要

**新建 L2 AssetService + 消除 Boot 管线 + SceneService 瘦身**

- 新建 `L2_AssetService/`：AssetService（加载/初始化/生命周期）+ AssetCatalog（数据目录）
- 消除 `Pipeline/Boot/` 12 文件：IBootTask、BootPipeline、BootTaskComposer、BootAssetCatalog、8 BootTask → 收敛为 AssetService.RunBootInit()
- 删除 `L2_AddressablesService/`：功能吸收进 AssetService
- 删除 `SceneLoader`、`LoadProgress`、`SRuntimeSceneState`、`SSceneRequest`、`SceneRequestEvent`：不必要的抽象
- `GameRegistry` → `AssetCatalog`：命名修正，实例由 GameService.Assets 持有
- `TransitionGate` → `SceneTransition`：去 Boot 感知，纯场景切换
- `SceneService`：公开 API 简化为 `Load()` / `Load(SceneId)`
- `UIService`：事件驱动 → 直接调用 `SceneService.Load()`
- `RdTagDefSO.RebuildAllCaches` → `AssetService` 私有方法
- `AssetCatalog`：去 `_xxxReady` bool、死 API、LogNotReady
