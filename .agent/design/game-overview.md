## 一、项目概述

### 一句话定义
> 俯视角末世生存种田流游戏，融合武功套路与热武器战斗，在丧尸横行的世界里通过NPC协作重建据点。

### 核心关键词
- 俯视角 / 末世生存 / 种田流 / 单人PC（Steam）
- Mod 社区：纯数据驱动，JSON 格式，零代码门槛，Steam Workshop 分发
- 多语言：官方中英双语，字符串外部化支持社区翻译
- 武功套路 + 热武器（装备决定伤害基底，Ability 为动作模式）
- NPC劳动力（可指挥、可成长）/ 尸潮事件（伪随机动态压力）
- 科技树（图纸消耗型）/ 建造（网格化模块化）/ 农业与烹饪
- **世界观**：陨石外星孢子 → 母体雾区 → 外界封锁 → 无人机交易

### 参考游戏
- **《僵尸毁灭工程》**：生存基底、俯视角、末世氛围
- **《环世界》**：科技树、NPC控制模式
- **《腐烂国度》**：动作感
- **《森林》**：建造自由度

## 二、世界观摘要

202X年，陨石坠落在虚构的日本岛屿**"八重岛"**。外星孢子**"赤尘"**感染碳基生命，感染者沦为**"堕者"**（丧尸）。赤尘的终极形态是**巨型树状母体**，持续释放危险雾区。外界联合封锁岛屿，仅通过无人机用高能矿物交换补给。

侵蚀抗性梯度：海水免疫 → 森林高抗 → 农田中抗 → 小镇低抗 → 城市无抗。**生命越密集的自然环境抵抗力越强。**

> 详细设定见 [world/setting.md](world/setting.md) 和 [world/spore-erosion-rules.md](world/spore-erosion-rules.md)

## 三、核心差异化

| 维度 | 僵尸毁灭工程 | 我们的方向 |
|------|-------------|-----------|
| **世界观** | 写实丧尸 | 外星孢子 + 母体雾区 + 外界封锁 |
| **建造** | 功能导向 | 网格化模块建造，建筑有耐久可被破坏 |

| **Mod** | 无 | **纯数据 Mod 社区**：JSON 格式，玩家可新增物品/技能/NPC/科技，Steam Workshop 分发 |

## 五、核心循环

```text
探索阶段：
玩家离开据点 → 周边区域（含雾区边缘）
→ 搜刮资源（工具/图纸/种子/弹药/高能矿物）、解救NPC、清理堕者
→ 风险：遭遇堕者、雾区感染累积、消耗体力

资源阶段：
带回资源 → 存入仓库
资源类型：材料、工具、武器、消耗品、零件、知识类、高能矿物

分配与发展阶段：
玩家指挥NPC + 分配工具 →
├─ 种田（雾区外）→ 食材产出 → 支撑烹饪
├─ 烹饪 → 食物产出 → 养活玩家与NPC → 士气影响效率
├─ 建造/修复 → 据点功能提升（防御、床位、工作台）
├─ 采集/制作 → 工具/材料产出 → 支撑探索和建造
├─ 科技学习 → 消耗图纸解锁新科技 → 新配方/建筑/功能
├─ 防护准备 → 制作防毒面具、药品 → 支撑雾区探索
└─ 战斗训练/防御 → 提升玩家熟练度，准备应对尸潮

成长反馈：
玩家战斗 → 武器熟练度提升 → 战力增强
NPC工作 → 工作等级提升 → 效率增强
科技解锁 → 新功能/新建筑 → 据点全面发展
建造升级 → 更强防御 → 更好抵御尸潮

事件干扰：
尸潮（完全伪随机）→ 攻击建筑、消耗资源、可能伤亡
雾区扩张（慢速）→ 改变可种植区域、增加探索压力

循环闭合：
成长后 → 深入雾区 → 寻找并摧毁母体 → 获得高能矿物
→ 通过无人机换取稀有物资 → 支撑进一步成长
→ 积攒足够矿物后 → 触发逃离结局选项
```
