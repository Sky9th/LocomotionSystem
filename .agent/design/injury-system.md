# 伤病系统设计

> 日期: 2026-05-23
> 状态: 设计阶段，已确认核心方向
> 关联: `game-overview.md` 核心系统 / `stats-inventory.md` Vitals 节点

---

## 一、设计目标

硬核生存的"硬"很大程度上来自伤病——受伤不是扣 HP 了事，而是触发一系列连锁反应：
流血需要包扎、感染需要消毒、疼痛影响行动、重伤有永久风险。

核心原则：
- **受伤有后果** — 每种伤不止扣血，还有持续影响
- **治疗有层次** — 不只是用同一个"血瓶"，而是需要匹配的医疗物品
- **回避有价值** — 战斗有代价，不战而逃是合理选择
- **可管理** — 单人开发，轻量部位系统（仅分上下半身），伤害类型 × 严重度 × 部位矩阵

---

## 二、部位系统（轻量）

| 部位 | 影响 |
|------|------|
| **上半身** | 攻击速度、使用物品速度 |
| **下半身** | 移动速度、冲刺、跳跃 |

- 玩家不瞄准具体部位，伤害部位由攻击来源和类型随机决定
- 丧尸攻击：咬伤默认上半身（啃咬手臂/肩膀），爪击随机
- 跌落伤害：默认下半身
- 同一部位叠加新伤会加重已有伤害

## 三、伤害类型

| 类型 | 来源 | 即时效果 | 持续效果 | 典型场景 |
|------|------|----------|----------|----------|
| **割伤** | 利器（刀、碎玻璃、丧尸爪击） | HP 扣除 | 持续流血 | 近战受伤、搜刮被划伤 |
| **咬伤** | 丧尸啃咬 | HP 扣除 + 感染风险 | 流血 + 感染值攀升 | 被丧尸近身 |
| **钝器伤** | 棍棒、坠落、撞击 | HP 扣除 | 疼痛 + 体力上限暂时下降 | 被钝器打中、高处跌落 |
| **骨折** | 重击、高处跌落、尸潮碾压 | HP 大幅扣除 | 移速/攻速惩罚 + 疼痛 | 被大型丧尸击中 |
| **烧伤** | 火焰、高温表面、爆炸 | HP 扣除 | 疼痛 + 缓慢恢复 | 篝火意外、燃烧瓶、火灾 |

### 割伤 (Laceration)

最常见的外伤。任何涉及利器的战斗和搜刮行为都可能造成。

- 轻微割伤：流血缓慢，绷带包扎后止血
- 中度割伤：流血中等，需清洁 + 包扎
- 重度割伤：流血快速，需止血带 + 清洁 + 包扎，可能留疤

### 咬伤 (Bite)

丧尸特有的伤害类型，是游戏中最危险的伤害——不是因为即时伤害，而是因为感染风险。

- 必定流血（同割伤等级）
- 感染值累积速率取决于咬伤严重度
- 感染值达到阈值 → 丧尸化过程启动 → 死亡
- 默认攻击上半身

### 钝器伤 (Blunt Trauma)

无流血，但有疼痛和功能性惩罚。

- 轻微淤伤：轻微疼痛，短时间恢复
- 中度内伤：中疼痛 + 体力上限暂时降低
- 重度内脏伤：强疼痛 + 体力上限大幅降低 + 行动间歇性迟钝

### 骨折 (Fracture)

最严重的物理伤害，有长期后果。默认发生在下半身（跌落/重击）。

- 轻微骨裂：移速轻微降低，需夹板固定，恢复数天
- 骨折：移速降低 + 攻速降低，需夹板，恢复更长
- 粉碎性骨折：移速大幅降低 + 攻速大幅降低，需手术（高级医疗），恢复极长，可能永久残留轻微惩罚

### 烧伤 (Burn)

火焰相关的特殊伤害，疼痛值高但无流血。

- 轻微烧伤（一度）：表面疼痛，不需特殊治疗，自然恢复
- 中度烧伤（二度）：强疼痛 + 起泡，需烫伤药膏，恢复较慢
- 重度烧伤（三度）：极强疼痛 + 永久疤痕，需手术植皮，恢复极长

## 四、严重度

| 等级 | 流血速率 | 感染风险 | 疼痛值 | 治疗难度 | 恢复时间 |
|------|----------|----------|--------|----------|----------|
| 轻微 | 低 | 无 | 低 | 1 件物品 | 短 |
| 中度 | 中 | 中等 | 中 | 2 件物品 | 中等 |
| 重度 | 高 | 高 | 高 | 3+ 件物品 | 长 |

## 五、治疗系统

### 医疗物品

| 物品 | 用途 | 获取 |
|------|------|------|
| 绷带 | 止血（割伤/咬伤） | 搜刮（常见）、制作（布料） |
| 消毒剂 | 清洁伤口、降低感染概率 | 搜刮（中等稀有） |
| 止血带 | 重度流血急救 | 搜刮（稀有）、医疗技能制作 |
| 夹板 | 固定骨折 | 搜刮 + 制作（木材+布料） |
| 止痛药 | 临时压制疼痛值 | 搜刮（中等稀有） |
| 抗生素 | 对抗感染、延缓丧尸化 | 搜刮（稀有） |
| 烫伤药膏 | 治疗中度烧伤 | 搜刮（中等稀有）、制作（草药） |
| 手术包 | 治疗粉碎性骨折/重度烧伤 | 搜刮（极稀有）、科技解锁制作 |

### 治疗流程

```
受伤 → 检查伤害类型 + 部位 →
    割伤/咬伤:
      1. 使用绷带止血
      2. 如有感染风险 → 使用消毒剂
      3. 如重度流血 → 先用止血带，再包扎
      4. 等待恢复
    钝器伤:
      1. 使用止痛药缓解疼痛
      2. 休息加速恢复
    骨折:
      1. 使用夹板固定
      2. 等待骨骼愈合（天数）
    烧伤:
      1. 轻度自愈
      2. 中度使用烫伤药膏
      3. 重度使用手术包
```

### 治疗与部位

- 同一部位的伤越多，治疗时间越长
- 已包扎的伤在恢复期间再次受击 → 包扎可能失效（伤口重新裂开）
- 部位受伤严重到一定程度 → 该部位功能暂时/永久降低

### 医疗熟练度

包扎/消毒/固定 不是消耗物品就完事。角色的 MedicalProf 影响治疗效果：

- 低熟练度：治疗有概率失败（消耗物品但不生效），或效果打折
- 高熟练度：治疗消耗减半、恢复速度加快

这给"培养一个医生 NPC"提供了价值。

## 六、丧尸化过程

咬伤后感染值（Infection）攀升。达到阈值后不是立即死亡，而是进入**不可逆恶化过程**：

```
感染值 → 阈值触发

阶段1: 初期发热
  - 体力上限降低
  - 口渴加速
  - 角色偶尔咳嗽/发抖

阶段2: 意识模糊
  - 视野缩小/模糊
  - 操作有随机延迟
  - 移速降低
  - 无法冲刺

阶段3: 器官衰竭
  - 移速大幅降低
  - 无法攻击
  - HP 持续下降
  - 意识间歇性丧失

阶段4: 死亡 + 丧尸化
  - 角色死亡
  - 尸体在一段时间后变为敌对丧尸
  - 继承角色的部分属性（HP 更高、伤害更高）
```

- 抗生素可**延缓**但无法逆转丧尸化过程（延长各阶段时间，但终点不变）
- 各阶段持续时间由数值统一规划时确定
- 玩家可在任何阶段选择"自我了断"，阻止丧尸化
- NPC 同样经历此过程，玩家面临抉择：提前处理还是冒险留到最后一刻

## 七、NPC 共用

NPC 与玩家使用**完全相同的伤病系统**，包括：

- 相同的伤害类型和严重度
- 相同的治疗物品和流程
- 相同的 Stats 联动
- **相同的丧尸化过程**（被丧尸咬伤 → 感染 → 恶化 → 死亡 → 变丧尸）

这意味着：
- NPC 受伤后需要玩家消耗医疗物品治疗
- 被咬伤的 NPC 是一个**定时炸弹**——玩家必须决定何时"处理"
- 高级 NPC（熟练度高的医生/建造师）被咬是重大事件
- 如果 NPC 在据点内丧尸化，会对其他 NPC 造成威胁

## 八、与 Stats 的联动

```
受伤事件
  ├──→ HP 立即扣除
  ├──→ 记录受伤部位（上半身/下半身）
  ├──→ Blood 持续流失（割伤/咬伤）         [IStatConsumable]
  ├──→ Infection 攀升（咬伤）               [IStatCumulative]
  ├──→ Pain 立即增加                        [IStatConsumable]
  ├──→ Stamina/MaxStamina 暂时降低（钝器伤）
  ├──→ MoveSpeed 降低（下半身骨折/烧伤）     [Derived]
  └──→ AttackSpeed 降低（上半身骨折/烧伤）   [Derived]

连锁反应:
  Blood → 0         → 失血死亡
  Infection → 阈值  → 丧尸化过程启动 → 死亡 + 变丧尸
  Pain → 高         → Consciousness 降低 → 操作迟钝/视野模糊
  Pain → 高         → 自然恢复速度减半
```

## 九、UI 表现

### 角色面板

伤病列表显示在角色面板中，每项显示：
- 伤害图标 + 类型名 + 部位 + 严重度
- 剩余恢复时间
- 当前状态（流血中/已包扎/已固定/感染中/恢复中）

### 丧尸化 UI

角色感染并进入恶化过程后：
- HP 条变色（绿色 → 暗红）
- 屏幕边缘逐渐出现暗红色晕影
- 阶段升级时弹出文字提示

### HUD 快速提醒

- HP 条旁边显示伤病状态图标（出血图标闪红 = 需要包扎）
- 新受伤时弹出简短文字提示（"手臂被丧尸咬伤"）
