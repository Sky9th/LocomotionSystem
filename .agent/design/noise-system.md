## 一、设计目标

在硬核生存中，噪音不是可有可无的细节——它是**所有行为的隐藏成本**。

"从这里破窗进去更快，但玻璃碎裂声会引来半条街的丧尸"——这就是噪音系统要创造的决策时刻。

核心原则：
- **每个行动都有音量** — 跑、打、砸、开枪，玩家时刻在制造噪音
- **噪音 = 风险** — 声音越大，吸引的丧尸越多、越远
- **安静有代价** — 潜行安全但慢，跑步快但暴露
- **简单可算** — 用半径模型，玩家能直观判断"多远能听到"

## 三、噪音传播

### 基础模型：球形半径

噪音源发出后，以声源为中心向四周扩散，超过半径范围的丧尸不受影响。

### 衰减规则

- 无遮挡：噪音半径 = 基础半径
- 隔一堵墙：噪音半径 × 衰减系数
- 隔一道门：噪音半径 × 衰减系数（门的衰减低于墙）
- 室内→室外：室内声音传出时额外衰减
- 多层衰减取乘积

> 衰减系数在数值统一规划时确定。

### 叠加

同一位置短时间内多次噪音：
- 多次同等级噪音 → 半径累积放大
- 存在放大上限，防止无限叠加
- 叠加在"持续窗口"内计数

> 叠加系数、窗口时长、上限在数值统一规划时确定。

## 四、丧尸反应

### 感知模型

丧尸有两种感知方式：

| 感知 | 机制 | 受什么影响 |
|------|------|-----------|
| 听觉 | 噪音半径内 → 警觉 → 向声源移动 | 噪音等级、障碍物衰减、距离 |
| 视觉 | 视线锥形范围（前方 ~120°）内看到 → 直接追击 | 光线（昼夜）、遮挡物 |

### 反应状态机

```
Idle（闲逛/静止）
  │
  ├── 听到噪音（在半径内）
  │   └──→ Alerted（警觉）→ 向声源方向移动
  │       │
  │       ├── 到达声源位置 → 检查周围
  │       │   ├── 看到玩家 → Chase（追击）
  │       │   └── 看不到 → Investigating（搜索）
  │       │       │
  │       │       ├── 10-15 秒搜索无发现 → 返回 Idle
  │       │       └── 期间听到新噪音 → 重新追踪
  │       │
  │       └── 移动途中看到玩家 → Chase（追击）
  │
  └── 直接看到玩家（视线内）
      └──→ Chase（追击）
```

### 噪音竞争

如果短时间内多个噪音源：
- 丧尸追踪**最新的**高声级噪音
- 如果噪音等级相同，追踪**最近的**
- 枪声（等级 5-6）会覆盖所有低级噪音

### 噪音记忆

- 噪音位置被丧尸短暂"记住"
- 到达噪音位置后，如果没看到玩家，进入搜索状态
- 搜索状态持续一段时间后冷却
- 搜索期间听到新噪音 → 重新锁定新位置

> 持续时长在数值统一规划时确定。

## 五、昼夜影响

| 时段 | 噪音半径 | 视觉范围 |
|------|----------|----------|
| 白天 | 基准 | 正常 |
| 黄昏 | 略微放大 | 缩小 |
| 夜晚 | 放大 | 极缩小 |

夜晚更安静 → 同样的噪音传播更远 → 白天可以跑，晚上必须潜行。但丧尸夜间视野差 → 听觉成为主要感知方式。

> 噪音倍率和视觉范围数值在统一规划时确定。

## 六、玩家应对策略

| 策略 | 噪音等级 | 代价 |
|------|----------|------|
| 潜行绕过 | 1 | 慢，需要耐心 |
| 投掷物品引开 | 3（落点） | 消耗物品，效果不保证 |
| 近战速战速决 | 3-4 | 打斗声吸引附近丧尸 |
| 枪声清场 | 5-6 | 大量丧尸被吸引，可能形成尸群 |
| 白天跑步赶路 | 中-高 | 比潜行快得多但风险大 |

核心设计意图：**枪是最后手段**。开枪能解决眼前的丧尸，但会制造更大的问题。

## 七、噪音类型

| 类型 | 说明 | 丧尸反应差异 |
|------|------|-------------|
| **人类活动** | 行走、奔跑、近战、建造、开门、说话 | 丧尸会积极追踪（Alerted → Investigate） |
| **武器/爆炸** | 枪声、爆炸 | 丧尸会**立即追击**（跳过 Investigate，直接 Chase），吸引半径额外扩大 |
| **环境** | 雷声、动物移动、风吹物体 | 丧尸会短暂警觉但**不追踪**（仅 Alerted，很快恢复 Idle） |
| **丧尸叫声** | 丧尸追击时发出的嘶吼 | 对其他丧尸效果同"人类活动"——触发连锁反应 |

设计意图：枪声是最危险的噪音类型，因为丧尸不经过搜索阶段直接进入追击。这让开枪的代价远超近战。

## 八、丧尸连锁反应

当一只丧尸发现玩家后：

```
开枪/近战 → 半径内几只丧尸 → Alerted + 开始追踪
  │
  └── 它们追击时会发出叫声
      │
      └── 叫声吸引更远处的丧尸 → Alerted
          │
          └── 它们也发出叫声 → 传播直到连锁层数上限
```

**雪球效应规则**：
- 丧尸叫声的噪音等级：追击嘶吼 = 中噪音，受伤尖叫 = 高噪音
- 连锁传播有最大层数限制（防止全图丧尸被一次枪声引动）
- 第 1 层：直接听到原始噪音的丧尸
- 第 2 层：听到第 1 层丧尸叫声的丧尸
- 超过最大层数的丧尸不受影响

> 连锁层数上限和丧尸叫声噪音等级在数值统一规划时确定。

## 九、潜行熟练度降噪

StealthProf 影响玩家制造的所有噪音：

| 潜行水平 | 效果 |
|----------|------|
| 未训练 | 无降噪 |
| 初阶 | 移动噪音 -1 级 |
| 中阶 | 移动噪音 -1 级 + 交互噪音 -1 级 |
| 高阶 | 移动噪音 -2 级 + 交互噪音 -1 级 |

- 降噪不适用于武器固有噪音（枪声等级不受潜行影响）
- 降噪效果叠加在昼夜倍率之上
- 等级阈值在数值统一规划时确定

## 十、数据集成

### CombatNoise（已有 Stats 节点）

Stats 树中已有 `CombatNoise` (Derived)，它由武器类型 + 移动状态派生：

```
CombatNoise = 武器基础噪音 × 移动倍率
  武器基础噪音: 由武器类型决定
  移动倍率: 静止 < 潜行 < 走路 < 跑步

> 具体数值在统一规划时确定，由武器和移动状态的噪音等级映射表驱动。
```

### 噪音事件数据

```csharp
// 噪音事件 — 通过 EventDispatcher 发布
struct SNoiseEvent
{
    Vector3 sourcePosition;  // 声源世界坐标
    float radius;            // 最终传播半径（考虑衰减）
    int level;               // 噪音等级 1-6
    ENoiseType type;         // HumanActivity / WeaponExplosion / Environment / ZombieCall
    GameObject source;       // 声源对象
    int cascadeDepth;        // 连锁层级（0=原始噪音，1=第一层丧尸叫声，2=第二层）
}
```

丧尸 AI 系统订阅 SNoiseEvent，根据类型和连锁层级决定反应行为。
