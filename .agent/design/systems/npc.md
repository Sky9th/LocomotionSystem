# NPC 系统 + 士气系统设计

> 日期: 2026-07-09
> 状态: 设计阶段，核心方向已确认
> 关联: `game-overview.md` NPC系统 / `stats-inventory.md` Needs 节点 / `injury.md` NPC共用伤病 / `actor-tree-design.md` Human StatsTree

---

## 一、系统定位

NPC 是维持基地运转的必要劳动力。他们不是消耗品，而是值得长期培养的伙伴资产。

- **可指挥**：玩家随时框选 NPC 下达指令，环世界式直接控制
- **可成长**：持续工作提升熟练度与等级，正向反馈投入
- **值得保护**：高等级 NPC 的损失是重大挫折，形成保护动力

士气系统与 NPC 系统紧密绑定——**士气仅影响 NPC，不影响玩家**。它是 NPC 工作效率和成长速度的调节器，由饮食、居住、威胁等多因素驱动。

---

## 二、核心设计原则

1. **NPC 是培养资产** — 熟练度、等级、特殊分工构成长期投入，损失一个高级 NPC 比损失装备更痛
2. **指令优先于自主 AI** — 玩家控制权是第一优先级；无指令时 NPC 按需求驱动自主行动
3. **无工具则无工作** — 工作类型全开放，但没有对应实物工具就无法执行
4. **士气是效率杠杆** — 高士气加速工作与成长，低士气反之；管理士气是据点运营的核心课题
5. **损失不可避免但可控** — 尸潮、探索、意外可能造成 NPC 伤亡，但玩家通过防御、装备、战术可以最小化风险

---

## 三、与其他系统的接口

| 系统 | 对本系统的输入 | 本系统的输出 |
|------|--------------|------------|
| **农业与烹饪** | NPC 消耗食物；食物品质影响士气 | NPC 从事种田/烹饪工作 |
| **建造系统** | NPC 需要床位和居住空间；建造需要工具 | NPC 参与建造工作 |
| **资源系统** | NPC 需要工具；工具消耗耐久 | NPC 通过采集/制作产出资源 |
| **战斗系统** | NPC 需要武器；受伤需治疗 | NPC 参与防御，可随玩家出征 |
| **科技树** | 高级工具/设施需科技解锁 | NPC 工作产出支撑科技发展 |
| **尸潮事件** | 尸潮威胁 NPC 生存 | NPC 在尸潮中的行为影响防御结果 |
| **伤病系统** | NPC 共用完整伤病系统（含丧尸化） | 伤病 NPC 无法工作，占据医疗资源 |
| **士气系统** | 士气值直接影响 NPC 工作效率与成长速度 | NPC 的行为结果（伤亡、成就）反馈士气 |

## 四、NPC 基础属性

每个 NPC 拥有一组核心属性，部分与玩家共用 StatsTree（详见 `actor-tree-design.md` 的 Human 节点），部分为 NPC 专属：

### 共用属性（Human StatsTree）

| 属性 | 类型 | 范围 | 说明 |
|------|------|------|------|
| HP | Bounded | 0~MaxHP | 生命值。归零死亡 |
| Hunger | Consumable | 0~100 | 饥饿。归零扣 HP |
| Stamina | Consumable | 0~MaxStamina | 体力。工作/战斗消耗 |
| Sleepiness | Consumable | 0~100 | 困意。>50 效率惩罚，>80 强制休息 |
| Infection | Cumulative | 0~100 | 感染值。被咬伤后累积，达阈值触发丧尸化 |

### NPC 专属属性

| 属性 | 类型 | 范围 | 说明 |
|------|------|------|------|
| Morale | Bounded | 0~100 | 士气。50 = 中性基准，影响工作效率与熟练度获取速度 |
| Loyalty | Cumulative | 0~100 | 忠诚度。累积至阈值提升等级，影响指令服从概率和离队倾向 |
| WorkEfficiency | Derived | — | 工作效率系数。由 `Morale × 0.5 + 最高熟练度 × 0.5` 派生 |
| Proficiency | 多轨并行 | 0~100（单轨） | 各工作类型的独立熟练度，见成长机制 |
| Level | 多轨并行 | 1~上限 | 各工作类型的独立等级，由熟练度阈值决定 |

### 属性之间的联动

```
Hunger → 0      → HP 持续流失 → 死亡
Sleepiness > 50 → WorkEfficiency 打折
Sleepiness > 80 → 强制前往床位休息
Morale → 高低   → WorkEfficiency 乘算修正 + 熟练度获取速率修正
Infection → 阈值 → 丧尸化四阶段 → 死亡 + 变丧尸（同玩家，详见 injury.md）
```

## 五、玩家控制机制

采用环世界式控制模型：**框选 → 右键指令**。

### 即时指令

- 框选单个或多个 NPC
- 右键目标下达指令：移动到指定点、攻击目标、使用设施、跟随玩家、拾取物品
- 指令立即生效，NPC 中断当前行为执行指令
- 指令完成后，NPC 恢复自主 AI 或返回上一个长期任务

### 长期任务指派

通过据点管理界面为 NPC 分配长期工作任务：
- 选择 NPC → 指定工作类型 → 设定优先级（1~4 级）
- NPC 按优先级自动执行对应工作，无需玩家反复操作
- 工作执行受工具可用性、设施可用性、自身状态（饥饿/困意）约束
- 玩家可随时修改指派，即时指令优先于长期任务

### 优先级规则

```
玩家即时指令 > 长期任务指派 > 自主 AI（需求驱动）
```

### 自主 AI 行为（无指令时）

按需求驱动：
1. 饥饿低于阈值 → 前往仓库取食物进食
2. 困意高于阈值 → 前往床位睡眠
3. HP 低于阈值 + 有可用医疗品 → 自行治疗
4. 被攻击 → 自卫反击（如有武器）或逃跑（如无武器或血量过低）
5. 无紧急需求 → 执行长期任务；无任务则待机

## 六、工作类型与工具限制

### 工作类型（全开放）

| 工作类型 | 活动内容 | 必需工具/设施 | 产出 |
|----------|---------|-------------|------|
| 种田 | 开垦、播种、浇水、收获 | 锄头（开垦） | 食材 |
| 建造 | 放置建筑、修复建筑 | 锤子 | 建筑/修复值 |
| 烹饪 | 在灶台/篝火制作食物 | 厨具 + 灶台/篝火 | 食物 |
| 采集 | 砍树、采矿、采集植物 | 斧头（砍树）/ 镐子（采矿） | 材料 |
| 制作 | 在工作台制造物品 | 对应工具 + 工作台 | 工具/零件/物品 |
| 战斗 | 防御据点、随玩家出征 | 武器 | 安全/战利品 |
| 搬运 | 将资源从掉落点运回仓库 | 无 | 资源入库 |

### 工具限制规则

- **工具为实物物品** — NPC 背包中必须有对应工具才能执行工作
- **无工具 = 无法工作** — NPC 不会凭空工作，系统检测工具是否存在
- **设施绑定** — 烹饪需要灶台/篝火，制作需要工作台，设施不存在则无法执行
- **武器单独管理** — 战斗工具即武器，与工作工具分开装备

## 七、工具获取、消耗与维修

### 双轨获取

| 轨道 | 说明 | 特点 |
|------|------|------|
| 搜刮 | 从地图建筑/容器中获取 | 主要来源，质量随机，不可控 |
| 制作 | 在工作台消耗材料制造 | 后期补充，质量可控，需科技解锁配方 |

### 耐久与消耗

- 所有工具有耐久度（Durability），每次使用消耗一定耐久
- 耐久归零 → 工具损坏，从 NPC 背包中移除
- NPC 自动从仓库中取用耐久最高的可用工具
- 工具损坏时 NPC 中断工作，寻找替代工具；无替代则暂停该任务

### 维修系统

- 工具可在工作台消耗对应材料维修
- 维修恢复耐久值，恢复量与维修者熟练度正相关
- 不同工具的维修材料配方不同（如斧头需石材/金属 + 木材）
- 过度维修有耐久上限衰减（每次维修后最大耐久略微下降），最终需替换

### 消耗速率设计意图

工具消耗是资源循环的隐形驱动力。玩家必须持续获取材料来维修或替换工具，确保搜刮行为始终有价值，避免"一套工具用到通关"。

## 八、任务分配机制

### 长期指派流程

```
玩家打开据点管理界面
  → 选择 NPC
  → 设定工作优先级矩阵（可为每个 NPC 单独配置，也可使用全局模板）
  → NPC 按优先级 + 自身熟练度自动选择当前最优工作
```

### 工作执行流程

```
NPC 检查优先级最高的工作类型
  → 检查是否有可用工具
  → 检查是否有可用设施
  → 检查自身状态（非饥饿/非极度困倦/非受伤无法工作）
  → 前往工作地点 → 执行工作动作 → 产出 + 熟练度累积
  → 工作间隙按需进食/休息
```

### 专业化 vs 多面手

- **专业化优势**：专注一种工作的 NPC 熟练度提升更快，效率更高
- **多面手优势**：灵活应对突发需求（如尸潮后需全员修复建筑）
- **推荐策略**：核心岗位（厨师、医生）专业化，其余 NPC 保持 2-3 项工作能力
- 专业化程度由玩家通过任务指派决定，系统不强制限制

## 九、成长机制

### 熟练度积累

- 每次成功完成工作动作 → 增加对应工作类型的熟练度（Proficiency）
- 熟练度累积值受当前 Morale 修正：高士气 → 累积加速；低士气 → 累积减速
- 不同工作类型的熟练度独立计算，不互相影响

### 等级提升

- 熟练度达到阈值 → 该工作类型等级 +1
- 等级提升带来三重效率增益：

| 增益维度 | 效果 | 示例 |
|----------|------|------|
| 工作速度 | 完成单次动作时间缩短 | Lv.1 种田 10s → Lv.5 种田 6s |
| 产出质量 | 高品质产出概率提升 | 高品质食物士气加成更高 |
| 消耗节省 | 工具耐久消耗 / 材料消耗降低 | Lv.5 建造消耗材料 -20% |

- 等级上限与科技树绑定：基础上限 Lv.5，科技解锁后可提升至 Lv.10

### 成长曲线设计意图

成长分为三个阶段：
- **新手期 (Lv.1-3)**：快速成长，让玩家迅速感受到投入回报
- **熟练期 (Lv.4-6)**：成长放缓，效率已经可观，维持动力
- **专家期 (Lv.7-10)**：缓慢成长，需要科技解锁上限，专家的不可替代性凸显

### 士气对成长的影响

- 士气 > 50：熟练度获取速率提升（最高 +50% at Morale 100）
- 士气 < 50：熟练度获取速率下降（最低 -50% at Morale 0）
- 这意味着：管理士气不只是维持效率，更是加速 NPC 成长的关键手段

## 十、招募方式

### 招募流程

```
探索中遭遇幸存者
  → 玩家靠近触发对话
  → 对话展示幸存者基础信息和加入条件
  → 满足条件（据点有空余床位 + 基础资源）→ 可选择招募
  → 幸存者加入据点，成为可指挥 NPC
```

### 幸存者来源

| 来源 | 触发方式 | 特点 |
|------|---------|------|
| 探索遭遇 | 在地图建筑中随机出现 | 最常见，幸存者可能有特殊属性或已有熟练度 |
| 尸潮后救援 | 尸潮结束后概率出现受伤幸存者 | 需要紧急医疗，但可能具有高级战斗熟练度 |
| 无线电呼叫 | 科技解锁无线电后可使用 | 主动呼叫，可控但消耗资源 |

### 招募条件

- 据点有空余床位（1 NPC = 1 床位）
- 据点有基础食物储备（满足新 NPC 数日口粮）
- 部分幸存者可能有额外要求（如特殊物品、完成小任务）

### 幸存者属性随机

招募的幸存者拥有随机的基础属性（Strength/Agility 等）、随机初始熟练度（可能已有部分工作经验）和随机性格倾向（影响士气基准值、忠诚度变化率等隐性参数）。

## 十一、尸潮行为规则

### 指令优先

- 尸潮期间，玩家指令无条件优先
- 玩家可指挥 NPC 前往防御位置、攻击特定目标、操作防御设施、前往安全区域

### 无指令行为（自主）

| 情境 | 行为 |
|------|------|
| 持有武器 + 被攻击 | 自卫反击，优先攻击最近的攻击者 |
| 持有武器 + 未被攻击 | 按长期任务中的战斗优先级决定是否主动出击 |
| 无武器 | 向远离丧尸的方向逃跑 |
| HP < 30% | 无论有无武器，优先逃跑保命 |
| 附近有受伤同伴 | 有一定概率前往掩护（受 Loyalty 影响） |

### 尸潮后效对 NPC 的影响

- 尸潮中 NPC 受伤 → 消耗医疗资源，暂时无法工作
- 尸潮中 NPC 死亡 → 永久损失，其他 NPC 士气下降（减幅与死亡 NPC 的 Loyalty 正相关）
- 尸潮成功防守（无 NPC 死亡）→ 全体 NPC 士气小幅提升
- 建筑受损 → NPC 建造工作需求增加，修复优先级提升

## 十二、士气系统

士气仅影响 NPC，是据点运营的"温度计"——反映 NPC 的整体满意度，直接影响工作效率和成长速度。

### 士气影响因素

#### 正面因素

| 因素 | 影响程度 | 说明 |
|------|---------|------|
| 食物多样性 | 高 | 连续多日食用不同食谱 → 士气持续提升 |
| 高品质食物 | 中-高 | 复杂食谱产出的食物提供额外士气加成（一次性） |
| 舒适居住环境 | 中 | 独立床位、室内空间、温度适宜 → 缓慢持续提升 |
| 尸潮防守胜利 | 低-中 | 短暂提升，无 NPC 死亡时触发 |
| 忠诚事件 | 低 | NPC 间的社交正面事件（未来扩展） |

#### 负面因素

| 因素 | 影响程度 | 说明 |
|------|---------|------|
| 单调饮食 | 中 | 连续多日食用同一种食物 → 士气缓慢下降 |
| 食物短缺 | 高 | 饥饿值长期偏高或断粮 → 士气快速下降 |
| 恶劣居住环境 | 中 | 无床位（睡地板）、拥挤、露天 → 缓慢持续下降 |
| 雾区威胁 | 低-中 | 据点靠近雾区 → 持续性士气压迫；雾区扩张靠近据点 → 士气加速下降 |
| NPC 死亡 | 高 | 同伴在尸潮/探索中死亡 → 全体士气骤降（与死亡 NPC 的 Loyalty 正相关） |
| 尸潮防守失败 | 中 | 建筑被毁、人员伤亡 → 士气大幅下降 |

### 士气变化机制

- 士气不是瞬时值，而是有惯性：变化以每日结算为主，事件触发瞬时修正为辅
- 食物多样性按"滚动窗口"计算——取过去 N 天的食谱种类
- 居住环境按"据点评分"计算——床位数量 vs NPC 数量、是否有屋顶、人均空间
- 雾区威胁按"据点距最近雾区边缘距离"计算——距离越近惩罚越重

### 士气与效率的关系

```
WorkEfficiency = Morale × 0.5 + 最高熟练度 × 0.5
```

- Morale = 50（中性基准）→ WorkEfficiency 仅由熟练度决定
- Morale > 50 → WorkEfficiency 获得额外加成
- Morale < 50 → WorkEfficiency 受到惩罚
- 极端低士气（< 20）→ NPC 可能拒绝工作或出现消极行为（怠工、浪费材料）

### 士气与成长速度的关系

- 熟练度获取速率 = 基础速率 × 士气修正系数
- Morale = 50 → 修正系数 = 1.0（基准速度）
- Morale > 50 → 修正系数递增（最高 1.5 at Morale 100）
- Morale < 50 → 修正系数递减（最低 0.5 at Morale 0）

### 尸潮结果对士气的影响

| 结果 | 士气影响 | 持续时间 |
|------|---------|---------|
| 完美防守（无伤亡、建筑完好） | +5~10 | 3 天 |
| 轻损防守（有建筑受损、无死亡） | -2~0 | 1 天 |
| 重损防守（有 NPC 死亡） | -10~20（每人） | 7 天 |
| 溃败防守（多 NPC 死亡、大量建筑被毁） | -20~30 | 14 天 |

## 十三、设计意图总结

NPC 系统的核心体验循环：

```
招募幸存者 → 分配工具/任务 → NPC 工作产出 → 维持据点运转
                                        ↓
                                  熟练度成长 → 效率提升
                                        ↓
                        玩家感受到投入回报 → 产生保护欲
                                        ↓
                    尸潮/意外造成 NPC 损失 → 重大挫折
                                        ↓
                    激励玩家改善防御/装备/士气管理
                                        ↓
                          循环深化，形成情感绑定
```

士气系统在这个循环中充当"软性约束"——它不会直接导致游戏失败，但低士气会让据点逐步失速：效率下降 → 产出减少 → 食物短缺 → 士气进一步下降。维持士气需要玩家在食物多样性、居住条件、防御安全之间持续投入资源，防止陷入恶性循环。
