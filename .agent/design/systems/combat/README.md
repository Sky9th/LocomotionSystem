# 战斗系统总览

> 日期: 2026-07-09
> 状态: 设计阶段，核心方向已确认
> 关联: `game-overview.md` 战斗系统 / `damage-model.md` 伤害地基

---

## 系统定位

战斗系统是玩家角色与游戏世界进行物理交互的核心管道——通过 Ability 管道驱动武器动作、装备注入伤害基底、管道修正结算最终效果。一句话：**装备决定打多疼，技能决定怎么打，人决定加成多少。**

---

## 核心设计原则

| 原则 | 说明 |
|------|------|
| **装备定义伤害基底** | 近战武器的 baseDamage、弹药的 EffectSO 是伤害计算的起点。一把生锈的刀和精制钢刀是不同的物理物体 |
| **Ability 为动作模式** | 技能定义"怎么打"（搜索形状、前摇、冷却），不定义伤害数值。伤害从装备运行时注入管道 |
| **管道统一结算** | 所有伤害走八维度 Ability Pipeline：②门控→③扣费→④搜索→⑤效果→⑥结算→⑦反应→⑧广播 |
| **近战有人物修正，枪械没有** | 力量影响挥砍力度（管道⑤ IEffectModifier），但子弹动能不随开枪的人变化。感知影响枪械命中率，不影响伤害 |
| **操作以鼠标为主，键盘为辅** | 鼠标左键普攻是最频繁的操作；快捷键（Q/E/R/F）释放技能，切换武器时技能栏自动切换 |
| **弹药即伤害基底** | FMJ/JHP/AP 是不同的 EffectSO，换弹 = 换装备，不是换技能 |

---

## 操作方式

| 操作 | 功能 | 说明 |
|------|------|------|
| 鼠标左键 | 普通攻击 | 最频繁的操作。对目标点击即释放当前武器的普攻技能 |
| Q / E / R / F | 技能快捷键 | 释放当前武器的 4 个主动技能。切换武器时技能栏自动刷新 |
| Tab / 滚轮 | 切换武器 | 切换后技能栏立即替换为新武器的技能组 |

## 武器类型

游戏提供 6 种武器类型，覆盖近战和热武器两条路线。每种武器捡到即自动学会其基础技能组（3-5 个 Ability）。

| 大类 | 武器类型 | 代表武器 | 伤害类型 | 核心特点 | 易得理由 |
|------|---------|---------|---------|---------|---------|
| 近战 | 刀 | 厨房刀、猎刀 | Slash / Pierce | 快速、破防、单挑强 | 民宅厨房、五金店 |
| 近战 | 棍 | 棒球棍 | Blunt / 控制 | 范围大、硬直控场 | 体育用品店、车库 |
| 近战 | 斧 | 消防斧、伐木斧 | Slash / 重击 | 慢速、极高单发伤害 | 消防箱、工具店 |
| 热武 | 手枪 | 9mm 手枪 | Pierce（弹药决定） | 灵活、弹药相对充裕、移动射击 | 民宅、警察局、枪店 |
| 热武 | 霰弹枪 | 12 号霰弹枪 | Pierce（弹药决定） | 近距王者、扇形毁伤、极高噪音 | 农场、警车 |
| 热武 | 步枪 | .22 LR 步枪、民用 AR-15 | Pierce（弹药决定） | 远距精准、弹药最稀有 | 猎户家中、枪店 |

> **A 测近战排序**：刀（快速/破防）< 棍（范围/控制）< 斧（慢速/重击）。高级玩法中，武器可与武学套路（Martial Arts Routine）组合，形成连击链。

## 伤害模型

> 详见 [damage-model.md](damage-model.md) — 装备决定伤害地基，人物和环境做加减乘除。

核心公式：

```
伤害 = 装备基底 × 人物修正 × 环境修正 × 命中修正
```

管道流向：装备基底在管道⑤注入 → 近战经 IEffectModifier 乘算修正 → 目标侧 IResolutionModifier 护甲/抗性对抗 → 最终伤害。

---

## 与其他系统的接口

| 系统 | 输入 | 输出 |
|------|------|------|
| **装备系统** | 武器提供 baseDamage；弹药提供 EffectSO（伤害基底）；护甲提供 armorValue | 战斗消耗武器耐久、消耗弹药；护甲承受伤害消耗耐久 |
| **属性系统** | 力量（近战伤害修正）、感知（枪械命中率/散布）、体力（近战技能消耗） | 命中敌人增加对应武器熟练度 |
| **噪音系统** | 技能释放产生噪音事件（近战命中 Lv4、手枪 Lv5、步枪/霰弹 Lv6） | 噪音半径内丧尸被吸引，触发听觉反应状态机 |
| **伤病系统** | 敌人攻击造成割伤/咬伤/钝器伤/骨折，走统一伤害管道 | 玩家伤害造成丧尸受伤反馈（硬直/击退/死亡） |
| **科技树** | 高级武器/弹药/护甲需科技解锁 | 战斗熟练度支撑探索更危险区域 |
| **尸潮模式** | 尸潮提供高强度战斗场景 | 战斗表现影响尸潮结果 |
| **生存指标** | 战斗消耗体力、受伤影响生命/流血/感染 | 战斗胜利获得食物/资源支持生存 |
| **AI 系统** | 噪音事件驱动丧尸听觉反应；视觉感知驱动追击 | 击杀丧尸反馈 AI 死亡状态 |
