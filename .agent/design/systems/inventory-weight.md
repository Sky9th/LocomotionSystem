# 负重与背包系统设计

> 日期: 2026-05-23
> 状态: 设计阶段
> 关联: `../game-overview.md` 资源与工具系统 / `../data/stats-inventory.md` Movement 节点 / `injury.md` 伤病

---

## 一、设计目标

硬核生存的核心在于"选择"——背包容量和负重上限迫使玩家在每次出门前做取舍。

"这把斧头能砍更多树，但占用的负重可以装 3 罐食物。到底带不带？"

核心原则：
- **每个物品都有重量** — 没有免费的午餐
- **负重有等级** — 不是能/不能的二元切换，而是逐渐恶化的代价
- **背包是重要装备** — 背包类型决定容量上限，本身也有重量
- **出门是一场规划** — 带什么武器、带多少食物、留多少空间装战利品

## 二、负重模型

### 核心公式

```
负重比 = 当前总负重 / 负重上限 × 100%
```

- 当前总负重 = 所有携带物品的重量之和（含装备、背包自身）
- 负重上限 = 基础负重 + 背包加成 + 属性加成（Strength 影响）

### 负重等级

| 等级 | 负重比 | 移速惩罚 | 冲刺 | 体力消耗 | 典型场景 |
|------|--------|----------|------|----------|----------|
| 轻载 | 低 | 无 | 可冲刺 | 正常 | 刚出门，少量装备 |
| 中载 | 中 | 轻微降低 | 可冲刺 | 微增 | 带齐装备和补给 |
| 重载 | 高 | 明显降低 | 不可冲刺 | 增加 | 战利品装满了 |
| 超载 | 超出上限 | 只能慢走 | 不可冲刺 | 快速消耗 | 贪心拿太多了 |

> 各等级的具体阈值百分比在数值统一规划时确定。

### 超载的额外惩罚

软上限设计——超载不会阻止拾取，但代价快速累积：

- 移速降至最低（只能慢走）
- 体力持续消耗（负重越大消耗越快——扛着重物赶路终会力竭）
- 体力耗尽 → 无法移动，必须原地丢弃物品才能继续
- 无法跳跃、无法冲刺
- 无法使用某些武器（需要双手的重武器等）

设计意图：创造"能不能扛到家"的赌博时刻。扔掉一些战利品就能走快一点，但每件都是冒险的回报。

## 三、背包系统

### 基础容量

角色始终有一定的基础携带能力（口袋、腰带、手持），在没有背包的情况下也能携带少量物品。

### 背包类型

| 类型 | 负重加成 | 自身重量 | 额外功能 | 获取 |
|------|----------|----------|----------|------|
| 无背包 | — | — | 仅基础容量 | 初始自带 |
| 小背包 | 少量 | 轻 | — | 初始/搜刮（常见） |
| 中型背包 | 中等 | 中 | + 快速使用栏位 | 搜刮（中等稀有） |
| 大背包/登山包 | 大量 | 重 | + 快速使用栏位 + 睡袋挂载 | 搜刮（稀有） |
| 军用背包 | 最大 | 很重 | + 快速使用栏位 + 护甲挂载 | 搜刮（极稀有）、军事基地 |

> 背包的具体容量值和重量在数值统一规划时确定。

### 背包的取舍

背包本身有重量——大背包虽然容量大，但空背包就占了不少负重。这意味着：
- 小背包适合短途搜刮（轻便，留更多空间给战利品）
- 大背包适合长途远征（需要带更多补给和装备）
- 没有"最好"的背包，只有最适合当前目标的

---

## 四、纯重量制

背包仅按重量限制，没有格子/空间维度：

- 每个物品有一个重量值
- 总负重 = 所有携带物品重量之和，不超过负重上限（或超过上限进入超载惩罚）
- 不存在"占几格"的概念——子弹轻可以带很多，发电机重自然带不动

优势：
- 规则简单直观，玩家一眼就能算出"还能拿多少"
- UI 简洁，不需要网格拼图
- 用重量差异（子弹轻/木材重）自然制造选择

---

## 五、背包可丢弃

背包不是锁定在装备栏上的——玩家可以随时丢弃背包：

- 丢弃背包 → 背包内所有物品连同背包本身一起掉落在地
- 丢弃后立即减轻负重，恢复移速
- 被丧尸追击时，扔包轻装逃跑是有效策略
- 代价：装备和战利品全丢，需要回头找（可能已经不安全了）

这也意味着：
- 你可以捡到别人的背包（含物品）——搜刮效率更高
- 敌人/NPC 也可能掉落背包
- 死亡后，你的背包（含所有物品）遗留在死亡地点

## 六、物品重量参考

所有物品有一个重量值，遵循现实逻辑：

| 物品类型 | 相对重量 | 例 |
|----------|----------|-----|
| 消耗品（单件） | 极轻 | 绷带、火柴、子弹 |
| 消耗品（堆叠） | 轻-中 | 食物罐、水瓶 |
| 工具 | 中-重 | 斧头、锤子、锯子 |
| 武器（近战） | 中 | 小刀 < 砍刀 < 斧头 |
| 武器（远程） | 中-重 | 手枪 < 步枪 < 霰弹枪 |
| 建筑材料 | 重 | 木材、石材、金属板 |
| 大型物品 | 极重 | 发电机、家具 |

> 具体重量值在数值统一规划时为每个物品单独设定。

## 七、与 Stats 的联动

Stats 树中已有相关节点：

```
Movement
├── CarryWeight        负重上限        [Bounded]  { ← Strength, 背包加成 }
├── CurrentWeight       当前负重        [Bounded]  { = 所有物品重量之和 }
└── MoveSpeed           移动速度        [Derived]  { ← Agility, 负重比, 伤病 }

Attributes
└── Strength            力量            [Bounded]  { → CarryWeight 加成 }
```

### 伤病影响

- 下半身骨折 → CarryWeight 暂时降低（负重上限减少，可能突然超载）
- 上半身骨折 → 物品使用速度降低
- 疼痛高 → 负重体感加重（负重比 × 额外系数）

## 八、UI 表现

### 背包界面

- 格子式物品列表，每格显示图标 + 堆叠数
- 底部显示：当前负重 / 负重上限 + 负重等级标签
- 负重条颜色变化：轻载正常色 → 重载黄色 → 超载红色

### HUD 快速提醒

- 负重接近上限时，负重条变色警告
- 超载时屏幕边缘闪烁红色
- 拾取物品时如果超过负重上限，弹出提示"负重已满"

### 物品 Tooltip

鼠标悬停在物品上显示：
- 物品名称
- 重量
- 类型标签
- 简要描述

## 九、玩家决策场景

### 出门前的规划

```
目标：去小镇搜刮医疗用品
环境：白天，预计来回 2 小时

决策：
- 带大背包（装更多战利品，但重）还是小背包（轻快，但装得少）？
- 带斧头（防御用，但重）还是小刀（轻但伤害低）？
- 带 3 罐食物和 2 瓶水（充足但重）还是 1 罐 1 瓶（轻但可能不够）？
- 留多少负重空间给战利品？
```

### 搜刮中的取舍

```
在药店找到：
- 抗生素 ×2（轻、救命、稀有）
- 绷带 ×10（轻、常用）
- 消毒剂 ×3（中等重量）
- 止痛药 ×5（轻）

负重还剩 X 单位。全部带走刚好超载。
超载走回去 → 体力消耗加速，可能走不到家。
必须取舍——留什么？扔什么？
```
