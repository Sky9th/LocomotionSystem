## 一、系统定位

尸潮是打破静态生存循环的**动态干扰事件**。在没有尸潮的日子里，玩家按部就班地种田、建造、搜刮——节奏趋于平稳。尸潮的作用是周期性地打断这种平稳，迫使玩家在"发展"与"防御"之间做出资源分配。

更深一层，尸潮是**成长检验器**。玩家花数日升级的防御工事、培养的 NPC 战斗力、囤积的弹药储备，在尸潮来临时接受集中检验。扛住了——成长得到正反馈；没扛住——暴露出短板，驱动下一轮发展。

尸潮的第三个作用是**制造叙事张力**。一次惨烈的尸潮过后，据点满目疮痍，NPC 士气低落，玩家在废墟中清点损失——这是末世生存最具沉浸感的时刻。

## 二、核心设计原则

### 2.1 完全伪随机

尸潮触发不使用真随机，而是**伪随机分布**（Pseudo-Random Distribution, PRD）。每次未触发增加下一次的触发概率，触发后重置。这避免了真随机的两个痛点：连续触发（太残酷）和长期不触发（太无聊）。

### 2.2 规模正相关

尸潮规模与据点综合评分**正相关**，不存在"碾压式"尸潮——规模总是与玩家当前水平匹配，提供一个**有挑战但可应对**的压力。同时设置了规模下限和上限，保证小据点不会被一波带走，大据点不会毫无压力。

### 2.3 构成随机

每次尸潮的丧尸类型比例在预设范围内随机生成，确保重复可玩性。同一规模的两次尸潮，可能一次以基础丧尸为主（数量多但好打），一次掺杂特殊丧尸（数量少但棘手）。

## 三、与其他系统的接口

| 系统 | 输入（尸潮依赖什么） | 输出（尸潮影响什么） |
|------|---------------------|---------------------|
| **战斗系统** | 依赖玩家战斗熟练度和武器储备 | 提供高强度战斗场景；尸潮期间击杀丧尸可加速熟练度成长 |
| **NPC 系统** | NPC 参与防御，人数和战斗力影响结果 | NPC 可能受伤或死亡；尸潮后 NPC 士气大幅波动（详见第十一节） |
| **建造系统** | 依赖防御工事（围墙、大门、陷阱）的强度和布局 | 建筑受损，需要修复；激励玩家持续升级防御 |
| **资源系统** | 消耗弹药、武器耐久、医疗用品、工具耐久 | 驱动资源补充循环；尸潮后产生战利品（详见第十一节） |
| **科技树** | 高级防御科技（加固围墙、自动炮塔等）显著降低尸潮损失 | 尸潮凸显防御科技的价值，驱动玩家优先解锁相关节点 |
| **噪音系统** | 尸潮期间的战斗噪音可能吸引额外游离丧尸加入 | 尸潮警报本身是高噪音事件（等级 6），可能触发更广范围的丧尸连锁反应 |
| **士气系统** | — | 尸潮结果直接影响 NPC 士气变化（详见第十一节） |
| **伤病系统** | — | 尸潮是 NPC 和玩家受伤的主要场景之一，咬伤带来感染风险 |

## 四、触发机制

### 4.1 判定周期

每日进行一次尸潮触发判定。判定时机为每日结算阶段（黄昏或黎明，具体时间点由游戏节奏最终确定后锁定）。

### 4.2 伪随机算法

采用标准 PRD 模型，参数如下：

| 参数 | 说明 | 设计意图 |
|------|------|---------|
| 基础概率 C | 每次判定的基础触发概率 | 控制尸潮平均间隔 |
| 递增幅度 | 每次未触发时概率增加的量 | 控制概率爬升速度，保证不会长期不触发 |
| 触发后重置 | 触发后概率回到基础值 | 避免连续尸潮 |
| 无冷却期 | 触发后第二天即可再次判定 | 极端情况下允许短时间内两次尸潮，但不做硬性限制 |

概率上限为 100%（即连续未触发达到一定天数后必然触发），防止无限期不触发。

### 4.3 概率影响因素

基础概率 C 并非固定值，受以下因素动态修正：

- **母体距离与数量**：据点周边母体越多、距离越近，基础概率越高。母体是尸潮的根本驱动力。
- **近期噪音积累**：据点区域近期（过去 N 日）累积噪音量越高，概率修正越大。频繁在据点附近开枪或建造会增加"被发现"的风险。
- **雾区覆盖率**：据点所在区域的雾区覆盖率越高，概率修正越大。

> 具体 C 值、递增幅度和修正系数在数值统一规划时确定。

### 4.4 触发后流程

```
尸潮触发
  → 检测据点综合评分 → 确定尸潮规模（丧尸总数、波次、持续时间）
  → 确定尸潮构成（各类型比例随机）
  → 生成丧尸波次表
  → 预警阶段开始（详见第七节）
  → 丧尸从地图边缘多方向生成并移动
  → 战斗阶段（持续至丧尸全灭 or 时间结束剩余丧尸撤退）
  → 后效结算（详见第十一节）
  → 概率重置为 C
```

## 五、规模与强度

### 5.1 据点综合评分

尸潮规模由**据点综合评分**决定。评分为多维度加权求和：

| 维度 | 包含内容 | 权重说明 |
|------|---------|---------|
| **人口** | 玩家 + NPC 总人数 | 人越多，尸潮越大——丧尸"感知"到更多生命 |
| **基建** | 建筑总面积、防御建筑等级和数量 | 据点越大越显眼 |
| **科技** | 已解锁科技节点总数、高级节点数量 | 科技水平暗示据点发展程度 |
| **战力** | 玩家武器熟练度、NPC 战斗等级、武器/弹药储备量 | 战力越高，匹配更强尸潮 |
| **生存** | 食物储备天数、医疗物资储备、士气平均值 | 生存状况越好，"吸引"的丧尸越多 |

每个维度下设子项，最终综合评分 = Σ(维度分数 × 维度权重)。维度权重设计倾向：**人口权重最高**（丧尸对生命感知最强），基建和战力次之，科技和生存权重较低。

### 5.2 规模映射

综合评分映射到三个核心参数：

| 参数 | 说明 | 映射关系 |
|------|------|---------|
| **丧尸总数** | 本次尸潮的丧尸总数 | 与评分正相关，存在下限和上限 |
| **波次** | 尸潮分为几波进攻 | 高分 → 多波次（波间有短暂间隙供玩家补给） |
| **持续时间** | 从第一只丧尸出现到最后一只的时长 | 与总数和波次联动计算 |

单波丧尸数量 = 总数 / 波次。波间间隙随波次递增而缩短（越往后越紧）。

### 5.3 规模限制

- **下限**：综合评分极低的据点（如新开局），尸潮规模有最小值，避免毫无游戏体验。
- **上限**：综合评分极高时，尸潮规模触及上限，防止性能问题和无解局面。
- **平滑曲线**：评分→规模的映射使用平滑曲线（非阶梯），避免在阈值附近出现突变。

## 六、尸潮构成

### 6.1 丧尸类型

| 类型 | 特征 | 行为差异 |
|------|------|---------|
| **基础型** | 普通丧尸，移速慢，血量低，无特殊能力 | 数量最多的填充单位，依靠数量消耗弹药和防御耐久 |
| **进阶型** | 移速更快、血量更高，或具有攀爬/跳跃能力 | 可越过低级围墙，对防线薄弱点构成突破威胁 |
| **特殊型** | 具有特殊能力：爆炸（自爆丧尸）、喷吐（远程攻击）、召唤（触发更多丧尸）、重型（高血量+高伤害+对建筑伤害加成） | 出现概率低但战术价值高，改变玩家的防御策略 |

### 6.2 比例随机

每次尸潮的三种类型比例在预设范围内随机波动：

- 基础型占比最高，是尸潮的主体
- 进阶型占比居中
- 特殊型占比最低，但随综合评分提升而增加

特殊型的具体子类型也在池内随机，一次尸潮中最多出现 2 种不同特殊型（防止复杂度爆炸）。

### 6.3 与综合评分的关联

- 低评分据点：几乎只有基础型（95%+），偶有少量进阶型
- 中等评分据点：基础型约 70-80%，进阶型约 15-25%，偶有特殊型
- 高评分据点：进阶型和特殊型比例显著提升，构成更复杂

特殊型出现概率与综合评分正相关。这意味着玩家发展得越好，面对的尸潮不仅数量更多，构成也更棘手——这是"成长检验"的一部分。

## 七、尸潮行为

### 7.1 进攻优先级

丧尸对目标的优先攻击顺序：

1. **玩家** — 最高优先。丧尸感知到玩家后优先追击。
2. **NPC** — 次优先。被 NPC 攻击时反击；无玩家在视野内时主动攻击 NPC。
3. **防御建筑** — 第三优先。围墙、大门、陷阱等阻挡路径的建筑。
4. **生产/居住建筑** — 最低优先。在前三类目标不可达时攻击。

注意：丧尸不会"聪明地"绕过围墙——它们会攻击挡路的障碍物。但进阶型丧尸（有攀爬能力）可能翻越低级围墙，直接攻击墙后目标。

### 7.2 多方向汇聚

尸潮不从一个方向进攻。丧尸从据点的多个方向（2-4 个）同时生成并推进：

- 方向选择考虑了地形因素——丧尸不会从悬崖或水域方向出现
- 各方向的丧尸数量不一定均等——可能有一个主攻方向 + 若干牵制方向
- 这迫使玩家分散防御力量，而非集中火力堵一个口

### 7.3 噪音联动

尸潮期间的战斗噪音（枪声、爆炸、丧尸嘶吼）会与噪音系统联动：

- 据点内的高噪音（特别是枪声）可能吸引据点外原本不参与本次尸潮的游离丧尸
- 这些"额外增援"的丧尸从听到噪音的方向加入尸潮
- 潜行武器（弩、消音武器）不会触发额外增援

这意味着：**用枪打尸潮可能越打越多**。玩家需要在火力输出与控制噪音之间做权衡。

### 7.4 战斗结束后

尸潮结束后（所有波次完成 + 丧尸全灭或持续时间到），

- 剩余丧尸：如果持续时间到仍有丧尸存活，它们进入"游荡"状态——在据点周边徘徊但不主动进攻，玩家需要清理
- 尸体保留：丧尸尸体在地面保留一段时间后消失，玩家可在尸体上搜刮战利品

## 八、预警机制

尸潮不是"突然出现在据点门口"的偷袭。从触发判定到第一只丧尸到达，有一个预警阶段。

### 8.1 预警方式

| 方式 | 说明 | 可靠性 |
|------|------|--------|
| **环境音效** | 远处传来的丧尸嘶吼声逐渐变响，方向感清晰 | 100% 触发，最基础的预警 |
| **侦察** | 玩家可指派 NPC 或亲自到据点周边侦察，提前发现丧尸集结迹象 | 需要主动行动，可提前数小时预警 |
| **电台（可选）** | 若玩家建造并启用无线电台，可接收外界广播的区域尸潮预警 | 需要科技解锁和电力供应，提供最早的预警 |

### 8.2 预警时间

预警阶段从判定触发开始，到第一只丧尸到达据点外围结束。时长与尸潮规模正相关——大规模尸潮需要更长时间集结，预警也更长。

玩家在预警阶段可以做的事：
- 检查并加固防御工事（紧急修复受损建筑）
- 调整 NPC 部署（战斗岗位分配、非战斗 NPC 转移到安全区域）
- 检查弹药和医疗物资储备
- 决定"打"还是"撤"（见第九节）

## 九、玩家应对方式

### 9.1 加固防御

预警阶段的首要行动。检查围墙完整性，修复破损处，在关键位置补充陷阱。如果时间充裕，可以临时搭建额外障碍物。

### 9.2 调配人员

根据 NPC 的战斗能力分配岗位：
- 高战力 NPC 部署在主攻方向
- 低战力 NPC 部署在牵制方向或转移到后方安全区域
- 医生 NPC 准备医疗物资，在后方待命

### 9.3 战术选择

| 策略 | 优势 | 风险 |
|------|------|------|
| **固守据点** | 利用防御工事，NPC 协同作战 | 建筑受损，消耗弹药和医疗物资 |
| **出城迎击** | 在丧尸到达据点前削弱其数量 | 离开防御工事，玩家和 NPC 暴露风险高 |
| **火力全开** | 快速清场，减少建筑损伤 | 噪音大，可能吸引额外丧尸；弹药消耗大 |
| **潜行消耗** | 用陷阱和近战消耗丧尸，控制噪音 | 效率低，战斗时间长，防御建筑耐久压力大 |
| **诱敌分击** | 玩家主动引开一波丧尸，减轻主防线压力 | 玩家独自面对大量丧尸，风险极高 |

### 9.4 撤退

如果评估后认为无法守住，玩家可选择**战略性撤退**：

- 带领 NPC 撤离据点，转移至提前准备的备用据点或临时避难所
- 尸潮到达后，丧尸攻击无人防守的建筑（建筑仍会受损）
- 尸潮结束后返回，清剿残余丧尸，评估损失，重建

撤退不是"失败"——它是末世生存中的合理策略。但撤退的代价是建筑受损、资源可能被毁，NPC 士气大幅下降。

## 十、尸潮后效

### 10.1 即时结算

尸潮结束后，立即结算以下各项：

| 项目 | 结算内容 |
|------|---------|
| **弹药消耗** | 本次尸潮消耗的总弹药量，按武器类型统计 |
| **武器/工具耐久** | 近战武器和防御工具（如修理锤）的耐久消耗 |
| **医疗物资消耗** | 包扎、消毒、止痛药等使用量 |
| **建筑耐久损失** | 各建筑因丧尸攻击损失的耐久值 |
| **陷阱消耗** | 一次性陷阱（如木刺）的数量消耗 |

### 10.2 人员伤亡

- **NPC 受伤**：根据伤害类型和严重度应用伤病系统（详见 `injury.md`）
- **NPC 死亡**：永久失去该 NPC，连带其积累的熟练度
- **玩家受伤/死亡**：按死亡与存档机制处理（详见 `death-save.md`）
- **被咬伤的 NPC**：面临丧尸化风险（详见 `injury.md` 第六节），玩家必须在限定时间内决定如何处理

### 10.3 战利品

尸潮结束后，玩家可在丧尸尸体上搜刮战利品。战利品池与尸潮构成关联：

- 基础型丧尸：低价值掉落（破烂衣物、少量材料）
- 进阶型丧尸：中等价值掉落（武器零件、弹药、工具）
- 特殊型丧尸：高价值掉落（稀有零件、特殊材料、图纸碎片）

战利品的设计意图是**部分补偿尸潮消耗**，但不完全覆盖——尸潮整体上仍是净消耗事件。玩家不能靠尸潮"刷资源"。

### 10.4 NPC 士气影响

尸潮结果对 NPC 士气的影响是一次性大幅波动：

| 结果 | 士气变化 | 持续时间 |
|------|---------|---------|
| **轻松防守**（损失极小、无伤亡） | 士气**上升**——"我们能行" | 持续数日 |
| **艰难胜利**（有损失、有伤亡） | 士气**下降**——恐惧和悲伤 | 持续数日至数周 |
| **惨胜**（严重损失、大量伤亡） | 士气**大幅下降**——部分 NPC 可能想要离开 | 持续数周，需要食物/奖励提振 |
| **撤退**（放弃据点） | 士气**暴跌**——信任崩溃 | 极长，部分 NPC 可能永久离开 |

士气影响叠加在基础士气系统之上。尸潮后的士气管理是据点恢复的重要环节。

### 10.5 长期影响

- **建筑修复**：受损建筑需要消耗材料修复。这构成了战后恢复期的核心活动。
- **尸潮间隙**：触发概率重置后，玩家获得一段相对安全的"恢复窗口"，可以抓紧补种、修复、搜刮。
- **教训与准备**：每次尸潮暴露的短板（如某方向防御薄弱、弹药类型储备不足）驱动玩家调整策略，为下一次尸潮做准备。

## 十一、与母体的叙事关联

尸潮不是"偶然事件"，其根本原因与母体直接相关。

### 11.1 母体驱动

母体是丧尸行为的**组织者**。母体通过释放孢子信号，周期性召集周边区域的丧尸向生命密集区域（即玩家据点）发动集群进攻。尸潮本质上是母体的"免疫反应"——当幸存者据点发展到一定规模，母体将其视为威胁，组织丧尸进行清除。

### 11.2 母体数量与尸潮频率

- **母体数量**：地图上存在的母体越多，玩家据点周边的丧尸活动越频繁，尸潮基础触发概率越高。
- **母体距离**：距离据点越近的母体，对尸潮触发概率的贡献权重越大。
- **母体被摧毁**：摧毁一个母体后，其"管辖"范围内的尸潮触发概率显著降低。但其他母体可能扩张并接管该区域。

### 11.3 母体扩张与尸潮升级

母体随时间缓慢生长和扩散。母体的成长阶段影响尸潮构成：

- **小型母体**：周边尸潮以基础型为主。
- **中型母体**：进阶型丧尸出现概率提升。
- **大型母体**：特殊型丧尸出现，尸潮构成更复杂。

这形成了一个**战略闭环**：玩家发展越强 → 尸潮越大 → 推动玩家去摧毁母体以降低尸潮压力 → 摧毁母体获得高能矿物 → 交易换取更强装备 → 推动发展 → 面对更大的母体和更强的尸潮。

### 11.4 "献祭"机制与尸潮

强大生物可向母体"献祭"，促使其生长或产生新堕者。如果玩家放任周边区域的特殊生物活动而不清理，它们可能"献祭"母体，加速母体成长——间接导致更频繁、更强大的尸潮。这意味着**探索和清理周边区域是降低尸潮压力的间接手段**。

## 十二、设计决策记录

| 决策 | 原因 |
|------|------|
| PRD 伪随机而非真随机 | 避免连续尸潮（太残酷）和长期不触发（太无聊），平衡体验 |
| 规模正相关而非固定 | 匹配玩家水平，提供有挑战但可应对的压力，防止碾压和无聊 |
| 多方向进攻而非单方向 | 单方向可被"堵门"策略彻底化解，多方向迫使玩家分散防御力量 |
| 战利品部分补偿而非完全覆盖 | 尸潮是净消耗事件，如果尸潮能"赚钱"，玩家会主动刷尸潮，违背系统设计意图 |
| 噪音联动而非独立运行 | 与噪音系统解耦会让尸潮变得孤立，噪音联动让枪械"最后手段"的定位在尸潮中也成立 |
| 母体关联而非独立事件 | 赋予尸潮叙事意义，连接世界观，让摧毁母体有实际游戏收益 |
