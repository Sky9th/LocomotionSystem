# 农业与烹饪系统

> **最后更新**：2026-07-09
> **状态**：核心流程稳定，作物和食谱可持续扩展

---

## 一、系统定位

农业与烹饪系统是据点食物自给自足的核心，同时承担士气驱动的关键角色。

农业解决了"食物从哪里来"的长线问题——搜刮的食物终究会耗尽，农田才是永续生存的基础。烹饪解决了"食物有什么价值"的深度问题——生的食材只能填饱肚子，加工后的食物才能提升士气、驱动 NPC 效率。

两者绑定：农业为烹饪提供原料，烹饪让农业产出变得有意义。

## 二、农业流程

### 2.1 四步基础循环

```
开垦 → 播种 → 生长 → 收获
 └──────── 循环 ────────┘
```

#### 第一步：开垦

- 需求：锄头工具（工具系统）
- 操作：选择一块荒地 → 使用锄头 → 荒地转化为农田地块
- 限制：必须在雾区范围之外（雾区内无法开垦）
- 耗时：单块农田开垦需要一定时间 / 工作次数
- NPC 可代为操作（需分配锄头）

#### 第二步：播种

- 需求：对应作物的种子（从上次收获保留或搜刮获得）
- 操作：选择已开垦的农田 → 选择作物种类 → 消耗种子 → 播种完成
- 每块农田可种一种作物
- NPC 可代为操作

#### 第三步：生长

- 固定天数自动成熟，无需额外浇水、施肥等操作
- 不同作物有不同的生长周期（短/中/长）
- 生长期间农田在视觉上有阶段变化（刚播种 / 幼苗 / 成熟）
- 雾区若在生长期间扩张至农田区域 → 作物枯死、地块污染需重新开垦
- 无需玩家监控，成熟时通知

#### 第四步：收获

- 操作：选择成熟农田 → 收获
- 产出：食材（N 个）+ 概率返还种子（留种机制）
- 留种比例：每次收获有概率获得 1-2 颗种子，保障种植可持续
- NPC 可代为收获

### 2.2 留种机制

留种是农业可持续性的关键保障。设计要点：

- 每次收获除食材外，**必定额外产出 0-2 颗种子**（概率控制）
- 基础概率：80% 获得 1 颗，30% 获得 2 颗
- 这意味着每块农田平均产出足以支撑下一轮播种
- 但遭遇连续坏运气时可能缺种——玩家需保留种子储备或外出搜刮种子

## 三、作物清单

### 3.1 基础作物

| 作物 | 生长周期 | 单产食材 | 留种概率 | 特殊说明 |
|------|---------|---------|---------|---------|
| 土豆 | 中（7-10天） | 3-5 个 | 80%/30% | 产量高、耐储存，末世主食 |
| 胡萝卜 | 短（5-7天） | 2-3 个 | 70%/20% | 生长快、产量小，适合快速补充 |
| 卷心菜 | 长（10-14天） | 4-6 个 | 85%/35% | 产量最高但周期最长，高级食谱原料 |

### 3.2 作物扩展方向

未来可扩展的作物类型：
- 茄科（番茄/辣椒）——烹饪调味，提升士气加成
- 豆科（大豆）——制作豆腐/酱油，改变食谱体系
- 药用植物（草药）——医疗系统原料
- 纺织作物（棉花/麻）——制作衣物和护甲

## 四、烹饪系统

### 4.1 烹饪设施

| 设施 | 获取方式 | 可用食谱 | 产出上限 |
|------|---------|---------|---------|
| 篝火 | 初始可用 | 基础食谱（烤制、煮制） | 低品质食物 |
| 灶台 | 科技解锁（建造线） | 全部食谱 | 全品质食物 |

篝火和灶台的差异在于可使用的食谱范围和食物品质上限。篝火只能做简单加工（烤土豆、煮汤），灶台才能产出高级食物（炖菜、烤肉拼盘、药膳）。

### 4.2 食谱系统

采用**固定食谱模式**，而非自由组合模式：

- 每个食谱有固定的原料配比和产出
- 食谱通过搜刮食谱书或科技树解锁
- 解锁后永久可用
- 食谱本质是"知识"——学会就是学会

| 食谱来源 | 示例食谱 | 特点 |
|----------|---------|------|
| 初始已知 | 烤土豆、烤胡萝卜、煮蔬菜汤 | 基础饱腹，士气加成低 |
| 搜刮获得 | 炖肉汤、烤肉串 | 需要肉类 + 蔬菜，士气加成中 |
| 科技解锁 | 营养炖菜、药膳、大餐拼盘 | 原料多样、士气加成高 |

### 4.3 烹饪操作流程

```
1. 与烹饪设施交互（篝火或灶台）
2. 打开烹饪界面，显示已解锁食谱列表
3. 选择食谱 → 查看所需原料
4. 确认烹饪 → 消耗原料（从仓库自动扣除）
5. 等待烹饪时间（设施工作时 NPC 可代劳）
6. 产出食物 → 自动存入仓库
```

NPC 可从事烹饪工作——需分配厨具 + 附近有烹饪设施。NPC 会按指令或自主选择食谱进行烹饪。

## 五、食物效果

### 5.1 饱腹度

所有食物的基础功能——恢复饱腹度。每份食物有固定饱腹值，角色的饥饿程度决定进食频率。

### 5.2 士气加成

高品质食物提供额外的士气加成，这是烹饪系统的核心价值：

| 食物品质 | 士气效果 | 持续时间 | 示例 |
|----------|---------|---------|------|
| 无加成 | 无士气变化 | — | 生吃食材 |
| 基础 | ±0 | 当日 | 烤土豆、煮汤 |
| 良好 | +1 士气 | 当日 | 炖肉汤、烤肉串 |
| 精良 | +2 士气 | 当日 + 次日残留 | 营养炖菜、药膳 |
| 盛宴 | +3 士气 | 当日 + 次日 | 大餐拼盘、稀有食谱 |

## 六、与士气联动机制

饮食与士气的联动是农业与烹饪系统的价值锚点：

### 6.1 每日士气变化

- 每个 NPC 每日消耗至少一份食物
- 当日消耗的食物品质决定士气变化方向
- 连吃多天基础食物 → 士气缓慢累积衰减
- 高品质食物可抵消衰减并产生正向加成

### 6.2 饮食多样性

- 单调惩罚：连续食用同一种食物超过 N 天 → 士气每日 -1
- 多样化奖励：N 天内食用过 M 种不同食物 → 士气额外 +1
- 这推动玩家种植多种作物、解锁更多食谱

### 6.3 士气 → 工作效率

- 士气高 → NPC 工作速度提升、熟练度获取加速
- 士气低 → NPC 工作速度下降、可能拒绝工作
- 士气极低 → NPC 可能离开据点

## 七、NPC 工作参与

NPC 可参与农业和烹饪的全部环节，需满足以下条件：

| 工作类型 | 需求工具 | 需求设施 | 绑定科技 |
|----------|---------|---------|---------|
| 开垦 | 锄头 | 无（荒地即可） | 无 |
| 播种 | 无 | 已开垦农田 | 无 |
| 收获 | 无 | 成熟农田 | 无 |
| 烹饪（基础） | 厨具 | 篝火或灶台 | 无 |
| 烹饪（高级） | 厨具 | 灶台 | 对应食谱需科技解锁 |

NPC 不会"凭空"工作——必须有对应的工具和设施。这形成"生产资源→制作工具→分配给 NPC→NCP 生产更多资源"的内生循环。

## 八、雾区影响

赤尘孢子的设定对农业和烹饪产生直接约束：

- **无法种植**：雾区覆盖区域内无法开垦新农田，已有农田若被雾区覆盖则作物枯死
- **土地污染**：被雾区覆盖过的土地，雾区消退后需重新开垦（污染清除）
- **有机物污染**：在雾区内收获的食材、猎杀的动物肉类被视为污染食材，不可直接食用
- **污染食材风险**：若误食污染食材 → 玩家增加感染值，NPC 可能变异
- **选址意义**：农田必须建在远离雾区（或雾区扩散方向相反）的位置，据点选址须把农田安全纳入考虑

## 九、与其他系统的接口

| 关联系统 | 农业与烹饪提供 | 农业与烹饪需要 |
|----------|--------------|--------------|
| 资源系统 | 食材、食物（消耗品） | 种子、水、厨具（工具） |
| 工具系统 | 工具使用消耗（锄头、厨具） | 锄头（开垦）、厨具（烹饪） |
| NPC 系统 | 食物支撑 NPC 生存 | NPC 劳动力从事种田和烹饪 |
| 士气系统 | 食物品质驱动士气变化 | — |
| 科技树 | — | 解锁新作物品种、新食谱、灶台 |
| 世界观 | — | 农田选址避让雾区，污染食材不可食用 |
| 尸潮事件 | — | 尸潮可能破坏农田 |
