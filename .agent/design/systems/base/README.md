## 一、据点是什么

据点是玩家在八重岛末日废土中安身立命的空间。它既是生存的物理屏障，也是发展的核心载体。

**据点的三重身份**：

| 身份 | 含义 |
|------|------|
| **堡垒** | 围墙、陷阱、防御工事抵御尸潮，保障内部安全 |
| **家园** | NPC 居住、工作、吃饭的地方，也是玩家搜刮归来后的休息站 |
| **工厂** | 农田产出食材、工作台制作工具、灶台烹饪食物，自给自足的经济循环在此运转 |

据点选址由玩家自由决定。根据孢子侵蚀抗性梯度，森林和农田区域侵蚀等级低，适合建家；城市和工业区侵蚀严重，不适合长期居住但值得搜刮。

## 二、四个子系统如何协作

据点建设不是单一系统，而是四个子系统相互咬合运转的整体。

### 2.1 建造 -- 空间载体

建造系统提供物理空间。围墙圈出安全区、地板铺设活动面、工作台和灶台占据空间并提供功能。没有建造，其他三个系统没有"落地"的地方。

建筑有耐久、可被丧尸破坏、需材料修复——建造不是一劳永逸的，而是需要持续维护的生存投入。

> 详见 [building.md](building.md)

### 2.2 科技树 -- 成长驱动

科技树是据点能力的"天花板"。初始可用建筑有限（木墙、篝火、简易床），高级建筑（石墙、灶台、高级工作台）需要通过图纸消耗解锁。

科技树驱动的是"可建造什么"——它决定了建造菜单里出现哪些选项。没有科技解锁，据点在功能和美观上都无法进化。

> 详见 [tech-tree.md](tech-tree.md)

### 2.3 资源与工具 -- 经济循环

资源和工具是据点的"血液"。建造消耗材料（木材、石材、金属），种田需要锄头，烹饪需要厨具。

资源通过采集和搜刮流入仓库，通过建造和制作流出。工具在反复使用中消耗耐久，需要维修或更换。这个循环如果断裂（比如木材耗尽、工具全坏），据点发展就停滞。

> 详见 [resources-tools.md](resources-tools.md)

### 2.4 农业与烹饪 -- 食物供给 + 士气

据点的 NPC（以及玩家自己）需要吃饭。农业产食材，烹饪加工成食物。食物不仅是生存必需品，还与士气联动——长期单调饮食导致士气下降，士气下降又拖慢 NPC 工作效率和成长速度。

农业还有一个硬约束：雾区无法种植。这意味着农田必须建在安全区域内，据点选址直接影响农业产能。

> 详见 [agriculture-cooking.md](agriculture-cooking.md)

## 三、系统关系图

```
                    ┌──────────────┐
                    │   科技树      │
                    │  (图纸解锁)   │
                    └──────┬───────┘
                           │ 解锁新建筑/配方/工具
                           ▼
┌──────────┐ 材料消耗  ┌──────────┐  工具需求  ┌──────────────┐
│ 资源与工具 │ ──────► │   建造    │ ◄─────── │ 农业与烹饪    │
│          │          │          │          │              │
│ 采集/搜刮 │ ◄─────── │ 空间载体  │ ──────► │ 食材 → 食物   │
│ 仓库存储  │ 拆除返还  │ 耐久/防御 │ 占用空间  │ 士气联动      │
└──────────┘          └────┬─────┘          └──────┬───────┘
                           │                       │
                           │ 提供保护               │ 提供食物
                           ▼                       ▼
                    ┌──────────────────────────────────┐
                    │            NPC 劳动力             │
                    │   工作效率 ←── 士气 ←── 食物品质  │
                    │   存活需要 ←── 防御 ←── 建筑耐久  │
                    └──────────────────────────────────┘
```

**关键流转**：

1. **探索 → 资源流入**：玩家离开据点搜刮，带回材料、图纸、种子、工具
2. **解锁 → 能力扩展**：图纸消耗解锁科技 → 新建筑/新工具/新食谱可用
3. **建造 → 空间扩展**：消耗材料建造 → 新功能设施落地 → 防御增强
4. **种田 → 食物产出**：消耗种子和工具耐久 → 食材 → 烹饪 → 食物
5. **食物 → 士气 → 效率**：食物品质影响 NPC 士气 → 士气影响工作效率和成长速度
6. **尸潮 → 消耗循环**：尸潮攻击建筑 → 建筑受损 → 消耗材料修复 → 再次出发搜刮
