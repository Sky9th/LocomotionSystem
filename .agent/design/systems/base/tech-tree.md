# 科技树系统

> **最后更新**：2026-07-09
> **状态**：核心设计稳定，节点数量可后续无限扩展

---

## 一、系统定位

科技树是据点发展的核心驱动机制。玩家通过搜刮图纸、消耗图纸解锁科技节点，永久获得新能力——新配方、新建筑、新工具、新规则。

科技树定义了"据点能做到什么"的上限。没有研发成本、没有等待时间，唯一的门槛是图纸——图纸在哪里，科技就在哪里。

---

## 二、核心设计原则

### 2.1 图纸消耗型

每个科技节点需要消耗一张对应的图纸物品（或组合多张图纸）。图纸属于**知识类资源**，不可再生。学习后图纸消失，知识永久掌握。

### 2.2 前置 AND 逻辑

节点解锁条件为前置科技 ID 列表，所有前置必须全部满足，缺一不可。这意味着：

- 科技线内有纵向依赖（初级→中级→高级）
- 不同科技线之间存在横向交叉依赖（高级建筑可能需要工具科技线的支撑）
- 设计图纸分布时，交叉依赖创造"卡点"——玩家必须多线发展

### 2.3 解锁自动生效

满足前置 + 消耗图纸 → 立即解锁，无需等待时间，无需额外操作。解锁效果全局生效，所有 NPC 自动受益。

---

## 三、科技节点数据结构

每个科技节点包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| ID | 字符串 | 唯一标识，全局不可重复 |
| 名称 | 字符串 | 玩家可见的科技名称 |
| 描述 | 字符串 | 简短说明解锁了什么 |
| 图标 | 资源引用 | 科技树界面显示的图标 |
| 分类 | 枚举 | 所属科技线（农业/食物/建造/工具/医疗/战斗） |
| 前置科技 | ID 列表 | 解锁本节点必须满足的前置条件（AND 逻辑） |
| 消耗图纸 | ID 列表 | 学习时需要消耗的图纸物品 ID |
| 解锁效果 | 效果列表 | 学习后立即生效的效果数组 |
| 显示顺序 | 整数 | 科技树界面中的排列顺序 |

---

## 四、解锁效果类型

一个科技节点可以包含多种类型的解锁效果：

| 效果类型 | 说明 | 示例 |
|----------|------|------|
| 解锁配方 | 玩家和 NPC 获得新制作配方 | 解锁"铁斧"制作配方 |
| 解锁建筑 | 建造菜单中新增建筑选项 | 解锁"灶台""工作台" |
| 解锁工具/武器 | 可使用新的工具或武器 | 解锁"十字弩"使用 |
| 解锁 NPC 工作 | NPC 获得新的工作类型 | 解锁 NPC"烹饪"工作 |
| 修改参数 | 修改全局数值参数 | 建造速度 +20% |
| 提升上限 | 提升某项属性的上限 | NPC 等级上限 +5 |
| 解锁技能 | 玩家获得新的战斗技能 | 解锁"横扫"技能 |

## 五、科技获取流程

```
搜刮探索 → 发现图纸（知识类资源，不可交易）
       → 打开科技树界面
       → 查看可解锁节点（前置已满足、图纸已持有）
       → 点击"学习"
       → 消耗图纸 + 满足前置 → 解锁效果立即永久生效
```

关键规则：
- 图纸不可制作，不可交易，只能通过探索搜刮获得
- 多人学习同一科技需要多份图纸
- 图纸可存入仓库囤积，等待前置满足后使用
- 科技解锁覆盖全据点——玩家和所有 NPC 共享科技进度

## 六、科技界面设计

### 6.1 节点状态

| 状态 | 条件 | 视觉表现 |
|------|------|----------|
| 已解锁 | 该节点已被学习 | 高亮 + 勾选标记 |
| 可解锁 | 前置已满足 + 背包/仓库持有足够图纸 | 高亮 + 闪烁边框 |
| 不可见 | 前置未解锁，且不在当前搜索范围内 | 隐藏/灰色问号 |
| 可见但不可解锁 | 前置已满足但缺少图纸 | 灰色 + 显示图纸名称提示 |
| 前置未满足 | 前置条件不足 | 灰色 + 连线显示缺失的前置 |

### 6.2 分类筛选

科技树界面顶部提供分类标签：全部 / 农业 / 食物 / 建造 / 工具 / 医疗 / 战斗。选择分类后仅显示对应科技线的节点，其他节点隐藏但连线保留。

### 6.3 交互细节

- 点击节点：右侧面板展开详情（名称、描述、前置、消耗图纸、解锁效果）
- 可解锁节点：详情面板底部显示"学习"按钮
- 已解锁节点：详情面板显示解锁时间
- 连线：灰色虚线（未解锁）/ 实色实线（已解锁）

## 七、图纸分布原则

图纸按科技线分布在主题匹配的地点，遵循"哪里有相关知识，哪里就能找到对应图纸"的原则：

| 科技线 | 图纸分布地点 | 示例图纸 |
|--------|-------------|----------|
| 农业 | 农场、书店、园艺店、村庄民宅 | 灌溉技术、轮作知识 |
| 食物 | 餐厅厨房、食品工厂、民宅厨房、书店 | 腌制技术、烘焙工艺 |
| 建造 | 建筑工地、五金店、工厂、书店 | 地基施工、承重墙设计 |
| 工具 | 五金店、修理厂、工具店、工厂 | 锻造基础、零件精加工 |
| 医疗 | 医院、诊所、药店、实验室 | 外伤处理、抗生素提取 |
| 战斗 | 枪店、警察局、军事设施、猎户家中 | 弹药改造、战术配合 |

图纸稀有度与地点危险度成正比：基础图纸在安全区域（村庄、农田），高级图纸在危险区域（军事基地、城市工业区）。

## 八、六条核心科技线

### 8.1 农业线
围绕种植效率、作物种类、农田管理展开。解锁新作物品种、肥料使用、灌溉技术。终局解锁温室（可在雾区边缘种植）。

### 8.2 食物线
围绕食物加工、储存、营养价值展开。解锁新食谱、腌制/风干技术、食材利用率提升。终局解锁营养强化（食物士气加成倍增）。

### 8.3 建造线
围绕建筑材料、建筑类型、防御工事展开。解锁石材建筑、多层结构、陷阱系统。终局解锁防御塔。

### 8.4 工具线
围绕工具种类、工具品质、维修效率展开。解锁铁器制作、零件复用、批量生产。终局解锁自动化工具台。

### 8.5 医疗线
围绕治疗效率、药品制作、感染净化展开。解锁绷带/急救包制作、防毒面具、感染值清除。终局解锁抗体（一定时间内免疫感染）。

### 8.6 战斗线
围绕武器制作、弹药制造、战斗技能展开。解锁枪械维修、弹药复装、爆炸物制作。终局解锁穿甲弹和高级护甲。

## 九、与其他系统的接口

| 关联系统 | 科技树提供 | 科技树需要 |
|----------|-----------|-----------|
| 资源系统 | 新配方（对应制作产出） | 图纸物品（知识类资源） |
| 建造系统 | 解锁新建筑类型 | — |
| NPC 系统 | 解锁新工作类型、提升等级上限 | NPC 工作产出（材料支撑制作） |
| 农业与烹饪 | 解锁新作物、新食谱 | — |
| 战斗系统 | 解锁新武器、新技能、新弹药 | 战斗熟练度（部分科技有战斗等级前置） |
| 尸潮事件 | 解锁防御科技 | 尸潮检验据点发展成果 |
| 世界观 | 防护科技（防毒面具）、净化科技、母体材料利用 | — |
