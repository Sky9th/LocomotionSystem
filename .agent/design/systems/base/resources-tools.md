# 资源与工具系统

> **最后更新**：2026-07-09
> **状态**：核心框架稳定，资源品类和工具类型可持续扩展

---

## 一、系统定位

资源与工具系统是游戏经济循环的基础，定义了所有物质实体及其交互规则。

资源回答了"这个世界有什么"——从搜刮到采集，从可再生到不可再生，每一种资源都有自己的来源和去处。工具回答了"角色如何与世界交互"——没有工具，角色无法工作、无法建造、无法改造环境。

两者共同构成了"获取→使用→消耗→补充"的闭环。

## 二、资源分类框架

### 2.1 六大基础类别

所有物品归属六大类，分类基于现实物质形态，确保玩家直觉匹配：

| 大类 | 子类示例 | 说明 |
|------|---------|------|
| **材料类** | 木材、石材、金属、玻璃、塑料、橡胶、纺织品、化学品 | 建造、制作、维修的基础物质。体积大、重量重 |
| **工具类** | 木工工具、农具、建筑工具、维修工具、厨具、医疗工具 | 工作载体，有耐久。可搜刮、可制作、可维修 |
| **武器类** | 冷兵器、热武器、弹药、爆炸物 | 战斗用。弹药为消耗品，武器有耐久 |
| **消耗品类** | 医疗品、燃料、电池、食品、饮品、种子 | 一次性使用。用完即消失 |
| **零件类** | 标准件（螺丝/钉子）、机械零件（齿轮/弹簧）、电子元件（电路板/电线）、管道件 | 维修和高级制作的中间材料 |
| **知识类** | 图纸、书籍、地图、手册 | 不可制作、不可交易。科技解锁的消耗品 |

### 2.2 按获取方式分类

| 获取方式 | 涵盖品类 | 特点 |
|----------|---------|------|
| 采集 | 木材、石材、植物纤维、水 | 基础资源，野外可再生 |
| 搜刮 | 工具、武器、零件、图纸、消耗品 | 主要获取方式，一次性，不可再生 |
| 生产 | 加工材料、制作工具、烹饪食物 | 需要配方 + 原料 + 设施 |
| 种植 | 食材、种子 | 农业系统产出，需要土地和管理 |

### 2.3 按用途分类

| 用途 | 涉及资源 | 对应系统 |
|------|---------|----------|
| 生存必需 | 食物、水、药品、燃料 | 饥饿/健康/疲劳 |
| 生产必需 | 工具、材料、零件 | 建造/制作/农业 |
| 发展必需 | 图纸、高级材料、高能矿物 | 科技树/交易 |
| 防御必需 | 弹药、武器、建材 | 战斗/尸潮/建造 |

## 三、工具系统详解

### 3.1 设计哲学

工具不是背包里的装饰品，而是角色与世界交互的**媒介**。没有斧头就不能砍树，没有锄头就不能开垦，没有厨具就不能烹饪。工具的存在让"能做什么"成为显性规则，而非隐形假设。

### 3.2 工具类型清单

| 工具类型 | 核心用途 | 绑定工作 | 典型搜索地点 |
|----------|---------|----------|-------------|
| 斧头 | 砍伐树木、分解木材 | 采集（木材） | 工具店、消防箱、农场 |
| 镐子 | 开采石材、矿脉 | 采集（矿物） | 矿场、工具店、建筑工地 |
| 锤子 | 建造、修理建筑 | 建造/维修 | 五金店、车库、民宅 |
| 锯子 | 加工木材、制作家具 | 制作（木工） | 工具店、工厂、车库 |
| 锄头 | 开垦农田、翻土 | 种植（开垦） | 农场、园艺店、村庄民宅 |
| 厨具 | 烹饪食物 | 烹饪 | 厨房、餐厅、民宅 |
| 扳手/钳子 | 维修机械、拆卸零件 | 维修（机械） | 修理厂、车库、工厂 |

### 3.3 工具属性

每个工具物品包含以下属性：

| 属性 | 说明 |
|------|------|
| 耐久度 | 工具的可用次数，每次工作消耗 |
| 工作效率系数 | 影响工作速度的倍率（高品质工具 > 基础工具） |
| 维修材料配方 | 消耗哪些材料可以恢复耐久 |
| 品质等级 | 影响最大耐久和工作效率（基础/良好/优良） |
| 是否可制作 | 部分工具只能搜刮，部分可后期制作 |

### 3.4 获取双轨制

| 获取途径 | 适用阶段 | 特点 |
|----------|---------|------|
| 搜刮 | 全程，前期主要 | 零成本，依赖探索运气，获得品质随机 |
| 制作 | 中后期补充 | 需要科技解锁配方 + 消耗材料，品质可控 |

双轨并行而非互斥——搜刮不够用的时候制作来补，制作不了的稀有工具只能靠搜刮。

### 3.5 消耗与维修

- **消耗规则**：每次使用工具完成一个工作动作（砍一棵树、翻一垄地、烹一道菜），工具耐久 -1
- **损坏后果**：耐久归零 → 工具损坏 → 该工具物品消失
- **维修机制**：使用对应材料维修，恢复部分耐久（非满耐久）。维修配方可能消耗零件类资源（如修复斧柄需要木料 + 钉子）
- **维修限制**：每把工具有最大维修次数，达到上限后报废

## 四、存储系统

### 4.1 据点仓库（全局存储）

- 据点拥有统一仓库，所有资源统一存取
- NPC 工作时自动从仓库取用材料和工具，产出自动存入
- 建造、烹饪、制作消耗的资源直接从仓库扣除
- 仓库容量可随建筑扩展（建造更多储物箱）

### 4.2 背包容量（个人携带）

- 玩家和每个 NPC 拥有独立背包，容量有限
- 探索时携带的资源受背包格数 + 负重限制
- 回到据点后可将背包物品一键存入仓库
- 背包容量可由装备（背包）或科技提升

## 五、资源循环

### 5.1 可再生资源

基础自然资源可通过采集持续获取，形成自然补充循环：

- 树木（木材）：野外刷新周期较长，鼓励据点周围植树
- 石材（石矿）：固定矿点，但不同位置矿藏量不同
- 水：据点水井或附近水源可无限取用
- 种植产出：农业系统持续产出食材

### 5.2 搜刮资源（一次性）

地图上分布的搜刮资源为一次性获取，位置固定、数量固定：

- 工具、武器、零件、图纸、消耗品
- 搜刮完毕后不会刷新
- 这驱动玩家不断向更远、更危险区域探索

### 5.3 不可再生资源

某些关键资源在整个游戏世界中的总量固定，不可再生也不可制造：

- 图纸（每张唯一地点）
- 高能矿物（仅母体死亡产出）
- 特殊零件（如军用电子元件）

这些资源驱动玩家深入最危险的雾区，构成探索的终极动机。

## 六、与其他系统的接口

| 关联系统 | 资源系统提供 | 资源系统需要 |
|----------|------------|-------------|
| 科技树 | 图纸物品（知识类资源） | 解锁新制作配方、新工具使用 |
| NPC 系统 | 工具（工作载体）、食物（生存消耗） | NPC 通过工作产出资源 |
| 建造系统 | 材料（木材/石材/金属等） | 工具（建造需锤子/锯子） |
| 战斗系统 | 弹药、武器 | 击杀丧尸获得材料（极少） |
| 农业与烹饪 | 种子、厨具 | 食材产出、食物产出 |
| 尸潮事件 | 弹药、工具耐久消耗 | 尸潮战利品（少量资源） |
| 世界观 | 高能矿物（交易筹码） | 雾区内资源获取需防护装备 |
