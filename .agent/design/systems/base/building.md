# 建造系统

> 日期: 2026-07-09
> 状态: 设计阶段
> 关联: `game-overview.md` 建造系统章节 / `base/README.md` 据点建设总览

---

## 一、系统定位

建造系统是据点建设的空间载体。如果说科技树决定了"能做什么"，资源系统提供了"用什么做"，那么建造系统回答的是"做在哪里"——它将蓝图、材料和劳动力转化为可见、可用、可被破坏的物理建筑。

没有建造，农田无处开垦、工作台无处安放、NPC 无处睡觉、围墙无从建立。建造是据点一切功能的物理基础。

---

## 二、核心设计原则

1. **模块化自由组合**：基于 Synty 模块化资产，建筑可自由摆放、旋转、紧邻拼接。玩家决定的不是"建什么布局"，而是每一块地板、每一段围墙的位置。

2. **功能导向**：建筑不是装饰。每种建筑提供明确的游戏功能——围墙阻挡丧尸、工作台解锁制作配方、床提供 NPC 休息位。

3. **网格化对齐**：建筑吸附到统一网格，自动对齐相邻建筑。降低操作门槛的同时保证视觉整洁。

4. **有耐久、可破坏、需维护**：建筑不是永久的。丧尸攻击、尸潮冲击都会消耗建筑耐久。耐久归零建筑消失。玩家需要消耗材料修复受损建筑——建造是持续投入，不是一次消费。

5. **与科技树绑定**：基础建筑开局可用，高级建筑（石墙、高级工作台、灶台等）需要消耗图纸通过科技树解锁。建造菜单的可选项随着科技进度逐步扩展。

---

## 三、建筑分类

### 3.1 防御建筑

阻挡丧尸进入据点的第一道防线。丧尸优先攻击防御建筑。

| 建筑 | 材料 | 耐久 | 说明 |
|------|------|------|------|
| 木墙 | 木材 | 中等 | 基础围墙，初期防御 |
| 石墙 | 石材 + 木材 | 高 | 进阶围墙，科技解锁 |
| 木门 | 木材 | 中等 | 可开关的通行口，玩家/NPC 自动通过，丧尸被阻挡 |
| 木刺陷阱 | 木材 + 金属 | 低（一次性伤害） | 对经过丧尸造成伤害，耐久归零后消失 |

**设计要点**：
- 围墙和门组成封闭区域 = 安全区。安全区内丧尸无法进入（除非门被破坏）。
- 围墙本身不阻挡视线或射击，玩家可在墙后攻击墙外丧尸。
- 陷阱对玩家和 NPC 不触发。

### 3.2 生产建筑

提供制作、加工、烹饪功能。NPC 需要在对应建筑上工作才能产出。

| 建筑 | 材料 | 前置科技 | 功能 |
|------|------|----------|------|
| 篝火 | 木材 + 石材 | 初始可用 | 基础烹饪（有限食谱），提供光源 |
| 灶台 | 石材 + 金属 | 烹饪科技线解锁 | 进阶烹饪（更多食谱），食物品质+ |
| 工作台 | 木材 + 金属 + 零件 | 建造科技线解锁 | 解锁工具/武器制作配方 |
| 农田 | 锄头开垦（非建筑材料） | 初始可用 | 播种作物，产出食材 |

**设计要点**：
- 篝火和灶台是互斥升级关系——有了灶台后篝火可拆除回收。
- 工作台等级可扩展（基础工作台 → 高级工作台），对应更复杂的制作配方。
- 农田不是"建造"出来的，而是用锄头在可耕地上"开垦"出来的。但开垦后的地块在系统上视为建筑地块。

### 3.3 居住建筑

提供 NPC 和玩家的生活所需。

| 建筑 | 材料 | 功能 |
|------|------|------|
| 简易床 | 木材 + 纺织品 | 1 个休息位（NPC 睡觉恢复体力），玩家存档点 |
| 储物箱 | 木材 + 金属 | 增加据点仓库容量 |

**设计要点**：
- 每张床 = 1 个 NPC 床位。NPC 总数不能超过据点床位数。
- 床的材质和质量可升级（简易床 → 舒适床），影响 NPC 士气和体力恢复速度。
- 储物箱容量叠加，所有储物箱共享同一仓库池。

### 3.4 结构建筑

提供空间基础，本身无游戏功能，但其他建筑通常需要依托结构建筑放置。

| 建筑 | 材料 | 说明 |
|------|------|------|
| 木地板 | 木材 | 铺设平坦地面，部分建筑需放置在地板上 |
| 石地基 | 石材 | 更坚固的地基，可用于加固地板或提升建筑耐久基底 |

**设计要点**：
- 地板决定"可建造区域"。农田不能放在地板上（需要土地），但工作台和床需要地板。
- 石地基上的建筑获得耐久加成——它既是地板也是隐形的防御升级。

## 四、获取方式

建筑获取有两种途径：

### 4.1 初始可用

以下建筑在游戏开始时即可建造，无需科技解锁：
- 木墙、木门、木地板
- 篝火、农田（开垦）
- 简易床、储物箱

这些建筑覆盖了据点最基础的需求：防御、生产、居住。玩家开局即可圈地建家。

### 4.2 科技解锁

以下建筑需要消耗对应图纸、通过科技树解锁后才能建造：
- 石墙、石地基（建造科技线）
- 木刺陷阱（建造科技线）
- 灶台（烹饪科技线）
- 工作台（建造科技线）
- 高级舒适床（建造科技线）

解锁流程：搜刮获得图纸 → 打开科技界面 → 消耗图纸学习 → 科技节点点亮 → 建造菜单中新增对应建筑选项。解锁是永久且据点全局的。

## 五、建造操作流程

建造采用网格化操作，五步完成：

```
步骤1: 打开建造菜单 → 选择建筑类型
步骤2: 半透明预览出现在鼠标位置，自动吸附最近网格点
步骤3: 按 R 键旋转（每次 90 度），旋转后仍对齐网格
步骤4: 单击确认放置 → 检查材料是否足够 → 消耗材料 → 建筑生成
步骤5: 建筑进入功能状态（防御生效/生产可用/居住提供床位）
```

**操作细节**：

- **网格吸附**：默认网格大小为 1 米 × 1 米，建筑按自身体积占用整数格。预览时显示蓝色（可放置）或红色（不可放置，如与其他建筑重叠或在不可建造地形上）。
- **旋转**：每次按 R 旋转 90 度。门和围墙有方向性——门需要正确的朝向才能让 NPC 自动通行。
- **材料检查**：确认放置时一次性扣除材料。材料不足时显示红色提示，建造失败（不消耗任何材料）。
- **即时生效**：建筑放置后立即生效。围墙立即阻挡丧尸、工作台立即开放制作菜单。
- **建造时间**：玩家建造为即时完成。NPC 建造（见第九章）有建造时间。

## 六、拆除与回收

玩家可以拆除已放置的建筑。

| 操作 | 结果 |
|------|------|
| 进入建造菜单 → 选择"拆除"模式 → 点击建筑 | 建筑消失，返还 50% 建造材料到仓库 |
| 存储物品的建筑（储物箱） | 需先清空内部物品才能拆除 |

**设计考量**：
- 50% 返还而非 100%，防止玩家无成本反复调整布局。同时保留"拆旧建新"的灵活性。
- 拆除返还的材料类型与建造消耗完全一致（木材建造 → 返还木材），不做通用"建材"抽象。
- 防御建筑在尸潮来临前不可拆除（防止玩家"临阵拆墙"逃课）。

## 七、耐久与破坏

### 7.1 耐久值

所有建筑都有耐久值，不同类别基线不同：

| 类别 | 耐久基线 | 说明 |
|------|----------|------|
| 防御建筑 | 高 | 设计目的即为承受攻击 |
| 生产/居住建筑 | 中 | 不直接承受攻击，但在防线上 |
| 结构建筑 | 低 | 地板和地基本身不吸引攻击 |

石地基上的建筑耐久获得加成（+30%），石墙耐久显著高于木墙。

### 7.2 丧尸攻击优先级

丧尸在据点内的攻击遵循优先级：

```
玩家 > NPC > 防御建筑 > 生产/居住建筑 > 结构建筑
```

- 丧尸优先攻击可见的活物（玩家/NPC）
- 活物不可及时，转而攻击路径上的防御建筑（破墙而入）
- 防御建筑被破坏后，丧尸进入内部，转而攻击生产/居住建筑
- 结构建筑（地板/地基）优先级最低，通常在丧尸大量堆积时才被波及

### 7.3 修复机制

耐久未归零的建筑可通过消耗材料修复。

- **修复材料**：与建造材料相同（木墙用木材修，石墙用石材修）
- **修复效率**：1 个材料恢复固定耐久值（如 1 木材 = 10 耐久）
- **修复触发**：玩家主动操作——进入建造菜单 → 选择"修复"模式 → 点击受损建筑
- **状态显示**：建筑外观随耐久下降逐渐破损（裂纹 → 碎块 → 坍塌前兆），玩家可目测判断哪些建筑需要修

## 八、与其他系统的接口

| 系统 | 输入 | 输出 |
|------|------|------|
| **资源系统** | 消耗材料（木材、石材、金属、零件、纺织品） | — |
| **工具系统** | NPC 建造需要对应工具（锤子），消耗工具耐久 | — |
| **科技树** | 高级建筑需科技解锁 | 新建筑选项加入建造菜单 |
| **NPC 系统** | NPC 可被指派建造任务（需锤子） | 建筑完成为 NPC 提供床位、工作位 |
| **农业与烹饪** | 农田（开垦地块）作为建筑占位；篝火/灶台作为烹饪设施 | 建筑提供食物加工能力 |
| **尸潮事件** | 尸潮攻击建筑，消耗耐久 | 防御工事是尸潮应对的核心手段 |
| **士气系统** | — | 建筑品质（舒适床 vs 简易床）影响 NPC 士气 |

## 九、NPC 参与建造

NPC 可被指派建造任务，但核心建造控制权在玩家手中。

**玩家建造 vs NPC 建造**：

| 维度 | 玩家建造 | NPC 建造 |
|------|----------|----------|
| 操作方式 | 手动选择建筑、放置、确认 | 玩家放置蓝图后，指派 NPC 去建造 |
| 建造时间 | 即时完成 | 有建造时间（取决于 NPC 等级和建筑复杂度） |
| 消耗 | 材料即时扣除 | 材料即时扣除，工具耐久在建造过程中消耗 |
| 适用场景 | 紧急防御（尸潮前筑墙）、精细布局 | 大规模建设、非紧急扩建 |

当玩家手动建造时，建造即时完成——这保证了玩家在紧急情况下能快速反应。当指派 NPC 建造时，NPC 移动到建筑位置，消耗建造时间完成，释放玩家的操作窗口去处理其他事务。
