# 孢子侵蚀抗性设定

**所属项目**：俯视角末世生存种田流游戏
**状态**：初稿
**更新日期**：2026-07-05
**关联文档**：[[game-overview.md]] 世界观设定章节

---

## 一、核心设定

赤尘孢子对环境的侵蚀能力并非均等。存在一条从 **"完全免疫"** 到 **"重度侵蚀"** 的梯度：

| 侵蚀等级 | 环境类型 | 孢子活性 | 堕者密度 | 母体生成 |
|----------|----------|----------|----------|----------|
| **零级 · 免疫** | 海洋/大型水体 | 近乎为零 | 无 | 不可能 |
| **一级 · 高抗性** | 原始森林、湿地、珊瑚礁等生命高密度区 | 极低 | 极少（偶有游荡） | 极难（几乎不发生） |
| **二级 · 中抗性** | 农田、牧场、村庄等半自然区域 | 低 | 零星 | 罕见 |
| **三级 · 低抗性** | 小镇、郊区 | 中等 | 常见 | 可能 |
| **四级 · 无抗性** | 城市、工业区、军事基地 | 高 | 密集 | 已确认存在 |

**核心规律**：**生命密集程度越高的自然环境，对赤尘的抵抗力越强；人类改造越多、生态越单一的区域，越容易被侵蚀。**

## 二、设定逻辑（游戏中不可知，仅供设计参考）

### 2.1 为什么海水无效？
已有设定：海水中孢子扩散和污染能力极弱甚至无效。原因不明。

### 2.2 为什么原始森林也抗性高？
与海水同理——**原因不明**。但现象是一致的：原始森林、湿地、珊瑚礁等物种高度多样的生态系统，对赤尘表现出显著的抵抗力。

游戏内可能的推测方向（仅作叙事素材，不确认真相）：
- 生物多样性产生的某种"生态场"抑制了孢子活性
- 土著微生物与孢子存在竞争/拮抗关系
- 孢子更倾向于感染/改造"简单"的生态系统（如单一物种主导的城市环境）

**设计原则**：**不做科学解释，保持神秘感。** 玩家只能观察到现象，无法确认真相。

### 2.3 为什么城市侵蚀最严重？
反过来理解：城市是人类活动最密集、生态最单一的区域——混凝土、钢铁、单一物种（人类+宠物+害虫）。这种"生态真空"对赤尘来说几乎没有阻力。

## 三、与已有设定的衔接

### 3.1 与海水设定一致
已有设定：*"母体/孢子在海水中的扩散和污染能力极弱甚至无效（原因未知）"* — 本设定将这一规律从海洋扩展到所有"高生命密度生态"，形成统一规则。

### 3.2 与八重岛地形契合
八重岛地形（已有设定）：北部山地森林、中部小镇农田、南部港口及军事设施。

按侵蚀梯度重新映射：
| 区域 | 生态类型 | 侵蚀等级 | 游戏体验 |
|------|----------|----------|----------|
| 北部山地森林 | 原始森林 | 一级 | 相对安全，资源丰富（木材/猎物），适合建据点 |
| 中部农田 | 农田/村庄 | 二级 | 轻度威胁，偶有堕者，主角初始区域 |
| 中部小镇 | 小镇 | 三级 | 中度威胁，搜刮价值高，需战斗准备 |
| 南部港口 | 城市/工业 | 四级 | 高度危险，堕者密集，可能已有母体 |
| 南部军事设施 | 军事基地 | 四级 | 极度危险，但最高价值搜刮（武器/图纸） |

### 3.3 与母体设定的衔接
已有设定中的母体生成条件不变。但在高抗性区域（原始森林），母体几乎不可能自然生成——即使有赤尘存在，也无法积累到形成母体的临界浓度。

## 四、叙事意义

### 4.1 主角存活的原因
**这也是为什么主角能在偏远村庄幸存的关键因素。**

灾难爆发时：
- 城市人口密集、生态单一 → 赤尘快速侵蚀 → 大面积感染 → 堕者潮爆发
- 偏远村庄靠近森林/农田 → 自然环境提供缓冲 → 感染速度慢 → 幸存者有反应时间

如果全岛同步沦陷、遍地堕者，一个普通人根本无法存活。侵蚀梯度的存在使得"幸存"本身具有了合理性。

### 4.2 探索的自然引导
侵蚀梯度天然形成了难度曲线：
- **新手期**：村庄/农田周边（二级），低威胁，学习基础生存
- **成长期**：小镇边缘（三级），开始接触战斗和搜刮
- **挑战期**：港口/军事基地（四级），高回报高风险

这与已有开发规划中的"A测地图 = 小镇+周边农田/森林"完全匹配。

### 4.3 长线叙事钩子
- 如果森林能抵抗赤尘，为什么城市不能"复野"来恢复抗性？（可能的后期科技/玩法方向）
- 外界为什么选择八重岛作为封锁对象——是否因为他们已经观察到侵蚀梯度，在做某种实验？
- 母体是否会进化出突破高抗性区域的能力？（后期威胁升级的方向）

## 五、对已有系统的影响

### 5.1 对尸潮系统
已有尸潮设定不受影响。但可在叙事层补充：尸潮本质上是从高侵蚀区向低侵蚀区扩散的堕者聚集现象。

### 5.2 对科技树
可选新增科技方向（远期）：
- **生态学观测**：幸存者通过观测发现侵蚀规律（叙事解锁，非科技节点）
- **生态恢复**：通过种植多样性作物、引入物种，提升据点周边抗性（远期玩法）

### 5.3 对地图设计
A测地图设计时需体现：
- 森林区域 → 视觉上更"干净"，植被茂密，氛围相对平和
- 农田村庄 → 轻度侵蚀痕迹，偶有堕者
- 小镇 → 雾区边缘可见，建筑破损，堕者活跃
- 港口/军事基地 → 重度雾区，母体可能存在，建筑严重侵蚀

### 5.4 对建造选址
玩家选择据点位置时存在策略考量：
- 靠近森林 → 安全但远离搜刮点
- 靠近小镇 → 搜刮便利但尸潮威胁更大
- 平衡点在农田/村庄边缘（初始区域自然引导）

## 六、待后续细化

1. **侵蚀等级的具体量化**：是否需要在代码中以数值表示（如 `erosionResistance: 0-1`），还是仅作为地图设计的定性指导？
2. **动态变化**：玩家的建造/砍伐是否会降低区域抗性？（如砍光森林 → 抗性下降 → 堕者增多）
3. **雾区与侵蚀的关系**：雾区是否只能在抗性低的区域扩散？还是雾区本身会降低区域抗性？
4. **视觉表现**：不同侵蚀等级的环境美术差异定义。
