## 一、灾难起源

### 1.1 时间与地点

**202X年，现代。** 一颗陨石坠落在虚构的日本岛屿"八重岛"近海，撞击产生的冲击波摧毁了南部港口的部分设施。陨石本身沉入海底，但它携带的东西留了下来——一种被后续研究者命名为 **"赤尘"（Red Dust）** 的外星孢子。

### 1.2 赤尘（Red Dust）

赤尘并非地球已知的任何微生物或真菌。它通过两种途径传播：

- **空气传播**：孢子微粒悬浮于空气中，可被吸入肺部。
- **接触传播**：直接接触受污染的土壤、水体或感染者体液。

赤尘的核心行为模式是 **"感染 → 改造 → 聚合"**：

1. 首先感染碳基生命体（人类、动物、植物均可被感染）。
2. 在宿主体内繁殖并逐步替换宿主组织。
3. 当局部孢子浓度达到临界值，聚合生成 **母体**。

赤尘对无机物（金属、混凝土、塑料）无任何作用——它只对碳基有机结构感兴趣。

### 1.3 堕者（The Fallen）

被赤尘感染的碳基生命最终会失去意识，沦为 **"堕者"**——仅凭本能攻击未感染活物的行尸走肉。

| 特性 | 描述 |
|------|------|
| **意识** | 完全丧失，无恐惧、无痛觉、无自我 |
| **行为** | 被活物的声音、气味、移动吸引，无差别攻击 |
| **弱点** | 头部——大脑是赤尘控制宿主的神经中枢，摧毁即死 |
| **感染性** | 被咬伤/抓伤后 **100% 感染**，潜伏期数小时至数天不等 |
| **变异** | 少数堕者在长期感染后发生变异，体型增大或获得特殊能力 |

堕者不进食、不休息、不衰老。它们不是"活着的尸体"——它们是被外星生物劫持的碳基载具。

## 二、八重岛地理

八重岛（Yaejima）是一座面积约 **300 平方公里** 的虚构岛屿，位于日本列岛以南的太平洋海域。灾难前人口约 1.5 万，以渔业、农业和旅游业为生。

### 2.1 三大地理板块

| 板块 | 位置 | 地形特征 | 灾难前功能 | 灾难后状况 |
|------|------|----------|------------|------------|
| **北部山地森林** | 岛屿北半部 | 山地 + 原始森林覆盖，海拔 200-800m，溪流密布 | 自然保护林、少量猎户小屋 | 侵蚀抗性高，堕者极少，相对安全 |
| **中部小镇农田** | 岛屿中央谷地 | 平坦谷地，农田与牧场交错，散布两座小镇和数个村庄 | 农业区 + 居民区 | 轻度侵蚀，偶有堕者，幸存者初始活动区 |
| **南部港口军事区** | 岛屿南端沿海 | 天然深水港、工业仓储区、一处旧日军遗留设施改建的自卫队观测站 | 渔业港口 + 军事观测 + 小型工业 | 重度侵蚀，堕者密集，母体已确认存在 |

### 2.2 交通与隔离

岛屿内部有一条环岛公路和数条山间小道连接南北。灾难后道路多处阻断，部分区域被废弃车辆和倒塌建筑堵塞。岛屿与外界无桥梁或隧道连接——唯一的进出方式是船或飞机，这为后续的外部封锁提供了天然便利。

## 三、母体（The Hive）

### 3.1 形态与本质

**母体是赤尘的终极聚合形态**——一棵巨大的树状外星生命体，高度可达数十米，"树干"由致密的有机-矿物复合材料构成，"树冠"持续释放孢子雾气。

母体不是植物，不是真菌，不是动物。它是赤尘孢子达到临界浓度后自发聚合而成的 **集体生命形态**——相当于无数单个孢子的"社会性躯体"。一个母体就是一个独立的赤尘集群意志。

### 3.2 核心特性

| 特性 | 描述 |
|------|------|
| **无攻击力** | 母体本身不具备攻击或移动能力，它是纯粹的繁殖与改造器官 |
| **多母体** | 八重岛上存在 **多个母体**，各自独立，彼此不冲突 |
| **缓慢扩散** | 母体持续释放孢子雾气，缓慢扩大控制范围，速度以周/月计 |
| **献祭机制** | 强大堕者可将捕获的活物（含人类）拖至母体根部"献祭"，促进母体生长或催生新型堕者 |
| **可摧毁** | 母体可被武力摧毁（核心暴露后，炸药或持续攻击有效），死亡后残留 **高能矿物** |
| **摧毁后果** | 母体死后其控制的雾区不会立即消散，但不再扩张；周边堕者失去"方向感"，行为更混乱 |

### 3.3 高能矿物

母体死亡后，其核心结晶化为一种泛着暗红色微光的高密度矿物。外界通过无人机交易极力回收此矿物，用途未知。

**矿物特性**：
- 能量密度极高，远超已知任何天然矿物。
- 仅在母体核心产出，每只母体产量有限。
- 是幸存者与外界交易的唯一硬通货。

## 四、雾区（The Haze）

母体持续释放的孢子雾气在空中聚集，形成肉眼可见的淡红色薄雾区域，称 **"雾区"**。

### 4.1 雾区特性

| 维度 | 描述 |
|------|------|
| **影响对象** | **仅影响有机生命**——玩家、NPC、动物、植物。无机物（建筑、金属、武器）不受直接影响 |
| **视野** | 雾区内能见度大幅下降，越靠近母体越浓，核心区能见度不足 5 米 |
| **感染累积** | 在雾区内停留会持续累积"感染值"，达到阈值后发病（NPC 可能尸变，玩家死亡） |
| **种植禁令** | 雾区内 **无法种植任何作物**——雾气直接杀死植物或使其变异不可食用 |
| **有机物污染** | 雾区内自然生长的动植物均被污染，不可食用，不可作为材料 |
| **防护需求** | 需要防毒面具或特殊防护装备才能安全进入；身体抗性可延缓感染积累但无法完全免疫 |

### 4.2 雾区与母体的关系

- 一个母体 = 一个雾区。雾区以母体为中心向四周扩散。
- 雾区边界并非清晰界线，而是一个浓度递减的过渡带。
- 多个母体的雾区可能融合，形成更大的覆盖区域。
- 雾区扩张速度受环境侵蚀抗性影响——高抗性区域（森林）扩张极慢，低抗性区域（城市）扩张迅速。

---

## 五、侵蚀抗性梯度

赤尘孢子对不同环境的侵蚀能力存在显著差异。**核心规律：生命密集程度越高的自然环境，对赤尘的抵抗力越强；人类改造越多、生态越单一的区域，越容易被侵蚀。**

| 侵蚀等级 | 环境类型 | 孢子活性 | 堕者密度 | 母体生成 | 游戏体验 |
|----------|----------|----------|----------|----------|----------|
| **零级 · 免疫** | 海洋 / 大型水体 | 近乎为零 | 无 | 不可能 | 天然屏障，海上安全，游泳/船行无感染风险 |
| **一级 · 高抗性** | 原始森林、湿地 | 极低 | 极少（偶有游荡） | 极难 | 相对安全，资源丰富，建据点首选，偶遇堕者不足惧 |
| **二级 · 中抗性** | 农田、牧场、村庄 | 低 | 零星 | 罕见 | 轻度威胁，日常搜刮与耕种区，需保持警惕 |
| **三级 · 低抗性** | 小镇、郊区 | 中等 | 常见 | 可能 | 中度威胁，搜刮价值高，需要战斗准备和防护 |
| **四级 · 无抗性** | 城市、工业区、军事基地 | 高 | 密集 | 已确认 | 高度危险，最高价值搜刮，须组队+全防护进入 |

### 5.1 八重岛的实际映射

| 区域 | 侵蚀等级 | 体验定位 |
|------|----------|----------|
| 周边海域 | 零级 | 安全通道（但被封锁） |
| 北部原始森林 | 一级 | 安全区，资源采集 + 可选据点选址 |
| 中部农田村庄 | 二级 | 初始区，基础生存与建设 |
| 中部小镇 | 三级 | 中期搜刮目标，战斗检验 |
| 南部港口 + 军事设施 | 四级 | 终局探险，高回报高风险 |

### 5.2 设计原则

侵蚀梯度的成因在游戏中 **不做科学解释，不确认真相**。玩家只能通过观察和情报碎片获知现象，永远无法确知"为什么"。保持世界的神秘感。（详见 [spore-erosion-rules.md](spore-erosion-rules.md) 第二章）

## 六、外部封锁

### 6.1 联合封锁体系

灾难爆发后，多国联合力量在八重岛周边建立了三层封锁防线。封锁的目标不是保护岛内，而是 **阻止任何碳基生命体离开岛屿**——无论人类、动物，还是可能携带孢子的有机物。

| 层级 | 手段 | 覆盖范围 | 目标 |
|------|------|----------|------|
| **外层 · 水面巡逻** | 驱逐舰/护卫舰 24h巡逻，雷达 + 红外探测 | 岛屿周边 12 海里 | 拦截任何水面船只 |
| **中层 · 空中监视** | 无人机 + 反潜机持续巡航，热成像扫描 | 全岛及近海空域 | 发现游泳/潜水/飞行逃离者 |
| **内层 · 水下声呐** | 声呐阵列 + 感应水雷 | 岛屿近海水下 | 定位任何水下逃离的生物信号 |

### 6.2 三级响应机制

封锁系统高度自动化。当检测到疑似逃离行为时：

1. **一级 · 警告**：广播警告，要求返回。适用于小型、非明确逃离信号。
2. **二级 · 非致命拦截**：无人机发射催泪弹/声波武器驱赶。适用于无视警告者。
3. **三级 · 致命打击**：舰载武器直接开火。适用于大规模或武装逃离尝试。

没有例外，没有申诉，没有"人道主义豁免"。八重岛是一个活体培养皿，外面的人只想确保盖子盖紧。

### 6.3 封锁背后的动机推测

外界为什么封锁而非救援？游戏内不给出明确答案，但暗示了多重可能：
- 担心孢子扩散至全球（公开理由）
- 对高能矿物的需求高于人道关怀（暗中动机）
- 八重岛本身是一个"实验场"（阴谋论）
- 三者兼有（最可能）

## 七、无人机交易

### 7.1 唯一的联系通道

无人机交易是岛内幸存者与外界**唯一的正规联系通道**。每间隔一定天数（游戏内约 3-7 天），外界派遣一架大型货运无人机降落在指定坐标（通常是南部港口的旧货运广场）。

### 7.2 交易规则

| 规则 | 描述 |
|------|------|
| **交易媒介** | 高能矿物 = 唯一硬通货 |
| **交易方式** | 幸存者将矿物放入无人机货舱 → 无人机扫描矿物质量 → 释放对应价值的补给箱 |
| **全程无人化** | 无人机不搭载任何人，不与幸存者直接沟通，操作完全自动化 |
| **密封操作** | 货舱和补给箱均有生物密封，防止孢子污染 |
| **补给内容** | 食物、药品、弹药、工具、防毒面具滤芯、基础建材等生存物资 |

### 7.3 设计意义

无人机交易在叙事和玩法上同时承担关键角色：

- **叙事上**：提醒玩家"外面的人还活着，但你们已经被抛弃了"——强化"有希望的绝望"感。
- **玩法上**：高能矿物将"冒险"和"生存"两个循环打通——想要物资就得深入雾区，想要深入雾区就得先有物资。
- **逃离线**：积攒足够矿物后可能换取特殊运输，触发结局选项。

## 八、幸存者处境

### 8.1 玩家身份

玩家扮演一名 **普通幸存者**。灾难发生时可能在八重岛附近海域航行，侥幸未在最初爆发中被感染。乘小船登岛时身无长物——没有武器，没有物资，没有特殊技能。生存从零开始。

### 8.2 岛上聚落

灾难后，岛上的幸存者逐渐形成数个零散聚落：

- **人口**：全岛估计幸存者不超过 200 人，分散在 5-8 个聚落中。
- **关系**：聚落间以物易物，偶有合作，但信任极度稀缺。资源匮乏引发过数次冲突。
- **态度**：从"互助求生"到"各扫门前雪"到"先下手为强"，各种态度并存。
- **情报**：聚落间偶尔交换信息——哪个区域堕者变少了、哪里可能有未搜刮的物资、谁最近在无人机投放点附近失踪了。

### 8.3 核心矛盾："有希望的绝望"

这是贯穿整个游戏的基调：

> 你可以活下去。你可以用矿物换到不错的物资。你甚至可以过得比灾难前还好。
> 但你永远不被允许回去。
> 你不是被困在岛上——你是被困在"被抛弃"这个事实里。

这条矛盾线驱动着两条叙事轨道：
- **生存线**：接受现实，在岛上建立自己的生活。种田、建设、保护同伴、对抗尸潮。这是游戏的主体内容。
- **逃离线**：拒绝接受，攒矿换运输。成功后被送往另一个隔离岛——不是回家，而是换一个牢笼。

## 九、堕者与尸潮的叙事关联

### 9.1 堕者的生命层级

堕者并非完全均质。随着感染时间推移和赤尘在体内的深化，部分堕者出现变异：

| 类别 | 描述 | 叙事定位 |
|------|------|----------|
| **普通堕者** | 新近感染者，行动迟缓，个体脆弱 | 构成尸潮主体的炮灰 |
| **进化堕者** | 感染数月以上，体型增大，速度/力量提升 | 对幸存者构成真正威胁的战斗单位 |
| **特殊堕者** | 产生独特变异（爆炸、喷吐、召唤等），数量极少 | 母体的"免疫细胞"——守护核心区域 |

### 9.2 尸潮的叙事解释

尸潮在叙事层面并非"随机事件"，而是赤尘集群行为的宏观表现：

- 母体通过孢子网络感知周边区域的活物分布。
- 当检测到高密度活物聚集（例如一个有人口和建筑的幸存者据点），母体会引导周边堕者向该方向汇聚。
- 这不是"有意识的攻击"，而是赤尘的本能扩散反应——活物 = 潜在宿主 = 感染扩散机会。

换句话说：**尸潮不是丧尸发现了你，是母体发现了你。**

### 9.3 母体摧毁对尸潮的影响

摧毁母体后，该母体控制的堕者失去"方向引导"：
- 短期内堕者行为更混乱，可能出现局部密度下降。
- 长期看，其他母体的控制范围会缓慢接管这些"无主"堕者。
- 如果岛上所有母体都被摧毁，堕者将回归纯粹的本能游荡状态。

## 十、结局与逃离

### 10.1 逃离条件

积攒足够数量的高能矿物后，幸存者可通过无人机通讯频道发出特殊请求——用大量矿物换取一次 **"货物运输"**。这不是官方允许的撤离计划，而是封锁力量内部的灰色交易——有人愿意收矿物、睁一只眼闭一只眼。

### 10.2 逃离过程与代价

1. 玩家被装入密封货柜，伪装成矿物运输。
2. 运输终点不是日本本土，而是某国在太平洋上的军事隔离岛。
3. 在隔离岛上接受长期医学观察（6 个月至数年不定）。
4. 即使确认未被感染，也 **不得回归人类社会**——隔离岛就是新家。
5. 结局后可选择：结束游戏观看结局叙述，或继续留在八重岛进入无尽沙盒模式。

### 10.3 设计意图

这不是一个"好结局"。这是一个"选择"——是选择在自己的岛上做自由人，还是选择用矿物换一个"名义上的回归"。逃离本身不意味着胜利，只是另一种囚禁的开始。真正的胜利是玩家自己定义的——可能是在八重岛建立一个足够好的生活，以至于逃离变得不再必要。

## 十一、设定逻辑自检表

| 逻辑链 | 检查项 | 自洽性 |
|--------|--------|--------|
| 灾难起源 → 母体 | 陨石孢子 → 感染碳基生命 → 聚合生成母体 | 自洽 |
| 母体 → 雾区 | 母体持续释放孢子雾气 → 改造周边区域生态 | 自洽 |
| 海水免疫 + 森林高抗 → 侵蚀梯度 | 海水无效 + 森林高抗 → 侵蚀集中于城镇 → 幸存者在偏远村庄存活合理 | 自洽 |
| 海水隔绝 → 外部封锁 | 海水中孢子无法扩散 → 灾难可控于一岛之内 → 封锁在军事上可行 | 自洽 |
| 封锁 → 无人机交易 | 外界需要高能矿物但不愿冒险登岛 → 无人化交易是唯一安全通道 | 自洽 |
| 矿物价值 → 玩法循环 | 矿物是唯一硬通货 → 驱动玩家深入雾区 → 将冒险和生存两循环打通 | 自洽 |
