# 资产包评估框架

> 日期: 2026-06-12
> 用途: 评估第三方资产包（以 Synty POLYGON 系列为主）是否值得购买、优先级如何
> 关联: [[asset-license-tracker]]

## 背景

原有 Tier 分级主要依赖主观判断（"这个看起来有用"），缺乏统一标准。Woodland Apocalypse Map 的误判暴露了问题——仅凭标题和价格做决策，没查依赖、没看内容形态、没评估可替代性。

此框架要求**逐资产拉取产品 JSON 数据**后评分，不得凭标题/印象判断。

---

## 7 维评分框架

### 1. 资产形态 — "买来能拼还是只能看？"

| 等级 | 形态 | 说明 |
|------|------|------|
| ★★★★★ | 模块化元件 | 独立模型/材质/prefab，可自由组合搭建任意场景 |
| ★★★★☆ | 主题套装 | 同风格的一组模块化资产，部分完整建筑但用模块化方式构建 |
| ★★★☆☆ | 混合包 | 预搭建场景 + 少量新元件，元件可复用，场景仅参考 |
| ★★☆☆☆ | 预搭建场景 | 已布置好的关卡，拆解复用成本高 |
| ★☆☆☆☆ | 纯展示 | 仅供欣赏，无工程可用资产 |

**关键判断**：模块化建筑件 > 完整建筑 > 预搭建场景。程序化生成开放世界以模块化元件为核心需求。

---

### 2. 内容质量 — "东西多不多、好不好？"

- **独立资产密度**：去重后的唯一资产数（vs 变体/换色数量），以厂商产品 JSON 描述为准
- **跨场景复用率**：一个资产能在多少不同情境下使用（岩石 > 某品牌自动售货机）
- **Hero vs Filler 比例**：核心资产的占比（角色/武器/建筑 vs 碎石/垃圾桶）
- **单位成本**：价格 ÷ 独立资产类别的加权和

| 等级 | 标准 |
|------|------|
| ★★★★★ | 多个独立资产类别，每个类别数量充足，复用率极高 |
| ★★★★☆ | 独立资产丰富，部分可复用 |
| ★★★☆☆ | 数量尚可，但变体/重复多，复用场景有限 |
| ★★☆☆☆ | 资产少或大量换色填充 |
| ★☆☆☆☆ | 几乎没有独立可复用资产 |

---

### 3. 持有成本 — "真正到手要花多少钱？"

- **标价**：**必须使用常规原价**（`compare_at_price` 或 `price` 中较高的），促销/首发折扣不计入
- **依赖链**：是否需要其他包？叠加后的总持有成本
- **授权模式**：按席位还是按项目？有无收入上限？

| 等级 | 标准 |
|------|------|
| ★★★★★ | 独立包，无依赖，授权友好 |
| ★★★★☆ | 独立包，单价较高但合理 |
| ★★★☆☆ | 有 1 个依赖包，但依赖包本身也在计划内 |
| ★★☆☆☆ | 多个依赖包，总持有成本显著上升 |
| ★☆☆☆☆ | 依赖未计划的昂贵包，或授权有限制 |

> **⚠️ 促销具有时效性，不得影响评分。** $200 的包打 3 折到 $60，持有成本仍按 $200 评——促销只影响"什么时候买"，不影响"值不值得买"。

---

### 4. 技术适配 — "能直接拖进项目用吗？"

- **引擎兼容**：Unity 2022.3+ / URP
- **源文件**：是否提供 FBX/PSD
- **性能**：POLYGON 系列低多边形风格天然适合开放世界，此项对同系列基本为常量

| 等级 | 标准 |
|------|------|
| ★★★★★ | Unity URP 原生支持 + FBX 源文件 + 低多边形性能友好 |
| ★★★★☆ | Unity URP 支持，无源文件 |
| ★★★☆☆ | 需手动适配材质/管线 |
| ★★☆☆☆ | 仅 Built-in 或需大量改造 |
| ★☆☆☆☆ | 不兼容 Unity / 非 POLYGON 风格 |

---

### 5. 功能价值 — "支撑什么 gameplay 机制？"

| 层级 | 类型 | 示例 |
|------|------|------|
| ⬆️ 最高 | 直接玩法资产 | 武器、载具、可拾取物品、角色——直接影响 gameplay |
| ⬆️ 高 | 环境叙事 | 废墟、路障、涂鸦、尸体——讲述世界故事 |
| ⬆️ 中 | 关卡构建 | 建筑模块、道路、地形元件——搭建地图的基础 |
| ⬇️ 低 | UI/反馈 | 粒子特效、图标、HUD——玩家感知层 |
| ⬇️ 最低 | 仅参考 | 预搭建场景——不直接进游戏，仅供设计参考 |

一个资产包可同时覆盖多层，按最高层级定档。

| 等级 | 标准 |
|------|------|
| ★★★★★ | 覆盖直接玩法 + 关卡构建 + 环境叙事 |
| ★★★★☆ | 覆盖关卡构建 + 环境叙事 |
| ★★★☆☆ | 仅关卡构建或仅直接玩法 |
| ★★☆☆☆ | 仅 UI/反馈 |
| ★☆☆☆☆ | 仅参考 |

---

### 6. 可替代性 — "不用它会怎样？"

| 等级 | 标准 |
|------|------|
| ★★★★★ | 不可替代——整个项目的视觉/玩法基础，无其他包可替代 |
| ★★★★☆ | 高度专属——其他包能部分覆盖但缺失关键内容 |
| ★★★☆☆ | 可部分替代——已有/计划包能覆盖 ~50% 功能 |
| ★★☆☆☆ | 可大量替代——已有/计划包能覆盖大部分，只需少量补充 |
| ★☆☆☆☆ | 完全替代——已有资产即可实现，或可低成本自制 |

---

### 7. 组合关系 — "和 tracker 里其他资产怎么互动？"

| 关系 | 符号 | 影响 |
|------|------|------|
| **重叠** | ⇄ | 降低本资产优先级——功能已被其他包覆盖 |
| **互补** | ⊕ | 提升本资产优先级——填补其他包无法覆盖的空白 |
| **依赖** | ← | 计入持有成本——必须先/同时购买其他包 |
| **独占** | ⊗ | 不可替代——特定功能仅此包提供 |

评分时需列出**具体的关联资产名称和关系**，不得只写符号。

## 购买时机（不计入评分）

促销具有时效性，**不得影响 7 维评分和 Tier 判定**。此维度仅标注购买建议的时间窗口。

| 标签 | 条件 | 含义 |
|------|------|------|
| 🟢 **现在** | 当前折扣 ≥ 50% 或为历史最低价 | 立即购买 |
| 🟡 **等打折** | 常规价，Synty 经常 50-70% off | 等下次打折季 |
| 🔵 **不急** | Tier 3，当前无折扣 | Phase 后期再考虑 |
| ⚪ **不买** | Tier 4 | 不购买 |

额外标注：
- **折扣频率**：该包历史上打折多频繁（从 Synty tags 和社区信息推断）
- **折扣力度**：通常打几折（Synty 常规 50%，Humble Bundle 可达 70%+）
- **当前促销**：如果有活跃折扣，标注促销价和原价

---

## Tier 定义

| Tier | 含义 | 购买时机 |
|------|------|---------|
| **Tier 1** | 核心必需——缺它没法做游戏 | 首批购买，Phase 4-5 前到位 |
| **Tier 2** | 高价值——显著加速开发 | 第二批，对应 Phase 购买 |
| **Tier 3** | 锦上添花——填补空白或节省小量时间 | 打折时购买，或 Phase 后期补充 |
| **Tier 4** | 不相关——与项目方向不匹配 | 不购买 |

Tier 由 7 维综合判定，非简单加总。维度 6（可替代性）和维度 7（组合关系）权重最高——它们直接回答"买 vs 不买"。

---

## 数据来源

- **必须**拉取 `https://syntystore.com/products/{handle}.json` 获取产品完整数据
- 不得仅凭标题、截图、印象评分
- 评分需附产品 JSON 中的关键数据（内容清单、依赖声明、价格、技术信息）

## 使用流程

1. 获取产品 JSON → 提取内容清单、依赖、价格、技术信息
2. 逐维度评分（1-5 星），每项附一句依据
3. 维度 7 列出具体关联资产
4. 综合判定 Tier，说明加权理由
5. 更新 `asset-license-tracker.md`
