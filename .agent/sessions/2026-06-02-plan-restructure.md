# 2026-06-02 — 短期/长期计划重构

## 目标

基于 L4_Combat 战斗系统架构设计，重构短期和长期开发计划，确保计划与架构一致、范围边界清晰、推迟项有明确依赖方。

## 关键决策

### 短期计划：Phase 4 从 4 步缩到 2 步

| 变更 | 原因 |
|------|------|
| 4.1 重写（三层架构+双搜索类型） | 架构已设计，旧"鼠标左键攻击"过时 |
| 4.2 伤害管道 → **删除** | DamageRule 集成已纳入 4.1；伤病/死亡归入敌人 AI |
| 4.4 噪音骨架 → **删除**（合并入 4.2） | 发布端已在 4.1（攻击命中发布 SNoiseEvent），消费端是 4.2 敌人感知输入通道，不是独立子系统 |
| 4.3 敌人 AI → **4.2** | 重新编号 |

### 基准反推

以三个基准要求逐条反推 4.1 的 12 个施工子项——全部是地基，没有多余项。2 个技能（Q Cone + R RayLine）是最小闭环：验证架构支持多搜索类型，不需要 4 个。

4.2 同样反推：6 个子项全是地基+闭环必需。GridGraph bake 是其隐含前置依赖。

### 4.2 不纳入（每条有明确依赖）

- 噪音连锁/衰减 → Phase 12+ 噪音扩展
- 视觉光线影响/尸群/特殊感染者 → Phase 12+ 敌人扩展
- 丧尸化过程 → Phase 12+ 伤病扩展

### 长期计划同步

- 状态/完成项/子系统描述更新
- Phase 5 新增"战斗物品化"（武器=ItemDefSO+WeaponSkillSetSO）+ "战斗扩展"（Buff/Ranged/熟练度）
- Phase 12+ 战斗扩展对齐新划分（远程武器/熟练度→Phase 5，连招/技能效果/投射物→Phase 12+）
