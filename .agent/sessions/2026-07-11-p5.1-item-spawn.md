# 2026-07-11 — P5.1 物品地面生成 + AssetRef 运行时修复

## Background

P5.1 物品经济第一步：玩家走进房间，地上有物品。完成 HybridCLR Mod 闭环后回到 Phase 5 开发。

核心驱动：`PropertyPresetSO.Prefab` 是 C# 字段，Mod 无法覆写。改为 PropertyTree `Common/VisualPrefab` 节点。

前置基础设施：`AssetRefPropertyDefSO.Load()` 全量 `#if UNITY_EDITOR`，Build 中 AssetRef 值永远返回 null。需修复后 P5.1 才能工作。

## Changes

### 基础设施 — AssetRef 运行时加载

- `AssetRefPropertyDefSO.Load()` — runtime 路径 `Addressables.LoadAssetAsync<Object>(guid).WaitForCompletion()` + static cache + Editor fallback。移除 `#if UNITY_EDITOR` 分裂。
- `AssetRefPropertyDefSO.Resolve()` — 补 Object 直传路径的类型约束校验（此前仅 GUID 路径受约束）。

### PropertyTree — VisualPrefab 迁移

- `properties_all.json` — Entity 树 `Common/` 下新增 `VisualPrefab` 节点；Equipment 树 `Presentation/` 下移除 `VisualPrefab`。
- ConsumableBase/AmmoBase 现可读写 `Common/VisualPrefab`（此前仅在 Equipment 子树可见，而 ConsumableBase/AmmoBase 继承 Entity 而非 Equipment）。
- Unified loading: `Addressables.LoadAssetAsync(guid)` 原生支持 GUID 加载（`m_IncludeGUIDInCatalog: 1`），Editor + Build + Mod catalog 同一路径。无需 GUID→Path 中间映射。

### EntityService — 物品生成

- `CreateGameObject()` 统一入口：角色 → `Instantiate(Prefab)`；物品 → `GetAsset<GameObject>("Common/VisualPrefab")` → `defaultItemPrefab`（CoinBag）→ `CreatePrimitive(Cube)` 三级 fallback。
- `GroundItem.cs` 删除 — 物品生成无需独立 Prefab 或组件。模型直接 Instantiate，GO 直接 AddComponent<Identity>()。
- 角色路径标注 TODO：后续迁移到 Common/VisualPrefab；远期模块化装配。

### PlayerService — 测试代码

- 旧测试（zombie/backpack/container spawn）注释，仅保留 P5.1 地面物品 spawn。
- `bladeDefKey`/`pistolDefKey`/`backpackDefKey` 序列化字段移除，硬编码 `"Machete"`/`"M1911"`。

### 修复 — Unity fake-null

- `EntityCommandModule`/`EntityQueryModule`/`CharacterEquipment` — C# `?.`/`??=` 替换为 Unity 重载 `== null`，避免已销毁 Object 的 MissingReferenceException。

## Decisions

| Decision | Alternatives | Reason |
|----------|-------------|--------|
| AssetRef Load() → Addressables.LoadAssetAsync(guid) | A: GUID→Path SO 映射层 B: AssetRefMapBuilder 扫描 | Addressables 原生支持 GUID 加载（catalog 含 GUIDs），无需中间层 |
| VisualPrefab 放 Entity/Common | 留在 Equipment/Presentation | ConsumableBase/AmmoBase 不继承 Equipment，无法读取；Common/Icon 已开先例 |
| 物品生成无 GroundItem 组件 | A: GroundItem prefab + fallbackVisual 字段 B: GroundItem.cs 组件 | 模型直接 Instantiate，Identity 直接 AddComponent——最简 |
| fallback: CoinBag prefab（序列化字段） | A: CreatePrimitive(Cube) B: 代码内 GUID 硬编码 | 单一静态引用，序列化字段合理；Inspector 可配置 |
| 测试代码硬编码 "Machete"/"M1911" | 序列化字段 bladeDefKey/pistolDefKey | 测试代码不需要 Inspector 配置；内容 ID 迁移后改为 contentId |
