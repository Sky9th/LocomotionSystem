---
name: session-focus
description: 检测对话内容偏离当前会话目标时，建议用户另起 Session 以节省 token 和保持聚焦。
when_to_use: 用户提出与当前开发任务无关的话题（询问新功能、切换模块、大量设计讨论）时，主动建议新开会话。
---

## 触发条件

- 用户开始讨论与当前分支/任务无关的新模块或新功能
- 当前会话已跨度大量主题（超过 3 个不相关的领域）
- 上下文窗口消耗过多（接近上限）
- 用户问"能不能做 XXX"而 XXX 不在当前计划范围内

## 响应方式

简明提醒，不啰嗦：

> 💡 这个话题和当前 Session 的任务不太相关，建议新开一个 Session 来讨论 / 开发，可以节省 token 并保持焦点。

如果用户坚持在同一个 Session 继续，尊重选择。
